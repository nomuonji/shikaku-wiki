# ウェブ解析士（WACA認定）

## 資格の対象

ウェブ解析士は、一般社団法人ウェブ解析士協会（WACA）の民間認定資格です。サイトや広告のアクセス数を読むだけでなく、事業の目標と指標を結び付け、データから改善案を考える人を主な対象としています。Web担当者、広告・マーケティング職、制作会社の担当者、自社サイトを運用する人が、解析の基礎を体系的に学ぶ入口になります。法律上の独占業務を与える国家資格ではありません。

WACAには、ウェブ解析士、上級ウェブ解析士、ウェブ解析士マスターの段階があります。初級のウェブ解析士試験は、GA4の操作だけに限らず、事業分析、KPI、SEOや広告、レポート作成などを扱います。上位資格へ進むと、分析結果から提案を作り、実務の中で説明する力がより求められます。どの段階を選ぶかは、知識を得たいのか、分析レポートを仕事で使いたいのか、講師や指導者を目指すのかで変わります。

## 2026年度の受験方法

2026年度の協会案内では、認定講座の受講は任意で、公式テキストを使って独学し試験だけ申し込むこともできます。試験はPCで受ける60分・60問の四択式で、公式案内上はテキスト、講座スライド、計算機などを参照できます。開催回ごとの申込締切と試験期間、オンライン受験環境は変わるため、申し込み前に募集ページを確認してください。試験費用は2026年度の案内で17,600円（税込）です。講座を受ける場合は別途講座費用がかかります。

2026年9月以降の一部開催では、セーフティブラウザとWebカメラ付きPCが必要です。すべての開催回が同一の機材・手順とは限らないので、選んだ試験回の案内を優先してください。受験手続きは公式スケジュールから開催回を選び、会員サイトに登録して決済し、試験環境を事前確認します。

## 認定後の継続と制度変更

WACAは年度ごとにカリキュラムを改定し、資格の継続には年会費とフォローアップテストが関係します。免除条件や支払期限は取得日と資格区分により変わるため、会員規約と資格維持ページを確認してください。2027年度には認定方法と価格を見直す方針が公表されていますが、細部には「確定次第案内」とされた項目があります。2026年度内の申込みに適用される現行条件と、2027年度の予定を混同しないことが大切です。
