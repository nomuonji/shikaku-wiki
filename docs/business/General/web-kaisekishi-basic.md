# ウェブ解析士 (WACA認定)

## 概要
ウェブ解析士は、一般社団法人ウェブ解析士協会（WACA）が認定する民間資格です。
単なるアクセス解析ツールの使い方だけでなく、Webマーケティング全体の知識、KPI設定、現状分析、改善提案まで、成果につながる実務的なスキルを体系的に学べます。
「ウェブ解析士」「上級ウェブ解析士」「ウェブ解析士マスター」の3段階があります。

## 試験詳細 (初級: ウェブ解析士)
試験はオンラインで実施され、自宅から受験可能です。

| 項目 | 内容 |
| --- | --- |
| **試験日程** | 随時（月2回程度の特定期間に実施） |
| **試験時間** | 90分 |
| **問題数** | 50問（4択問題） |
| **合格ライン** | 正答率 70%以上（回により変動あり） |
| **受験料** | 17,600円（税込） |
| **受験資格** | なし |
| **持ち込み** | 可（テキスト、電卓、Google検索、GA4画面など） |

## 出題範囲
- ウェブ解析の基礎概念
- 事業分析とKPI設定
- Google アナリティクス 4 (GA4) の基礎と活用
- SEO、広告、SNSなどのマーケティング手法
- レポーティングと改善提案

## 難易度・勉強時間目安
- **難易度**: 低 ～ 中 (合格率 80% ～ 90%程度)
    - テキスト持ち込み可であるため、合格率は高いです。
    - ただし、90分で50問を解くスピードが求められるため、テキストのどこに何が書いてあるかを把握しておく必要があります。
- **勉強時間**: 30 ～ 50 時間程度
    - 公式テキスト（非常に分厚い）を一通り読み込み、模擬試験を解くことが重要です。
    - 未経験者の場合、認定講座を受講すると理解が早まります。
