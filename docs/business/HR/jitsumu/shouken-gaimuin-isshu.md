# 証券外務員（一種・二種）

## 受験前に知っておくこと

証券外務員資格は、金融商品の勧誘・販売など外務員業務に必要な知識を確認する資格です。試験に合格しただけで誰でも販売業務を始められるわけではありません。金融商品取引業者などで外務員として働く際は、所属する協会員を通じた外務員登録が必要です。金融機関の採用や配置では一種・二種のどちらが必要かを求人や勤務先に確認します。

一般向けの試験には一種と二種があります。二種では株式現物、公社債、投資信託などを含む基礎的な商品知識を扱い、一種では信用取引やデリバティブなど、より広い範囲を扱います。取り扱い可能な業務は資格区分だけでなく、法令・社内権限・登録状況にもよるため、「一種ならすべての金融商品を無条件で扱える」とは考えないでください。

## 2026年の試験方式と合格基準

日本証券業協会の2026年案内では、一種は100問、二種は70問のPC入力方式です。出題は○×方式と五肢選択方式で構成され、一種は2時間40分、二種は2時間です。合格基準は一種が440点中308点以上、二種が300点中210点以上。問題の配点は形式により異なります。

|  | 一種 | 二種 |
| --- | --- | --- |
| 問題数 | 100問 | 70問 |
| 試験時間 | 2時間40分 | 2時間 |
| 合格点 | 308点 / 440点 | 210点 / 300点 |

試験はテストセンター等で実施され、申込時に最新の予約枠と受験料を確認します。受験料、本人確認書類、予約変更の期限は申込先の案内に従います。2026年には一部の例外的な試験制度や対象期間も告知されているため、一般受験か、協会員の研修・特別会員向け区分かを取り違えないようにしてください。

## 学習範囲

日本証券業協会は、出題範囲の基準として「外務員必携」の目次を案内しています。金融商品取引法、協会規則、株式・債券・投資信託、先物・オプション、財務諸表、経済・金融の基礎などを学びます。法令や商品制度は改正されるため、古い問題集だけで学習せず、最新版の公式資料に照らしてください。

二種から始めるか一種を直接受験するかは、職場が求める資格区分、現在の金融知識、試験範囲に割ける時間で選びます。合格率や勉強時間は年度や受験者により異なり、協会が保証する目安として確認できないため、ここでは固定値を示しません。
