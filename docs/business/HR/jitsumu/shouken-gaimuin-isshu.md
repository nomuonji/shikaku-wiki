# 証券外務員 (一種・二種)

## 概要
証券外務員は、証券会社や銀行などの金融機関で、株式、債券、投資信託などの金融商品の勧誘・販売を行うために必要な資格です。
金融商品取引法に基づき、外務員として活動するには、この資格を取得し、日本証券業協会に登録する必要があります。
金融機関への就職・転職を目指す人にとって必須の資格です。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 二種: 120分、一種: 160分 |
| 問題数 | 二種: 70問、一種: 100問 |
| 合格ライン | 70%以上（二種: 210/300点、一種: 308/440点） |
| 受験料 | 13,860円（税込） |
| 受験資格 | なし（誰でも受験可能） |
| 試験方式 | CBT（プロメトリック テストセンター） |

## 種類と範囲
- **二種外務員**:
    - 現物株式、公社債、投資信託などの一般的な金融商品を取り扱えます。
    - 信用取引やデリバティブ（先物・オプション）は扱えません。
- **一種外務員**:
    - 二種の範囲に加え、デリバティブ取引や信用取引など、すべての有価証券関連業務を行えます。
    - 現在は、いきなり一種から受験することも可能です。

## 難易度・勉強時間目安
- **二種**:
    - 難易度: 初級（合格率 60～70%）
    - 勉強時間: 40 ～ 80 時間
- **一種**:
    - 難易度: 初級～中級（合格率 50～60%）
    - 勉強時間: 80 ～ 120 時間
