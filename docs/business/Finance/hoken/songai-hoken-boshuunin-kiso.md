# 損害保険募集人 基礎単位

## 概要
損害保険募集人資格は、損害保険（自動車保険、火災保険など）の代理店業務を行うために必要な資格です。
「基礎単位」はすべての募集人が取得必須の共通科目であり、これに加えて取り扱う商品に応じた「商品単位（自動車、火災、傷害疾病）」を取得します。
基礎単位に合格しないと、代理店登録や募集人届出ができません。

## 試験詳細
試験はCBT（コンピュータ試験）方式で実施されます。

| 項目 | 内容 |
| --- | --- |
| **試験日程** | 随時（代理店試験として実施） |
| **試験時間** | 40分 (基礎単位) |
| **問題数** | 50問 (基礎単位) |
| **合格ライン** | 70点以上 / 100点満点 |
| **受験料** | 会社・代理店負担が一般的 |
| **受験資格** | 損害保険会社または代理店に所属予定の者 |

## 出題範囲 (基礎単位)
- 損害保険の基礎用語
- 代理店の役割と責任
- コンプライアンス（保険業法など）
- 契約手続きの基本ルール

## 難易度・勉強時間目安
- **難易度**: 低 (合格率 90%以上)
    - 業界内では非常に易しい試験とされており、常識的な問題も多いです。
    - テキスト持ち込み不可ですが、しっかり読めば問題ありません。
- **勉強時間**: 5 ～ 10 時間程度
    - 配布されるテキストを一通り読み、模擬問題を解けば合格できます。
