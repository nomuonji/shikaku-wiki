# 生命保険募集人 一般課程試験

## 概要
生命保険募集人一般課程試験は、生命保険の販売（募集）を行うために必須となる基礎資格です。
生命保険会社や代理店で働く場合、まずこの試験に合格して金融庁への登録を行う必要があります。
コンプライアンスや保険の基礎知識、実務ルールを習得していることを証明します。

## 試験詳細
試験はCBT（コンピュータ試験）方式で実施されます。

| 項目 | 内容 |
| --- | --- |
| **試験日程** | 随時（所属会社を通じて申し込み） |
| **試験時間** | 40分 |
| **問題数** | 正誤問題・選択問題など |
| **合格ライン** | 70点以上 / 100点満点 |
| **受験料** | 所属会社により異なる（会社負担の場合が多い） |
| **受験資格** | 生命保険会社または代理店に所属予定の者 |

## 出題範囲
- 生命保険の現状と役割
- 契約の募集から成立までの実務
- コンプライアンス（法令遵守）
- 保険と税金、相続の基礎知識
- 顧客ニーズへの対応

## 難易度・勉強時間目安
- **難易度**: 低 (合格率 80%程度)
    - 落とすための試験ではなく、業務に必要な最低限の知識を確認する試験です。
    - 業界内では「合格して当たり前」と見なされることが多いです。
- **勉強時間**: 10 ～ 20 時間程度
    - 会社から配布されるテキストと問題集を数回繰り返せば合格可能です。
