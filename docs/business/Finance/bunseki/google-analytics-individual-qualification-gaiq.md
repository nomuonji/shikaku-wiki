# Google アナリティクス個人認定資格 (GAIQ)

## 概要
Google アナリティクス個人認定資格（GAIQ: Google Analytics Individual Qualification）は、Googleが提供するアクセス解析ツール「Google アナリティクス 4 (GA4)」の習熟度を証明する公式認定資格です。
Webマーケティング担当者やデータアナリストにとって必須の知識とされており、Google公認のスキル証明として履歴書にも記載可能です。

## 試験詳細
試験はGoogleの学習プラットフォーム「スキルショップ」上で、オンラインかつ無料で受験可能です。

| 項目 | 内容 |
| --- | --- |
| **試験日程** | 随時（オンラインで24時間いつでも受験可能） |
| **試験時間** | 75分 |
| **問題数** | 50問（選択式） |
| **合格ライン** | 正答率 80%以上（40問以上正解） |
| **受験料** | 無料 |
| **受験資格** | なし（誰でも受験可能） |
| **有効期限** | 合格から12ヶ月（更新には再受験が必要） |
| **再受験** | 不合格の場合、24時間後に再受験可能 |

## 出題範囲
主に以下のGA4に関する知識が問われます。
- Google アナリティクスの設定と構成
- データの収集と処理
- レポートの作成と分析
- コンバージョンとアトリビューション
- 広告との連携

## 難易度・勉強時間目安
- **難易度**: 初級 ～ 中級
    - Google アナリティクスの基本操作や用語を理解していれば合格可能です。
    - 試験中も資料の閲覧が可能ですが、制限時間があるため基礎知識は必須です。
- **勉強時間**: 20 ～ 40 時間程度
    - 初心者の場合、公式の学習コースを一通り受講するのに必要な時間です。
    - 実務経験者は数時間の確認で合格できる場合もあります。
