# 住宅ローンアドバイザー

## 概要
住宅ローンアドバイザーは、顧客にとって最適な住宅ローン選びをサポートするための専門知識を認定する資格です。
金融機関の担当者だけでなく、不動産会社の営業担当者やファイナンシャルプランナーなどが、顧客への提案力を高めるために取得します。
主に「住宅金融普及協会」が実施するものが有名です。

## 試験詳細
一般的に「養成講座」を受講し、その後の「効果測定（試験）」に合格することで取得できます。

| 項目 | 内容 |
| --- | --- |
| **実施団体** | 一般財団法人 住宅金融普及協会 など |
| **試験日程** | 年数回（養成講座の日程による） |
| **試験方式** | 会場試験（マークシート方式） または Web講習・試験 |
| **合格ライン** | 正答率 60% ～ 70%程度 |
| **受験料** | 養成講座受講料込で 25,000円 ～ 30,000円程度 |

## 出題範囲
- 住宅ローンの基礎知識（金利タイプ、返済方法）
- 住宅ローンの商品知識（フラット35、民間ローン）
- 資金計画の作成
- コンプライアンスと説明義務

## 難易度・勉強時間目安
- **難易度**: 低 (合格率 80%以上 ※養成講座ルート)
    - 養成講座をしっかり受講すれば、ほぼ合格できるレベルです。
    - 落とす試験ではなく、知識を認定するための試験です。
- **勉強時間**: 講座受講時間 ＋ 復習数時間
    - 事前の独学はあまり必要なく、講座の内容を理解することが重要です。
