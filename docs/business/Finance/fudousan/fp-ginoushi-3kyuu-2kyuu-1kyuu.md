# ファイナンシャル・プランニング技能士（FP）1級・2級・3級

## 概要

ファイナンシャル・プランニング技能検定は、職業能力開発促進法に基づく**国家検定**です。

合格した級に応じて「1級・2級・3級ファイナンシャル・プランニング技能士」と名乗ることができます。

家計、年金、保険、金融商品、不動産、税金、相続・事業承継など、個人・家庭のお金に関する6分野を横断します。

試験は**日本FP協会**と**金融財政事情研究会（きんざい）**の2団体が実施します。実技試験の選択科目などには違いがありますが、取得するFP技能士は同じ国家資格です。

## 2級・3級はCBT

2026年度の2級・3級FP技能検定は、両実施団体とも**CBT方式**です。

### 2級

| 項目 | 内容 |
| --- | --- |
| 学科 | 120分 |
| 実技 | 90分 |
| 学科受検料 | 5,700円 |
| 実技受検料 | 6,000円 |
| 学科 + 実技 | 11,700円 |

2級には受検資格があります。代表例は、3級FP技能検定の合格者、FP業務で所定の実務経験がある人、AFP認定研修を修了した人などです。

### 3級

| 項目 | 内容 |
| --- | --- |
| 学科 | 90分 |
| 実技 | 60分 |
| 学科受検料 | 4,000円 |
| 実技受検料 | 4,000円 |
| 学科 + 実技 | 8,000円 |

3級はFPを初めて体系的に学ぶ人の入口として利用されます。

CBTは年間を通じた実施期間の中から会場・日時を予約しますが、年度ごとに休止期間があります。

## 1級

1級は学科と実技の制度が2級・3級より複雑です。

### きんざい 1級学科

- 紙方式
- 基礎編150分 + 応用編150分
- 受検手数料：8,900円
- 2026年度は5月24日・9月13日などに実施

### 日本FP協会 1級実技

日本FP協会は、1級の**実技試験「資産設計提案業務」**を実施しています。

2026年9月試験は次の内容です。

| 項目 | 内容 |
| --- | --- |
| 試験日 | 2026年9月13日 |
| 試験時間 | 120分 |
| 出題 | 2題・20問 |
| 合格基準 | 100点満点中60点以上 |
| 受検料 | 20,000円 |

きんざいにも1級実技試験があり、実施方式・手数料が異なります。どのルートで1級を取得するかは、各実施団体の要綱を確認してください。

## 学習範囲・6分野

FP技能検定では、主に次の6分野を学びます。

1. ライフプランニングと資金計画
2. リスク管理
3. 金融資産運用
4. タックスプランニング
5. 不動産
6. 相続・事業承継

級が上がるほど、制度知識だけでなく、複数制度を組み合わせた判断や計算、顧客条件に応じた提案力が求められます。

## 合格基準

2級・3級では、学科・実技それぞれに合格基準があります。

一方の科目だけ合格した場合に科目合格として扱われる制度があり、所定期間内にもう一方へ合格することで級の合格につながります。

細かな有効期限・免除条件は、受検する団体の最新要綱を確認してください。

## 難易度・勉強時間目安

実施団体は一律の標準勉強時間を公表していません。

- 3級：6分野の基本用語と制度の全体像
- 2級：制度の詳細、計算、実務に近い判断
- 1級：複合的な資産設計・高度な計算・提案

という順に要求水準が上がります。

勉強時間を固定するより、過去問・CBT問題演習で6分野それぞれの正答率を確認し、弱点分野を補う方が合理的です。

## 「FP」と「AFP / CFP」の違い

FP技能士は国家検定です。

一方、AFP・CFP®は日本FP協会が認定する民間資格です。制度上は別資格なので、「FP2級 = AFP」ではありません。2級合格がAFP認定要件の一部と関係する場合がありますが、研修・登録など別の要件があります。
