# CFA (Chartered Financial Analyst)

## 概要
CFA（Chartered Financial Analyst：CFA協会認定証券アナリスト）は、米国CFA協会が認定する国際的な金融資格です。
証券分析、投資運用、企業財務などの分野で世界的に高い評価を得ており、金融業界の「ゴールド・スタンダード」とも呼ばれます。
試験はすべて英語で行われるため、高度な金融知識に加えて英語力も必須です。

## 試験詳細
Level I、Level II、Level IIIの3段階の試験に順に合格し、かつ4年以上の実務経験を有することでCFAチャーターホルダー（正会員）として認定されます。

| 項目 | 内容 |
| --- | --- |
| **試験日程** | Level I: 年4回 (2, 5, 8, 11月)<br>Level II: 年3回 (5, 8, 11月)<br>Level III: 年2回 (2, 8月) |
| **試験方式** | CBT（コンピュータ試験） |
| **試験時間** | 各レベル 約4.5時間（休憩含む） |
| **受験料** | 登録料 $350 + 受験料 $940～$1,250 (申込時期による) |
| **受験資格** | 学士号取得者（または見込み）、または相応の実務経験 |

## 出題範囲
以下のトピックが全レベルを通じて出題されます（ウェイトはレベルにより異なる）。
- Ethical and Professional Standards (倫理・職務基準)
- Quantitative Methods (計量分析)
- Economics (経済学)
- Financial Statement Analysis (財務諸表分析)
- Corporate Issuers (企業発行体)
- Equity Investments (株式投資)
- Fixed Income (債券投資)
- Derivatives (デリバティブ)
- Alternative Investments (オルタナティブ投資)
- Portfolio Management and Wealth Planning (ポートフォリオ管理)

## 難易度・勉強時間目安
- **難易度**: 超難関 (合格率 Level I: 40%台, Level II: 40-50%台, Level III: 45-50%程度)
    - 日本人にとっては「英語の壁」と「金融の専門性」の二重のハードルがあります。
    - 日本証券アナリスト(CMA)よりも格段に難しいとされます。
- **勉強時間**: 各レベル 300時間以上 (合計 1,000時間以上)
    - 多くの受験者は各レベルの合格に半年以上の準備期間を費やします。
    - 英語が母国語でない場合、さらに多くの時間が必要です。
