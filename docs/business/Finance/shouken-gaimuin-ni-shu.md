# 証券外務員二種

## 概要
証券外務員二種（二種外務員資格）は、証券会社や銀行などで金融商品（株式、国債、投資信託など）の販売・勧誘を行うために必須の資格です。
一種外務員とは異なり、信用取引やデリバティブ取引など一部のリスク商品は扱えませんが、現物株式や投資信託などの一般的な商品は扱えます。
金融機関への就職・転職を目指す人にとっての登竜門的資格です。

## 試験詳細
日本証券業協会が主催しており、CBT方式で実施されています。誰でも受験可能です。

| 項目 | 内容 |
| --- | --- |
| **試験日程** | 平日毎日（各テストセンターで実施） |
| **試験時間** | 120分 |
| **問題数** | 70問（○×方式50問、五肢選択方式20問） |
| **合格ライン** | 210点以上 / 300点満点 (70%) |
| **受験料** | 13,860円（税込） |
| **受験資格** | なし（誰でも受験可能） |

## 出題範囲
- 法令・諸規則（金融商品取引法、協会定款など）
- 商品業務（株式、債券、投資信託業務）
- 関連科目（証券市場の基礎、経済・金融・財政の常識、財務諸表など）

## 難易度・勉強時間目安
- **難易度**: 低 ～ 中 (合格率 65% ～ 70%程度)
    - 金融系の資格としては入門レベルですが、専門用語が多いため初学者は戸惑うかもしれません。
    - 計算問題も出ますが、パターンは決まっています。
- **勉強時間**: 50 ～ 80 時間程度
    - 1ヶ月程度の学習期間が目安です。
    - 市販のテキストと問題集を繰り返し解くことが合格への近道です。
