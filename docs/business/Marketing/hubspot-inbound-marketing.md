# HubSpot Inbound Marketing

## 概要

HubSpot Academy の **Inbound Certification Course** は、顧客を「集める → 関係を築く → 満足につなげる」というインバウンドの考え方を体系的に学ぶ無料の認定コースです。ファネルだけでなく、顧客中心の **flywheel（フライホイール）**、buyer persona、buyer journey まで扱います。

## 2026年9月時点の公式コース構成

| 項目 | 公式情報 |
| --- | --- |
| 受講料 | 無料 |
| 認定 | 1 Certification |
| Lessons | 7 |
| Videos | 15 |
| Quizzes | 4 |
| 学習時間 | 2時間45分 |
| 日本語 | 対応あり |

HubSpot Academy の公式ページでは、対象者としてインバウンド担当者、小規模事業者、マーケティング・営業チームなどを挙げています。

## 学べること

公式カリキュラムの中心は次の3点です。

- 顧客中心のインバウンド戦略を組み立てる
- フライホイールモデルを使って成長の仕組みを考える
- buyer persona と buyer journey を整理し、コンテンツや集客施策につなげる

「HubSpotの操作方法だけを覚える資格」ではなく、マーケティング・営業・サービスをまたいだインバウンドの基本思想を学ぶコースとして位置づける方が正確です。

## 似たHubSpot認定との違い

HubSpot Academy には別に **Inbound Marketing Optimization Certification** があります。こちらは既に顧客中心のマーケティング基盤を持つ人向けに、データを使った改善や施策最適化を深掘りする上位寄りの内容です。

初めてインバウンドを学ぶなら、まず Inbound Certification Course を先に見る方が構成を理解しやすいです。
