# リテールマーケティング（販売士）検定

## どの級を選ぶか

販売士は、小売の売場づくりから店舗運営、企業経営までを段階的に学ぶ日本商工会議所の検定です。3級は販売担当者として接客や売場づくりの基本を身につけたい人、2級は販売促進を企画し売場・店舗の管理を担う人、1級は商品計画や財務を含む経営判断に関わる人に対応します。小売業だけの資格と思われがちですが、日本商工会議所は卸売、製造、サービス業の販売担当者や、これから流通業界を目指す人も対象に挙げています。

級選びは肩書きより、現場で担当する仕事から考えると分かりやすくなります。接客や商品説明を担当するなら3級、売場の数字と人員を見て販促を回すなら2級、複数の売場や事業の計画を考えるなら1級が候補です。上の級ほど、知識の暗記だけでなく、店舗や企業全体を見た判断が求められます。

## 2026年度の受験と制度変更

2026年9月24日に日本商工会議所の案内を確認したところ、個人受験はCBT方式で、試験会場と空き日時を申込ページから選ぶ方式です。会場へ直接申し込む方法も案内されています。統一日程の年2回試験ではないため、希望日に空席があるかは予約ページで確認してください。団体受験や養成講習会には別の申込手続きがあります。

### 科目体系の段階的移行（2027〜2029年度）

日本商工会議所は2026年2月3日に、科目体系を現行5科目から新4科目へ整理・再編し、2027年度以降段階的に移行すると発表しました（[公式発表](https://www.kentei.ne.jp/50119)）。

新試験は級ごとに異なる年度から始まります。新ハンドブックは各級の新試験開始の1年前に発刊予定です。

| 級 | 新ハンドブック発刊年度 | 新体系試験開始年度 |
| --- | --- | --- |
| 3級 | 2026年度 | 2027年度 |
| 2級 | 2027年度 | 2028年度 |
| 1級 | 2028年度 | 2029年度 |

月単位の切替日は公式で級ごとに明示されている場合のみ確認してください。現行試験は各級の新体系開始まで継続します。

### 現行5科目から新4科目への対応

全級で科目数と名称が次のように再編されます。

| 現行科目 | 新科目 |
| --- | --- |
| ①小売業の類型 | ①流通概論 |
| ②マーチャンダイジング ＋ ③ストアオペレーション | ③マーチャンダイジング |
| ④マーケティング | ②マーケティング |
| ⑤販売・経営管理 | ④リテールマネジメント |

試験方式（CBT）、試験時間（1級90分、2級70分、3級60分）、合格基準（2・3級は平均70点以上かつ各科目50点以上、1級は各科目70点以上）に変更はありません。満点は500点から400点へ変わり、1科目あたりの問題数・配点も調整されますが、総問題数は100問のままです。

### 1級科目合格の移行条件

1級の科目合格制度について、新科目「マーチャンダイジング」の免除を受けるには、旧試験で「マーチャンダイジング」と「ストアオペレーション」の**両方**に科目合格していることが必要です（公式発表の適用範囲：2028年4月〜2029年6月の期間内の合格）。どちらか一方だけでは新科目の免除は適用されません。その他の科目は対応する新科目で免除が適用されます。

### 教材の選び方

- 2026年度中に3級を受験する、または現行体系で学習を始める場合は現行ハンドブックを使用。
- 3級を2027年度以降に受験する場合は2026年度発刊予定の新ハンドブックを待つ。
- 2級は2027年度以降の新試験に備えるなら2027年度発刊の新ハンドブック、それ以前は現行版。
- 1級は2028年度以降の新試験向けに2028年度発刊の新ハンドブックを確認。

受験級と予定年度を決めたうえで、表紙・発行元で現行版か新体系対応版かを確認してください。公式最新要項を優先します。

## 学習範囲の見取り図

現行試験では、小売業の類型、マーチャンダイジング、ストアオペレーション、マーケティング、販売・経営管理などを学びます。科目名を並べて覚えるより、次のように店舗の仕事へ結びつけると理解が進みます。

- どの商圏・店舗形態で誰に売るのか
- 何を仕入れ、在庫と価格をどう管理するのか
- 商品をどう陳列し、接客と販促をどう運用するのか
- 売上や利益、人員、法令順守をどう確認するのか

公式ページには級ごとの学習方法、サンプル問題、受験者データが掲載されています。勉強時間や合格率を一律に当てはめるより、直近のサンプル問題を解き、現場経験で分かる領域と用語から学び直す領域を分ける方が計画を立てやすくなります。

## 申し込み前の確認

### 2級の受験料

2026年9月28日に日本商工会議所の2級案内を確認した時点では、**2級の受験料は6,600円（税込）**、これとは別に**事務手数料550円（税込）**が必要です。

| 区分 | 金額 |
| --- | ---: |
| 2級受験料 | 6,600円（税込） |
| 事務手数料 | 550円（税込） |

この記事では、本Issueで公式確認していない1級・3級の料金を推測して埋めません。料金は改定される場合があるため、申込時は[日本商工会議所の2級案内](https://www.kentei.ne.jp/retailsales/class2)と[CBT申込ページ](https://cbt-s.com/examinee/examination/jcci_retailsales)の表示を優先してください。

試験時間、合格基準、免除制度も級や年度の案内に従います。科目体系の段階的移行が近いため、受験時期が変更後になる人は、現行版教材で学習を始める前に自分の級の切替年度と対応教材を確認してください。
