# Yahoo!広告 認定資格（検索）は今どう受ける？

**2026年10月20日確認：旧「Yahoo!広告」の検索広告認定資格を探しているなら、現在は「LINEヤフーマーケティングスキルバッジ」の「LINEヤフー広告 検索広告 Basic / Advanced」を確認してください。** 旧名称のまま試験を探すと、現行のコース名と一致しません。

LINEヤフーマーケティングキャンパスは**2026年5月28日**から、従来の「Yahoo!広告」などの学習・認定コースを「LINEヤフー広告」などのコースに変更しています。旧資格を保有する人の資格移行や有効性については、旧名称だけから自動移行・失効を断定できません。個別の認定証の期限や公式窓口で確認してください。

## BasicとAdvanced：どちらから受ける？

| 比較 | 検索広告 Basic | 検索広告 Advanced |
| --- | --- | --- |
| 何を証明する？ | 検索広告の基礎的な知識 | 検索広告の効果を高める機能・運用の知識 |
| 向いている人 | 初めて検索広告を学ぶ人、基礎を確認したい人 | 基礎を取得し、運用知識を深めたい人 |
| 受験の前提 | Advancedに必要な最初の資格 | **検索広告 Basic の取得が必要** |
| 試験時間 | 50分 | 50分 |
| 受験料 | 無料 | 無料 |

検索広告の資格を取りたい場合は、**検索広告Basic → 検索広告Advanced**の順です。「LINE公式アカウントBasic」や「ディスプレイ広告Basic」とは別コースなので、コース名の「検索広告」を確認してください。公式の[資格一覧・試験条件](https://www.lycbiz.com/jp/support/lineyahoo-marketing-skill-badge/)に両方掲載されています。

## 試験・更新・再受験の条件

| 項目 | 2026年10月20日時点の公式案内 |
| --- | --- |
| 学習・受験・認定バッジ取得 | いずれも無料 |
| 受験場所 | オンライン。ビジネスIDでログインし、プロフィールを登録 |
| 学習コースの受講 | 任意。試験だけ受けることも可能 |
| 試験時間 | 各50分 |
| 不合格の場合 | 前回の受験から24時間後に再受験可能 |
| 資格の有効期間 | **合格日から1年間** |
| 更新 | **合格後180日を経過すると更新テストを受けられる** |

合格後はマイページで認定証・認定バッジを確認できます。更新可能な時期と有効期限は異なります。「1年間有効」だからといって、合格後いつでも更新テストを受けられるわけではありません。具体的な手順は[公式受験マニュアル](https://www.lycbiz.com/jp/manual/lymskillbadge/examination/)で確認してください。

## 受験までの手順

1. [LINEヤフーマーケティングスキルバッジ公式案内](https://www.lycbiz.com/jp/support/lineyahoo-marketing-skill-badge/)を開き、「資格の取得はこちら」からLINEヤフーマーケティングキャンパスへ進みます。
2. ビジネスIDでログインし、**「LINEヤフー広告 検索広告Basic」**を選択します。Advancedを希望する場合も、先にBasicを取得します。
3. 必要に応じて無料の学習コンテンツを読みます。学習コースの受講自体は必須ではありません。
4. プロフィールに認定証へ印字する正式な氏名を登録し、試験ポリシーを確認して受験します。
5. 合格後はマイページで認定証を確認し、有効期限を記録しておきます。不合格なら24時間経過後に再受験できます。

## 学ぶ内容と仕事での使い方

Basicは検索広告の基本知識を整理する入口です。すでに検索広告の設定・運用に携わる人も、公式教材で用語や機能を確認できます。Advancedは検索広告の効果改善に必要な機能・運用知識を扱います。両者は**別々の認定試験**で、Advancedに進むためには検索広告Basicの取得が必要です。

この資格はLINEヤフー社が**個人の知識レベル**を認定するものです。法人の公認、広告成果、就職・転職の成功、特定の運用成績を保証する資格ではありません。公式も、認定バッジを使って企業自体が公認されたと誤認させる表記を認めていません。

公式の合格率・必要勉強時間・合格点を確認できないため、このページでは根拠のない難易度ランクや「何時間で合格」といった数値は掲載しません。受験前には最新のコース内容と試験ポリシーを確認してください。
