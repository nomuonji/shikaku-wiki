# SEO検定 2級

## 先に確認したい試験仕様

SEO検定2級は、全日本SEO協会が実施するSEOの検定です。コンテンツ、外部リンク、アクセス解析などを含む2級以下の公式テキスト範囲から出題されます。

2026年9月28日に公式案内を確認した内容は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| **受験資格** | 学歴・職歴・年齢・国籍などの制限なし |
| **出題形式** | 選択式80問 |
| **試験時間** | 60分 |
| **合格基準** | 得点率80%以上 |
| **会場受験料** | 7,000円（税別）/ 1回 |
| **オンライン受験料** | 9,000円（税別）/ 1回 |
| **受験方式** | 会場受験とオンライン受験の案内あり |

会場とオンラインでは、日程・申込方法・料金が同一ではありません。受験する回の条件は、[SEO検定2級の試験概要](https://www.ajsa.or.jp/kentei/seo/2nd/test.html)と[試験日程](https://www.ajsa.or.jp/kentei/seo/schedule/)で確認してください。

## 出題範囲

公式案内では、2025年以降の2級試験は「SEO検定2級・3級・4級 公式テキスト2025・2026年版」の全章・全ページが対象とされています。古い版の教材を使う場合は、現在の対象版と一致するか確認してください。

2級の学習テーマには、たとえば次の内容が含まれます。

- コンテンツ資産の構築
- 外部リンク対策
- トラフィック要因
- ソーシャルメディア対策
- アクセス解析や競合調査

詳細な章立ては[2級公式テキスト案内](https://www.ajsa.or.jp/kentei/seo/2nd/textbook.html)で確認できます。

## 合格率・難易度・勉強時間の扱い

この記事では、以前掲載していた「合格率71%（2024年）」「2021年以降は難化傾向」「勉強時間30〜50時間」という数値・傾向を削除しました。記事内で対象年度と一次情報を確認できなかったためです。

公式サイトには[合格率ページ](https://www.ajsa.or.jp/kentei/seo/goukakuritu.html)があります。合格率を見る場合は、**級と年度が一致する行**を確認してください。過去年度の率を現在の受験者にそのまま当てはめることはできません。

勉強時間も一律の公式基準はありません。まず公式テキストと問題集の範囲を確認し、既知の分野と未学習の分野を分けて計画するほうが実用的です。

## 2級が候補になる人

- SEOを体系的に学び直したい
- コンテンツ改善、アクセス解析、外部施策を一通り整理したい
- 4級・3級相当の基礎を踏まえて、より広い実務テーマを学びたい

資格取得そのものが検索順位や採用・受注を保証するわけではありません。実務で使う場合は、検索課題、仮説、変更内容、検証指標まで説明できる改善事例と組み合わせると、学習内容を示しやすくなります。
