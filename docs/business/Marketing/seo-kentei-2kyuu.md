# SEO検定 2級

## 概要
SEO検定2級は、全日本SEO協会が実施するSEO（検索エンジン最適化）の応用知識を評価する資格です。
コンテンツ資産の構築、外部リンク対策、アクセス解析など、現場のSEO担当者に必要な実践的スキルを学びます。
検索で見つけてもらうための基本を理解し、記事の改善方法が分かります。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| **試験日程** | 毎月実施（会場試験） |
| **試験方式** | 会場試験（選択式・筆記） |
| **試験時間** | 60分 |
| **問題数** | 80問 |
| **合格基準** | 80点以上 / 100点満点 |
| **受験資格** | なし |

## 出題範囲
- コンテンツ資産の構築
- 外部リンク対策
- トラフィック要因の重要性
- ソーシャルメディア対策
- アクセス解析と競合調査
- 4級・3級の内容も約2割含む

## 難易度・合格率
- **難易度**: 普通～やや易しい
- **合格率**: 71%（2024年）
  - 全級平均: 69%
  - 2021年以降、難易度が上昇傾向
- **勉強時間**: 30～50時間程度
