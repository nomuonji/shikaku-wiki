# SEO検定 2級

## 概要
SEO検定2級は、全日本SEO協会が実施するSEO（検索エンジン最適化）の応用知識を評価する資格です。
コンテンツ資産の構築、外部リンク対策、アクセス解析など、現場のSEO担当者に必要な実践的スキルを学びます。
検索で見つけてもらうための基本を理解し、記事の改善方法が分かります。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| **試験日程** | 毎月実施（会場試験） |
| **試験方式** | 会場試験（選択式・筆記） |
| **試験時間** | 60分 |
| **問題数** | 80問 |
| **合格基準** | 80点以上 / 100点満点 |
| **受験資格** | なし |

## 出題範囲
- コンテンツ資産の構築
- 外部リンク対策
- トラフィック要因の重要性
- ソーシャルメディア対策
- アクセス解析と競合調査
- 4級・3級の内容も約2割含む

## 難易度・合格率
- **難易度**: 普通～やや易しい
- **合格率**: 71%（2024年）
  - 全級平均: 69%
  - 2021年以降、難易度が上昇傾向
- **勉強時間**: 30～50時間程度

## 公式情報
- [全日本SEO協会](https://www.ajsa.or.jp/kentei/)
## 受験前に押さえたい試験仕様
全日本SEO協会の2025・2026年版案内では、2級は選択式80問、試験時間60分、合格基準は得点率80％以上です。試験は会場方式に加え、オンライン方式も案内されています。オンラインは実施日・受付期限が開催回ごとに決まるため、「毎月同じ条件」と考えず、申込画面で2級の回を選び直してください。協会は公式テキストの版により範囲を切り替える場合があり、過去版の教材だけで学ぶと対象外・改訂箇所を見落とすおそれがあります。

## 2級を選ぶ人、上位級を選ぶ人
SEO業務の担当になったばかりで、検索意図やページ改善の判断を一通り学びたい人には2級が候補です。すでに内部施策の実務を行い、より具体的な分析や改善手順を掘り下げたい人は1級の出題範囲と比べてください。資格は特定企業の採用・受注を保証するものではありません。学習成果を示すなら、検索課題、仮説、変更内容、検証指標をまとめた改善事例と組み合わせると、知識をどう使えるか伝わります。

費用・開催日・教材の版は変更されるため、[SEO検定2級の試験概要](https://www.ajsa.or.jp/kentei/seo/2nd/test.html)と[試験日程](https://www.ajsa.or.jp/kentei/seo/schedule/)で確認してください。確認日: 2026-09-24。
