# メンタルヘルス・マネジメント検定 II種 (ラインケアコース)

## 概要
メンタルヘルス・マネジメント検定 II種（ラインケアコース）は、管理監督者（課長、部長、リーダーなど）を対象とした資格です。
大阪商工会議所が主催しています。
部下が不調に陥らないよう配慮したり、不調が見受けられる部下に適切な対応を行ったりするための知識と技術を習得します。
職場環境の改善や、社内外の資源との連携など、組織的なメンタルヘルス対策のキーマンとしての役割が求められます。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 120分 |
| 問題数 | 50問（マークシート方式 4択） |
| 合格ライン | 100点満点中70点以上 |
| 受験料 | 7,480円（税込） |
| 受験資格 | なし（誰でも受験可能） |
| 有効期限 | なし（永久資格） |
| 試験方式 | マークシート方式 |

## 学習範囲・シラバス
公式テキストに準拠した以下の内容から出題されます。

1.  **メンタルヘルスケアの意義と管理監督者の役割**: 労働者のストレス状況、企業の社会的責任
2.  **ストレスおよびメンタルヘルスに関する基礎知識**: ストレスのメカニズム、心の健康問題
3.  **職場環境等の評価および改善の方法**: ストレスチェック制度、職場環境改善の進め方
4.  **個々の労働者への配慮**: いつもと違う様子の把握、声かけ
5.  **労働者からの相談への対応**: 傾聴、情報の提供、助言
6.  **社内外資源との連携**: 産業医、衛生管理者、外部相談機関との連携
7.  **心の健康問題をもつ復職者への支援の方法**: 休業中のケア、復職プログラム、職場復帰後のフォロー

## 難易度・勉強時間目安
- **難易度**: 中級
    - 合格率は50%〜60%程度です。
    - 管理職としての視点が求められ、法令や制度に関する知識も必要です。
- **勉強時間**:
    - 30〜50時間程度
    - 公式テキストを読み込み、過去問題を繰り返し解くことが合格への近道です。
