# メンタルヘルス・マネジメント検定 III種 (セルフケアコース)

## 概要
メンタルヘルス・マネジメント検定 III種（セルフケアコース）は、一般社員を対象とした資格です。
大阪商工会議所が主催しています。
自らのストレスの状況・状態を把握することにより、不調に早期に気づき、自らケアを行ったり、必要であれば助けを求めたりするための知識と技術を習得します。
心の健康管理の重要性を理解し、仕事や日常生活でのストレス対処能力（セルフケア）を高めることを目的としています。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 120分 |
| 問題数 | 50問（マークシート方式 4択） |
| 合格ライン | 100点満点中70点以上 |
| 受験料 | 5,280円（税込） |
| 受験資格 | なし（誰でも受験可能） |
| 有効期限 | なし（永久資格） |
| 試験方式 | マークシート方式 |

## 学習範囲・シラバス
公式テキストに準拠した以下の内容から出題されます。

1.  **メンタルヘルスケアの意義**: ストレス社会の現状、メンタルヘルス対策の重要性
2.  **ストレスおよびメンタルヘルスに関する基礎知識**: ストレスの仕組み、心身の反応、代表的な心の病気
3.  **セルフケアの重要性**: ストレスへの気づき、対処法
4.  **ストレスへの気づき方**: 身体的・心理的・行動的サイン
5.  **ストレスへの対処、軽減の方法**: リラクセーション技法、睡眠、運動、食事、相談

## 難易度・勉強時間目安
- **難易度**: 初級
    - 合格率は70%〜80%程度と高く、比較的取得しやすい資格です。
    - 初めてメンタルヘルスを学ぶ人でも、テキストをしっかり読めば合格可能です。
- **勉強時間**:
    - 10〜30時間程度
    - 短期間の学習で合格を目指せます。
