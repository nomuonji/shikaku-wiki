# サービス介助士

## 概要
サービス介助士（ケアフィッター）は、高齢者や身体の不自由な人が安心して社会参加できるように、おもてなしの心と正しい介助技術を身につけるための民間資格です。
公益財団法人日本ケアフィット共育機構が認定しています。
鉄道、航空、百貨店、金融機関、ホテルなど、サービス業を中心に多くの企業で導入されています。
「おもてなしの心」と「介助技術」の両方を学ぶことで、相手の立場に立った適切なサポートができるようになります。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 実技教習（2日間）の最後に実施される筆記試験（50分程度） |
| 問題数 | 50問（マークシート方式 3択） |
| 合格ライン | 100点満点中70点以上 |
| 受験料 | 41,800円（税込） ※受講料・教材費・検定料含む |
| 受験資格 | なし（誰でも受講可能） |
| 有効期限 | 3年間（更新にはセミナー受講やレポート提出などが必要） |
| 試験方式 | 通信講座＋実技教習（2日間）＋筆記試験 |

## 学習範囲・シラバス
資格取得までの流れは以下の通りです。

1.  **自宅学習（通信講座）**
    - テキスト学習：高齢者や障害者の理解、関連法規、介助の知識
    - 課題提出：提出課題（100問）で60点以上合格が必要
2.  **実技教習（2日間）**
    - 車いすの操作・介助（段差、坂道など）
    - 視覚障害者の手引き（誘導）
    - 聴覚障害者とのコミュニケーション
    - 高齢者疑似体験
    - ディスカッション・グループワーク
3.  **検定試験**
    - 実技教習の最後に実施される筆記試験に合格すると認定

## 難易度・勉強時間目安
- **難易度**: 初級
    - 合格率は80%以上と高く、講習をしっかり受けていれば合格できるレベルです。
    - 落とすための試験ではなく、正しい知識と技術を身につけることが目的です。
- **勉強時間**:
    - 自宅学習：1〜2ヶ月程度
    - 実技教習：2日間（連続または別日程で受講）
