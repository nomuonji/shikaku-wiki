# 第一種衛生管理者

## 概要
第一種衛生管理者は、労働安全衛生法に基づく国家資格です。
常時50人以上の労働者を使用する事業場では、衛生管理者を選任する義務があります。
「第一種」は、有害業務を含むすべての業種（建設業、製造業、運送業、医療業など）で衛生管理者として選任可能です（第二種は有害業務を含まない業種のみ）。

## 試験詳細
公益財団法人 安全衛生技術試験協会が実施しています。

| 項目 | 内容 |
| --- | --- |
| **試験日程** | 全国7箇所のセンターで毎月数回実施（出張試験もあり） |
| **試験時間** | 3時間 |
| **問題数** | 44問（五肢択一式） |
| **合格ライン** | 科目ごとに40%以上、かつ全体で60%以上 |
| **受験料** | 8,800円（非課税） |
| **受験資格** | 大学・短大卒＋実務経験1年以上、高卒＋実務経験3年以上 など |

## 出題範囲
1. **関係法令 (有害業務に係るもの)**: 10問
2. **労働衛生 (有害業務に係るもの)**: 10問
3. **関係法令 (有害業務以外)**: 7問
4. **労働衛生 (有害業務以外)**: 7問
5. **労働生理**: 10問

※第二種との違いは、1と2の「有害業務」に関する科目が追加されている点です。

## 難易度・勉強時間目安
- **難易度**: 中 (合格率 45% ～ 50%程度)
    - 国家資格の中では比較的取得しやすい部類ですが、有害業務（化学物質、粉じんなど）の専門知識が必要なため、第二種よりは難易度が高いです。
    - 近年、問題が長文化・複雑化する傾向にあります。
- **勉強時間**: 50 ～ 100 時間程度
    - 過去問の類似問題が多く出題されるため、過去問演習が非常に有効です。
    - 1日1時間の勉強で2～3ヶ月程度が目安です。
