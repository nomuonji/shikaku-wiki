# CFP (Certified Financial Planner)

## 概要
CFP®（Certified Financial Planner：CFP®認定者）は、NPO法人日本FP協会が認定するファイナンシャルプランニングの上級資格です。
顧客の資産設計、ライフプラン、相続・事業承継など、包括的なファイナンシャルプランニングの専門知識と実務能力を証明します。
国内のみならず、世界25カ国・地域で認められる国際資格でもあり、FP資格の最高峰とされています。

## 試験詳細
CFP®資格審査試験は全6課目で構成されています。AFP資格認定者であることが受験の前提条件です。

| 項目 | 内容 |
| --- | --- |
| **試験日程** | 年2回（6月・11月） |
| **試験方式** | マークシート方式（一部計算問題・事例問題） |
| **試験時間** | 各課目 2時間 |
| **課目数** | 全6課目 |
| **合格基準** | 各課目ごとに合格ライン設定（試験ごとに変動） |
| **受験資格** | AFP資格認定者であること |
| **資格更新** | 2年ごとに継続教育が必要 |

## 試験課目と出題範囲

### 1. ライフプランニング・リタイアメントプランニング
- キャッシュフロー表の作成、6つの係数計算
- 教育資金・住宅資金・老後資金の設計
- 社会保険制度（公的年金、医療保険、雇用保険、介護保険、労災保険）
- 確定拠出年金などの年金制度
- 労働基準法、成年後見制度
- 行動ファイナンス

### 2. リスクと保険
- 生命保険商品の仕組みと設計
- 損害保険商品の仕組みと設計
- 第三分野の保険（医療保険、がん保険など）
- 法人向け保険の活用
- 保険と税金
- リスクマネジメント

### 3. 金融資産運用設計
- 各国経済指標、金融政策
- 債券投資、株式投資、投資信託
- 外貨建て商品、デリバティブ
- ポートフォリオ理論、資産配分
- NISA、iDeCo等の税制優遇制度
- 金融商品取引法、犯罪収益移転防止法

### 4. タックスプランニング
- 所得税の計算（損益通算、所得控除、税額控除）
- 譲渡所得、不動産売却の税務
- 個人住民税、個人事業税
- 消費税
- 法人税（損金不算入など）

### 5. 不動産運用設計
- 不動産の売買・賃貸借に関する法令
- 不動産の有効活用、収益分析
- 不動産の価格評価（公的地価など）
- 不動産に関する税制（取得・保有・売却時）
- 借地借家法、建築基準法（容積率、建ぺい率）
- 登記、抵当権、不動産投資の利回り計算

### 6. 相続・事業承継設計
- 法定相続分、遺産分割協議、遺言書
- 特別受益、寄与分、成年後見制度
- 相続税の計算（配偶者の税額軽減、2割加算など）
- 贈与税の計算と各種控除制度
- 相続財産の評価（宅地、家屋、株式など）
- 事業承継（株式評価、会社法）

## CFP®とAFP®の違い

| 項目 | AFP® | CFP® |
| --- | --- | --- |
| **位置づけ** | FP資格の基本レベル | FP資格の最高峰（国際資格） |
| **難易度** | FP技能士2級相当 | FP技能士1級相当 |
| **受験資格** | 2級FP技能士合格 + AFP認定研修修了 | AFP認定者であること |
| **試験科目** | 統合された試験 | 6課目の専門試験 |
| **専門性** | 実践的FP知識 | 高度で幅広い専門知識 |
| **キャリア** | 金融業界でのキャリアアップ | より専門性を高め独立も視野 |

## 難易度・勉強時間目安
- **難易度**: 非常に高い (2024年度の合格率)
    - 全6課目一括受験合格率：約8～11%
    - 課目別合格率：約31～37%（2024年度第2回）
        - 金融資産運用設計：31.9%（最難関）
        - 不動産運用設計：35.5%
        - ライフプランニング・リタイアメントプランニング：34.6%
        - リスクと保険：35.0%
        - タックスプランニング：36.5%
        - 相続・事業承継設計：37.3%
    - 合格基準が試験ごとに変動する「足切り点」方式のため、回によって難易度が大きく異なる
- **勉強時間**: 400～600時間（AFP取得後）
    - 各課目を順次受験する戦略と、一括受験する戦略がある
