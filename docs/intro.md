# 資格カタログとは

資格を選ぶときに迷いやすいのは、試験の難しさよりも「取った後に何ができるのか」「今の自分に受験資格があるのか」という点です。資格カタログは、国家資格と民間資格の制度、受験条件、試験方式、費用を公式情報に沿って調べるための案内です。資格そのものを発行したり、受験を申し込んだりする公式機関ではありません。

## 資格を探す

まずは[資格検索](/explore/)で、資格名・カテゴリ・難易度・資格区分・試験方式・勉強時間から候補を絞れます。最大3件まで選んで、その場で比較できます。左のメニューから分野別に一覧することもできます。似た資格を比較したい場合は、資格名だけでなく「受験資格」「できる業務」「更新の有無」を見比べます。たとえば同じ職種に関係する資格でも、国家資格か民間認定か、試験に通れば足りるのか登録まで必要なのかは制度ごとに異なります。

## 分野から一覧する

主要な資格は8分野に整理しています。

| 分野 | 主なテーマ |
| --- | --- |
| [ビジネス](/docs/business/) | 経営・営業・人事・金融・マーケティング |
| [IT・技術](/docs/technology/) | 情報処理・クラウド・データ・開発・インフラ |
| [法律・会計](/docs/legal-accounting/) | 士業・法務・知財・簿記・会計 |
| [医療・福祉](/docs/medical-welfare/) | 医療・介護・福祉・リハビリ |
| [安全・環境](/docs/safety-environment/) | 防災・危険物・労働安全・環境 |
| [クリエイティブ](/docs/creative/) | デザイン・色彩・写真・映像 |
| [ライフスタイル](/docs/lifestyle/) | 語学・食・健康・文化・レジャー |
| [業界別](/docs/industry/) | 建設・製造・整備などの現場資格 |

分野を決めきれない場合は、[資格検索・比較](/explore/)で試験方式や資格区分から絞り込めます。

## 記事で確認できること

資格ごとの記事では、原則として次の情報を整理します。

- 資格の実施団体と、国家資格・民間資格などの区分
- 受験資格、試験科目、試験方式、合格基準
- 受験料と申込方法。年度や地域で変わる場合は、その条件
- 合格後の免許・登録・更新など、取得までに残る手続き
- 公式の試験案内や制度ページへのリンク

試験日や費用は改定されます。記事に確認日がある場合でも、それは公式情報を照合した時点であり、次回試験の実施を保証するものではありません。願書を出す前にリンク先の最新案内を確認してください。受験資格が学歴や職歴に関係する場合は、記事の要約だけで判断せず、公式要件の該当区分まで照合します。

## 資格から仕事を調べる

資格が業務にどう結びつくかを知りたい人は、[しごと図鑑](https://job.antonbase.com)も利用できます。仕事側の記事から必要な資格や関連する業界をたどれます。資格取得だけで採用や昇進が決まるわけではないため、求人の応募条件、実務経験、登録要件も合わせて確認してください。

このサイトの資格記事は比較検討のための情報です。法律・試験制度の個別判断、受験申込み、合格後の免許申請は実施団体が案内する手続きに従ってください。記事に公式根拠を確認できない合格率や勉強時間は固定値として載せません。
