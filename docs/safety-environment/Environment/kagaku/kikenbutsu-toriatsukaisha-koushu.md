# 危険物取扱者 甲種

## 概要

危険物取扱者は、消防法に基づく国家資格です。

**甲種**は、第1類から第6類まで**すべての種類の危険物**について、取扱作業とその立会いができる最上位区分です。

ガソリン等の第4類だけに限定されず、酸化性固体、可燃性固体、自然発火性物質、自己反応性物質、酸化性液体など全類を扱います。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 国家資格 |
| 試験方式 | 五肢択一・マークカード |
| 実技試験 | なし |
| 問題数 | 45問 |
| 試験時間 | 2時間30分 |
| 受験料 | 7,200円（非課税） |
| 合格基準 | 3科目それぞれ60%以上 |

総得点だけでなく、**すべての試験科目で60%以上**を取る必要があります。

## 試験科目

| 科目 | 問題数 |
| --- | ---: |
| 危険物に関する法令 | 15問 |
| 物理学及び化学 | 10問 |
| 危険物の性質・火災予防・消火方法 | 20問 |

合計45問です。

## 甲種の受験資格

乙種・丙種と違い、甲種には受験資格があります。

代表的なルートは次のとおりです。

### 1. 化学系の学科・課程を卒業

大学・短期大学・高専・専修学校等で、消防試験研究センターが認める化学に関する学科・課程を卒業した人。

### 2. 化学科目を15単位以上修得

大学・短大・高専・大学院等で、化学に関する授業科目を**15単位以上**修得した人。

### 3. 化学系の修士・博士

化学に関する事項を専攻し、修士または博士の学位を持つ人。

### 4. 乙種免状 + 2年以上の実務経験

乙種危険物取扱者免状の交付後、製造所等で**2年以上**危険物取扱いの実務経験がある人。

### 5. 指定された4種類以上の乙種免状

次の組み合わせを満たす4種類以上の乙種免状を持つ人です。

- 第1類または第6類
- 第2類または第4類
- 第3類
- 第5類

証明書類が必要なため、自分がどの受験資格に当てはまるかを公式チェック表で確認してください。

## 甲種で扱える危険物

- 第1類：酸化性固体
- 第2類：可燃性固体
- 第3類：自然発火性物質・禁水性物質
- 第4類：引火性液体
- 第5類：自己反応性物質
- 第6類：酸化性液体

甲種免状は、これらすべての類の取扱い・立会いに対応します。

## 試験日

危険物取扱者試験は全国の消防試験研究センター支部で年間を通して複数回実施され、**都道府県によって日程が異なります。**

全国共通の一日だけに実施される試験ではありません。

受験予定地の支部ページで、最新の試験日・申請期間・会場を確認してください。

## 難易度・勉強時間目安

実施団体は標準勉強時間を公表していません。

甲種は受験資格段階で化学の学修歴や乙種資格・実務経験などが要求され、試験でも物理・化学と6類全体を扱います。

学習では、法令・物化・性消の3科目を偏りなく進めることが重要です。どれか一科目でも60%を下回ると合格できません。
