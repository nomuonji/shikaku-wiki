# 危険物取扱者とは？ 甲種・乙種・丙種の違い

危険物取扱者は、消防法の危険物の取扱い等に関係する国家資格です。「乙4」はその一部であり、すべての危険物を扱える免状ではありません。**自分の職場が何類の危険物を扱っているか**で必要な類が変わります。

## 3区分の比較

| 区分 | 対象危険物 | 試験の受験資格 |
| --- | --- | --- |
| 甲種 | すべての類 | 所定の化学系学歴・単位、乙種免状保有者の実務経験・4種類等の経路が必要 |
| 乙種 | 免状に記載された第1類〜第6類のうちの類 | 制限なし |
| 丙種 | 公式に定める一部の第4類危険物 | 制限なし |

危険物を取り扱う際の具体的な業務・立会い・保安上の要件は、危険物の類、施設、業務内容に応じて別途確認してください。[公式の資格区分と対象危険物](https://www.shoubo-shiken.or.jp/kikenbutsu/guide.html)を基準にします。

## 第1〜6類の違い

| 類 | 対象の性質 | 代表例 |
| --- | --- | --- |
| 第1類 | 酸化性固体 | 塩素酸塩類など |
| 第2類 | 可燃性固体 | 硫黄、金属粉など |
| 第3類 | 自然発火性物質・禁水性物質 | カリウムなど |
| 第4類 | 引火性液体 | ガソリン、灯油、軽油、アルコール類など |
| 第5類 | 自己反応性物質 | 有機過酸化物など |
| 第6類 | 酸化性液体 | 過酸化水素など |

第4類を受験する人は[危険物取扱者乙4の詳細ガイド](/docs/safety-environment/Environment/kagaku/kikenbutsu-toriatsukaisha-otsushu-4rui/)から問題数、科目免除、免状交付まで確認できます。

## 甲種はどうすれば受験できる？

甲種には主に次の経路があります。

1. 所定の学校で化学関連の学科・課程を修めて卒業した。
2. 所定の学校で化学関連科目を15単位以上修得した。
3. 乙種免状を交付された後、危険物製造所等において危険物取扱いの実務経験が2年以上ある。
4. 第1類または第6類、第2類または第4類、第3類、第5類の各グループを満たす乙種免状を交付されている。
5. 化学関連の修士・博士の学位等がある。

正式な学校・単位・証明書の条件は[甲種受験資格の公式一覧](https://www.shoubo-shiken.or.jp/kikenbutsu/qualified01.html)が正本です。**免状の4種類を任意に選べばよいわけではありません。** [保有乙種免状の不足類チェッカー](/kikenbutsu-kou-juken-shikaku/)と[乙4と甲種の比較](/kikenbutsu-otsu4-kou-chigai/)を併用してください。

## 試験科目と合格判定

消防試験研究センターは、甲種を45問、乙種を35問、丙種を25問と案内しています。原則として各科目60％以上が合格基準です。免除者の科目・時間は異なります。固定の勉強時間や「何%の人が受かる」という根拠未確認の数値で級を選ばず、[試験科目表](https://www.shoubo-shiken.or.jp/kikenbutsu/annai/subject.html)から必要な範囲を確認してください。

## 何を先に取るか

第4類の業務を予定していて乙種の受験資格に制限がないことを重視するなら乙4が候補です。一方、第4類以外を扱う業務も想定するなら甲種や他の乙種の取得経路を調べます。**資格取得が採用を保証するわけではない**ため、担当予定の設備と募集要件まで確認することが重要です。
