# 危険物取扱者

## 概要

【危険物取扱者】化学/法令/物理の基礎をもとに、製造・物流の安全を守る資格。工場/SS/倉庫で即戦力。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格種別 | 国家資格（消防法。危険物の取扱い・立会いに必要） |
| 実施団体 | 一般財団法人消防試験研究センター（中央試験センター・各道府県支部） |
| 種類 | 甲種（全種類）、乙種第1〜6類（類ごと）、丙種（乙4のうち指定危険物のみ） |
| 受験資格 | 甲種のみ必要（大学の化学課程修了等）。乙種・丙種はなし |
| 試験手数料（非課税） | 甲種 7,200円、乙種 5,300円、丙種 4,200円 |
| 合格ライン | 全体60%以上、かつ各科目40%以上 |

最も受験者が多いのは乙種第4類（引火性液体：ガソリン・灯油・軽油・アルコール類など）で、年間約20万人が受験し、合格率は30〜40%程度が目安です。乙4は35問のマークシートで、危険物法令・基礎物理化学・性質消火の3科目から出題されます。試験は都道府県ごとに年複数回実施され、全国どこの会場でも受験できます。

## 難易度と対策

乙4はガソリンスタンド、化学工場、タンクローリー、危険物倉庫などで必須の資格で、警備・ビルメン業界でも評価されます。学習時間の目安は初学者で60〜100時間程度で、法令の暗記と性質・消火の理解が中心です。甲種は受験資格のハードルがある分、取得者は化学プラントの保安監督者として重宝されます。合格後は危険物取扱者保安講習（3年以内ごと）の受講義務がある点も押さえておきましょう。

## 受験の注意点

受付期間は試験日の2か月前〜1か月半前と短いため、消防試験研究センターの試験日程ページで早めに確認してください。電子申請と書面申請で締切・払込方法が異なるため注意が必要です。手数料は改定されることがあるため、申込前に公式発表を確認してください。
