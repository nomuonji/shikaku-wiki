# 危険物取扱者 乙種4類 (乙4)

## 概要
危険物取扱者 乙種第4類（通称：乙4）は、ガソリン、灯油、軽油、重油などの「引火性液体」を取り扱うことができる国家資格です。
ガソリンスタンド、化学工場、タンクローリーの運転手、ビルメンテナンスなど、幅広い職場で需要があります。
危険物取扱者試験の中で最も受験者数が多く（全体の約6割）、知名度も抜群です。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験日程 | 都道府県により異なる（東京都はほぼ毎週、他県は年数回程度）。試験日の2か月前〜1か月半前に受付 |
| 試験時間 | 120分 |
| 問題数 | 35問（五肢択一） |
| 合格ライン | 全体60%以上、かつ各科目40%以上 |
| 受験料 | 乙種 5,300円（非課税） |
| 受験資格 | なし |
| 試験方式 | マークシート方式 |

## 学習範囲・シラバス
1.  **危険物に関する法令 (15問)**
    - 指定数量、製造所等の区分、各種申請、保安講習など
2.  **基礎的な物理学及び基礎的な化学 (10問)**
    - 燃焼の理論、静電気、物質の状態変化、化学反応など
3.  **危険物の性質並びにその火災予防及び消火の方法 (10問)**
    - 第4類危険物（ガソリン、アルコール類、灯油等）の個別的性質、消火剤の種類など

## 難易度・勉強時間目安
- **難易度**: 初級（合格率 30%～40%）
    - 合格率が低めなのは、会社命令などで準備不足のまま受験する人が多いためです。しっかり勉強すれば合格は難しくありません。
    - 「物理・化学」でつまづく文系受験者が多いため、基礎から学習することが重要です。
- **勉強時間**:
    - およそ 40 ～ 60 時間

## 受験の注意点

受付期間は試験日の2か月前〜1か月半前と短いため、消防試験研究センターの試験日程ページで早めに確認してください。電子申請と書面申請で締切・払込方法が異なるため注意が必要です。合格後は危険物取扱者保安講習の受講義務（3年以内ごと）がある点も押さえておきましょう。手数料は改定されることがあるため、申込前に公式発表を確認してください。
