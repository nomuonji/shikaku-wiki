# 危険物取扱者 乙種4類（乙4）

## 乙4で扱える危険物と、扱えない範囲

危険物取扱者の乙種4類（乙4）は、消防法上の**第4類・引火性液体**に対応する資格です。ガソリン、アルコール類、灯油、軽油、重油などが代表例です。ただし、乙種第4類の免状があれば第1・2・3・5・6類まで自由に扱えるという意味ではありません。免状の類別と、現場で取り扱う危険物を一致させます。

乙4から甲種を目指す場合、受験資格を満たす経路は複数あります。甲種に進めるかは[乙4と甲種の違い](/kikenbutsu-otsu4-kou-chigai/)と[甲種受験資格・乙種免状の組み合わせチェッカー](/kikenbutsu-kou-juken-shikaku/)で確認できます。

## 最初に確認する5つの事実

| 項目 | 乙種第4類の公式案内 |
| --- | --- |
| 受験資格 | 制限なし。乙種は誰でも受験できる |
| 対象範囲 | 第4類の引火性液体 |
| 試験形式 | マークカードによる五肢択一式 |
| 試験時間 | 2時間（科目免除がない場合） |
| 試験手数料 | 5,300円、非課税。支払後の返金なし |

2026年10月21日に[受験案内](https://www.shoubo-shiken.or.jp/kikenbutsu/guide.html)、[受験資格](https://www.shoubo-shiken.or.jp/kikenbutsu/qualified01.html)、[試験の方法](https://www.shoubo-shiken.or.jp/kikenbutsu/annai/way.html)を参照した内容です。日程、申込期限、会場は支部によって異なるため、最新の受験案内で確認してください。

## 試験で必要な範囲

[公式の試験科目・問題数](https://www.shoubo-shiken.or.jp/kikenbutsu/annai/subject.html)では、通常の乙種は次の35問です。

| 科目 | 問題数 | ここで確認すること |
| --- | ---: | --- |
| 危険物に関する法令 | 15 | 指定数量、危険物施設や保安に関する決まり |
| 基礎的な物理学・化学 | 10 | 燃焼、物質の状態、基本的な化学の理解 |
| 危険物の性質・火災予防・消火 | 10 | 第4類引火性液体の性質、危険性、消火方法 |

[合格基準](https://www.shoubo-shiken.or.jp/kikenbutsu/annai/way.html)は原則として**各試験科目60％以上**です。全体で60％を超えれば、どれか1科目が低くても必ず合格する、という方式ではありません。科目免除を受けると対象科目の扱いが異なります。

## 他類の乙種免状をすでに持っている場合

乙種危険物取扱者免状の保有者が、別の乙種の類を受験する場合は科目免除制度があります。公式表には、法令と物化が全部免除となり、危険物の性質・消火の10問を35分で受験する区分が示されています。ただし、**資格と添付書類、申請する類が免除要件に該当するか**は[試験科目・免除一覧](https://www.shoubo-shiken.or.jp/kikenbutsu/annai/subject.html)を照合します。

## 仕事で使う前に確認すること

危険物の種類に加え、施設や業務でどのような立場で取扱い・立会いをするのかが重要です。乙4だけで甲種や他の類に関するすべての業務を代替することはできません。設備管理や燃料を扱う仕事を考えているなら[ビルメンの業務別資格ガイド](/birumen-shikaku/)も参照してください。

## 受験後の流れと勉強時間の考え方

試験に合格した後には、試験結果の通知と免状交付申請が続きます。試験合格と免状交付は同じ事実ではありません。受験票・写真、受験申請書類の扱いは[公式受験案内](https://www.shoubo-shiken.or.jp/kikenbutsu/guide.html)を確認してください。

この記事では、根拠が確認できない「必ず40〜60時間で合格する」「合格率が低いのは準備不足の受験者が多いから」といった学習・受験者属性の断定をしません。公式が公開する科目と問題数を見て、法令、物理・化学、第4類の性質の弱い分野から学習を組み立てます。
