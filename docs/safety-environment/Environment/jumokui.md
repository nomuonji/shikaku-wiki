# 樹木医

## 概要

樹木医は、一般財団法人 日本緑化センターが認定する**民間資格**です。

樹木の調査・診断・治療、保護・育成、倒木・落枝リスクの抑制、公園や街路樹の維持管理などに関わる専門家を認定します。

名称は商標登録されており、日本緑化センターの資格審査に合格し、登録した人が「樹木医」を使用できます。

## 応募資格

一般応募では、樹木に関係する所定の業務経歴が**5年以上**必要です。

対象となる例は次のとおりです。

- 樹木の調査・研究
- 診断・治療
- 保護・育成・管理
- 公園緑地の計画・設計・設計監理
- 緑化樹木・果樹の生産

樹木医補は、認定後の業務経歴1年以上で応募できます。

## 2026年度

| 項目 | 内容 |
| --- | --- |
| 一次審査 | 2026年7月12日 |
| 一次申込 | 2026年5月1日〜6月15日 |
| 一般受験手数料 | 19,000円 |
| 樹木医補 | 16,000円 |
| 二次審査 | Web講義 + つくば市で6日間の実習・資格審査 |

一次審査では、業績審査に加え、択一式90分・35問と論述式90分・3問が行われます。

## 二次審査・樹木医研修

一次審査合格者は樹木医研修へ進みます。

研修では16科目の講義・実習を受け、次の資格審査を行います。

- 科目試験
- 樹種識別の適性試験
- 面接試験

総合評価で合格した後、登録して樹木医資格を取得します。

## 難易度・勉強時間目安

樹木医は、受験前から5年の実務経験を求める専門資格です。一般的な知識検定のような「標準勉強時間」は設定されていません。

樹木生理・病害虫・土壌・診断・保護制度などを、実務経験と結びつけて理解する必要があります。
