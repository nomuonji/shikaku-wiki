# 防災士

## 概要
防災士は、日本防災士機構が認証する民間資格です。地域や職場で防災・減災活動に関わる知識を持つことを示すもので、国家資格ではありません。

制度確認日: 2026-10-19。詳細は公式サイトで最新情報を確認してください。

## 資格取得の流れ
一般的な取得方法は次の3ステップです（特例制度あり）。

1. 日本防災士機構が認証した研修機関の「防災士養成研修講座」を受講し、研修履修証明を取得。
2. 防災士資格取得試験に合格（受験料3,000円税込。研修履修証明取得者が受験可）。
3. 救急救命講習を受講し修了証を取得。認証登録申請時に5年以内に発行され、かつ発行者が定めた有効期限内のものが対象。

上記を満たしたうえで日本防災士機構に認証登録を申請（登録料5,000円税込）すると、防災士認証状と防災士証が交付されます。
