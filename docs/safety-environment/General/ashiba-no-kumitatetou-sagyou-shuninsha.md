# 足場の組立て等作業主任者

足場の組立て等作業主任者は、労働安全衛生法に基づき事業者が選任する作業主任者です。技能講習を修了した者のうちから選ばれ、講習修了だけで選任されたことにはなりません。料金・日程・合格率は登録講習機関ごとに異なるため、このページでは固定しません。

制度確認日: 2026-10-03。法令は改正されるため、申込前に厚生労働省の原文と登録講習機関の案内を確認してください。

## 選任が必要な作業

労働安全衛生法施行令第6条第15号では、次の足場の組立て、解体または変更の作業について、足場の組立て等作業主任者技能講習を修了した者のうちから作業主任者を選任しなければなりません。

- つり足場（ゴンドラのつり足場を除く）
- 張出し足場
- 高さが5メートル以上の構造の足場

高さ5メートル未満で、つり足場でも張出し足場でもない足場は、この作業主任者の選任対象そのものではありません。ただし、高さ2メートル以上の足場では組立て等の作業時に別の危険防止措置が必要です。選任したときは、作業主任者の氏名と行わせる事項を関係労働者に周知させます。

## 受講資格

労働安全衛生規則別表第6の受講資格は、次のいずれかです。年齢の運用は登録講習機関の案内で分かれるため、申込先に確認してください。

| 経路 | 要件 |
| --- | --- |
| 実務経験 | 足場の組立て、解体または変更に関する作業に3年以上従事した経験を有する者 |
| 指定学科 | 大学、高等専門学校、高等学校または中等教育学校で土木・建築または造船に関する学科を専攻して卒業した者で、その後2年以上同作業に従事した経験を有するもの |
| 厚生労働大臣が定める者 | 技能講習規程第1条の訓練を修了し、その後2年以上同作業に従事した経験を有する者など |

## 講習科目

足場の組立て等作業主任者技能講習規程（昭和47年労働省告示第109号）第3条の学科は次のとおりです。同規程第5条では、講習科目について筆記または口述の修了試験を行います。

| 講習科目 | 時間 |
| --- | --- |
| 作業の方法に関する知識 | 7時間 |
| 工事用設備、機械、器具、作業環境等に関する知識 | 3時間 |
| 作業者に対する教育等に関する知識 | 1時間30分 |
| 関係法令 | 1時間30分 |

技能講習規程第1条の訓練修了者や、とびの一級・二級技能検定合格者などは、「作業の方法に関する知識」と「工事用設備、機械、器具、作業環境等に関する知識」の受講免除を受けられる場合があります（同規程第4条）。免除が使えるかは講習機関に確認してください。

## 作業者向け特別教育との違い

足場の組立て等作業主任者技能講習は、選任対象の作業を指揮する作業主任者になるための講習です。一方、足場の組立て、解体または変更の作業に就く作業者には、別に特別教育が必要です（労働安全衛生法第59条、労働安全衛生規則第36条）。特別教育を修了しただけでは、作業主任者には選任できません。
