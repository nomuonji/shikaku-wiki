# 土壌医検定 3級

## 概要
土壌医検定3級は、日本土壌協会が実施する土づくりと作物生育に関する基礎知識を認定する検定です。農業従事者、家庭菜園愛好家、農業指導者などが土壌管理の基本を学べます。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| **試験方式** | 三肢択一式 |
| **問題数** | 50問 |
| **試験時間** | 60分 |
| **合格基準** | 30問以上正解 |

## 難易度・合格率
- **難易度**: 易しい
- **合格率**: 54.7%(2024年、受験者1,881人中1,029人合格)
  - 例年55-60%程度
- **勉強時間**: 30-50時間程度
