# 甲種防火管理者

## 概要

甲種防火管理者は、一定規模以上の建物・事業所で、消防計画の作成、避難訓練、火気管理、消防設備の維持管理などを統括する**防火管理者**として選任されるための資格です。

重要なのは、一般的な筆記試験へ合格して取得する資格ではないことです。

代表的な取得方法は、消防法に基づく**甲種防火管理新規講習を修了すること**です。

## 甲種と乙種の違い

防火管理が必要な建物は、用途、収容人員、延べ面積などによって甲種・乙種の対象が異なります。

甲種防火管理者は、乙種より広い対象物で選任できる資格です。

ただし「甲種を持っていれば、どの建物でも自動的に防火管理者になる」という意味ではありません。

実際に防火管理者として選任されるには、**その建物で管理的・監督的な地位にあること**など、別の要件があります。

## 甲種防火管理新規講習

日本防火・防災協会が実施する2026年の講習は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 消防法に基づく防火管理者資格 |
| 対面型 | 連続2日間 |
| オンライン型 | 約10時間・受講期間12日間 |
| 受講料 | 8,000円（税込） |
| 修了 | 所定講習を修了し修了証を取得 |

オンライン型はオンデマンド方式で、受講期間内に講義動画を視聴します。

効果測定等を含め、所定の受講条件を満たす必要があります。

## 講習内容

主に次の内容を学びます。

- 防火管理の意義と制度
- 火気取扱いと出火防止
- 危険物の安全管理
- 地震対策
- 施設・設備の維持管理
- 自衛消防
- 訓練・教育
- 消防計画の作成・運用

単に「火事の知識」を学ぶだけではなく、組織として防火管理を回すための実務が中心です。

## 誰が必要になる？

多数の人が出入り・居住する建物では、一定の条件に該当すると防火管理者を選任する義務があります。

対象となる建物・必要資格の区分は、建物用途、収容人員、延べ面積、管理権原などによって変わります。

自分の勤務先で甲種が必要かどうかは、所轄消防署や講習案内で確認してください。

## 再講習

一定の防火対象物で防火管理者として選任されている場合、**甲種防火管理再講習**の受講が必要になるケースがあります。

資格取得後に全員が一律で同じ頻度の再講習を受ける制度ではないため、選任先の条件を確認します。

## 難易度・勉強時間目安

甲種防火管理者は、競争試験型の資格ではありません。

約10時間の所定講習をきちんと受講し、防火管理の実務を理解することが中心です。

「合格率」「偏差値」のような試験難易度で比較するより、講習時間と選任後の責任範囲を理解する方が適切です。
