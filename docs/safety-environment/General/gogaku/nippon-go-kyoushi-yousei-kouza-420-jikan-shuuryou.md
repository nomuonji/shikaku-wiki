# 日本語教師 養成講座420時間 修了

## 420時間修了が意味すること
「420時間」は、日本語教師養成課程で学んだ時間を示す通称として使われてきました。講座を修了したことは学習歴の証明になりますが、それだけで現在の国家資格「登録日本語教員」になれるわけではありません。日本語学校など認定日本語教育機関で働くことを考える場合、講座の内容がどの制度・経過措置に該当するかを、文化庁ではなく現在の所管である文部科学省の登録日本語教員案内で確認してください。

## 登録日本語教員制度との違い
2024年に登録日本語教員制度が始まり、認定日本語教育機関で日本語教育を行うための資格・機関認定の仕組みが設けられました。新制度の基本ルートは日本語教員試験と実践研修ですが、養成機関の課程、修了時期、学士要件や職歴などによって経過措置が異なります。旧来の420時間講座でも、名称だけから経過措置の対象と決めつけることはできません。受講先が文部科学省の一覧でどの課程として登録されているか、修了証明や実習の内容が要件に合うかを照合しましょう。

経過措置には複数の類型と期限があり、対象者によって必要な試験・講習・実践研修が変わります。期限についても、一般的な移行期限と個別課程に適用される期間を混同しないでください。勤務予定の教育機関が求める資格、担当する課程、採用時期を確認し、必要であれば文部科学省または登録実践研修機関に自分の履修歴を提示して確認します。

## 講座選びと学びの活用
これから学ぶ人は、講座の「420時間」という表示だけで比較せず、登録日本語教員制度上の課程区分、実習内容、修了証の発行条件、卒業後の申請支援を確認してください。教授法だけでなく、日本語の音声・文法・語彙、学習者の背景、授業設計、評価、教室実習をどう扱うかも比較点です。海外で教える場合や、認定日本語教育機関以外で働く場合は、就職先や国・地域の要件が別に定められていることがあります。

すでに修了した人は、修了証に記載された講座名・修了日と、文部科学省の経過措置ルートを並べて確認すると、追加で必要な手続きが分かります。講座修了は学習の土台として活用できますが、就業可能性や登録可否は個別要件で決まります。
