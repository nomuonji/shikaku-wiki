# Illustratorクリエイター能力認定試験 スタンダード

## 概要
Illustratorクリエイター能力認定試験 スタンダードは、Adobe Illustratorの基本操作と、指示に従って正確にコンテンツを作成する能力を認定する試験です。
サーティファイ ソフトウェア活用能力認定委員会が主催しています。
DTPやWebデザインの現場で必要とされる、ツール操作の基礎、トレース、基本的なオブジェクト作成スキルが問われます。
実務経験が浅い人や、これからデザイナーを目指す学生・初学者に最適です。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 第1部（実技）：40分、第2部（実践）：90分 |
| 問題数 | 第1部：テーマ別大問7〜9問程度、第2部：1テーマ |
| 合格ライン | 得点率65%以上 |
| 受験料 | 7,600円（税込） |
| 受験資格 | なし（誰でも受験可能） |
| 有効期限 | なし（永久資格） |
| 試験方式 | 実技試験（PC上でIllustratorを操作し、作成したデータを提出） |

## 学習範囲・シラバス
- **第1部（実技）**
    - 基本的な図形描画（長方形、楕円、多角形など）
    - ペンツールによるパスの描画と編集
    - 文字の入力と設定（フォント、サイズ、行揃え）
    - カラー設定（塗り、線、グラデーション）
    - オブジェクトの変形、整列、グループ化
- **第2部（実践）**
    - 提供された素材や指示書に基づき、1つの作品（チラシ、案内状など）を作成
    - レイヤーの活用
    - 効率的な作業手順と完成度

## 難易度・勉強時間目安
- **難易度**: 初級
    - Illustratorの基本的なツール操作ができれば合格可能です。
    - スピードと正確性が求められるため、操作に慣れておく必要があります。
- **勉強時間**:
    - 20〜40時間程度
    - 公式テキストの模擬問題を繰り返し解き、時間内に完成させる練習が重要です。
