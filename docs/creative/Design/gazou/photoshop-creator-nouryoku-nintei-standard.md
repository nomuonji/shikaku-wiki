# Photoshopクリエイター能力認定試験 スタンダード

## 概要
Photoshopクリエイター能力認定試験 スタンダードは、Adobe Photoshopの基本操作と、画像編集の基礎的なスキルを認定する試験です。
サーティファイ ソフトウェア活用能力認定委員会が主催しています。
写真の補正、加工、合成、テキストの追加など、実務で頻繁に使用される機能の習得度を測ります。
WebデザインやDTPの分野への就職を目指す人や、Photoshopを初めて学ぶ人に適しています。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 第1部（実技）：40分、第2部（実践）：90分 |
| 問題数 | 第1部：テーマ別大問7〜9問程度、第2部：1テーマ |
| 合格ライン | 得点率65%以上 |
| 受験料 | 7,600円（税込） |
| 受験資格 | なし（誰でも受験可能） |
| 有効期限 | なし（永久資格） |
| 試験方式 | 実技試験（PC上でPhotoshopを操作し、作成したデータを提出） |

## 学習範囲・シラバス
- **第1部（実技）**
    - 選択範囲の作成と編集（長方形、楕円形、自動選択ツールなど）
    - 画像の移動、変形、トリミング
    - レイヤーの基本操作（作成、削除、複製、順序変更）
    - 色調補正（明るさ・コントラスト、色相・彩度など）
    - テキストの入力と編集
    - ペイントツール（ブラシ、塗りつぶし）の使用
- **第2部（実践）**
    - 提供された画像素材やテキストを使用し、指示に従って1つの作品を完成させる
    - 画像の合成と調整
    - レイヤースタイルやフィルターの基本的な適用

## 難易度・勉強時間目安
- **難易度**: 初級
    - Photoshopの基本的なツールとパネル操作ができれば対応可能です。
    - 複雑なマスク処理や高度な合成技術は求められませんが、基本的な操作をスムーズに行う必要があります。
- **勉強時間**:
    - 20〜40時間程度
    - 公式テキストや問題集を使って、実際の試験形式に慣れておくことが大切です。
