# Adobe Certified Professional (Photoshop)

## 概要
Adobe Certified Professional (Photoshop) は、Adobe Photoshop の使用に関する専門的なスキルを証明する国際認定資格です。
写真の編集、合成、グラフィックデザインにおける実務的な知識と操作技術が問われます。
アドビが公認する唯一の資格であり、合格すると「Adobe Certified Professional」の称号が得られ、デジタルバッジが付与されます。
Webデザイナー、フォトグラファー、グラフィックデザイナーを目指す人に適しています。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 50分 |
| 問題数 | 約30問（選択式および実技形式） |
| 合格ライン | 700点 / 1000点満点（目安） |
| 受験料 | 一般：10,780円（税込）、学生・教職員：8,580円（税込） ※オデッセイコミュニケーションズ価格 |
| 受験資格 | なし（誰でも受験可能） |
| 有効期限 | 3年間（資格取得から3年で失効するため、再受験が必要） |
| 試験方式 | CBT（コンピュータベースの試験、テストセンターまたは自宅受験） |

## 学習範囲・シラバス
試験は「Visual Design Using Adobe Photoshop」という科目名で実施されます。

1.  **業界の知識**: デザインの原則、著作権、プロジェクト管理、解像度などの用語
2.  **プロジェクトのセットアップ**: ドキュメント設定、カラーモード、ガイドとグリッド
3.  **インターフェースの操作**: ツールバー、パネル、ワークスペースのカスタマイズ
4.  **画像の整理**: レイヤー管理、マスク、スマートオブジェクト
5.  **画像の作成と変更**: 選択範囲、色調補正、レタッチ、テキスト、フィルター、描画モード
6.  **パブリッシュ**: 保存形式、書き出し設定

## 難易度・勉強時間目安
- **難易度**: 中級
    - アプリケーション内での実技操作が含まれるため、知識だけでなく実際に手を動かして制作できる能力が必須です。
    - 選択問題と操作問題が混在しており、的確な操作が求められます。
- **勉強時間**:
    - 経験者: 20〜30時間（試験対策中心）
    - 初学者: 150時間程度（実務経験やハンズオン学習を含む推奨時間）
