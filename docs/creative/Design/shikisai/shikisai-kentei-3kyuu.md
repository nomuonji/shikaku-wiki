# 色彩検定 3級

## 3級で身につく基礎

色彩検定3級は、色を感覚だけで選ぶのではなく、色相・明度・彩度や配色の考え方を言葉で説明する入門級です。ファッション、インテリア、販売、広報、Web制作などで配色を扱う人や、色の学習を始めたい人に向いています。色彩検定協会が実施し、受検に年齢や学歴の制限はありません。

学ぶ内容には、色が見える仕組み、色の分類、PCCS、色彩心理、色彩調和、配色イメージ、ファッション・インテリア、慣用色名などがあります。UC級のように色のユニバーサルデザインへ焦点を当てた試験とは役割が異なります。色の基本を広く学ぶなら3級、色覚の多様性に配慮した表現を深めるならUC級も候補です。

## 2026年度の試験情報

AFTの2026年度案内では、3級は夏期と冬期に実施され、マークシート方式、試験時間60分、検定料7,000円です。2026年度冬期の第67回は11月8日、申込期間は8月10日から10月1日までです。夏期試験は6月28日に実施済みです。会場・申込方法や当日の持ち物は受検地と方式によって異なるため、申込画面と受検案内を確認してください。

過去の説明にある合格ラインを固定値として扱うのは避けましょう。AFTは出題範囲と試験案内を公開していますが、年度により内容や案内が変わる可能性があります。公式ページにない勉強時間や合格率は目安としても断定せず、まず公式テキストとサンプル問題で自分の理解度を確かめるのが安全です。

## 独学の進め方

最初に色相環や色の三属性を図にして、言葉と見た目を結びつけます。次にPCCSのトーンと配色調和を使い、たとえば「同じ色相で明度を変える」「補色関係を使う」など、選んだ配色の理由を説明してみます。用語を丸暗記するだけだと、似た選択肢の違いを見分けにくくなります。

公式の出題範囲に沿って一周学んだ後、問題を解き、間違えた箇所を領域別に戻って復習します。慣用色名だけでなく、色の見え方や配色の関係を問う問題もあるため、問題集の答えを覚えるより、図や実物の色票を使って関係を確認すると応用しやすくなります。色を使った資料を作る人は、文字や線種を併用し、色だけに情報を持たせない練習も実務につながります。

## 申し込み前に見るページ

色彩検定は年度ごとに夏期・冬期の受付期間が決まります。マイページで受検級を選ぶ前に、2026年度の案内、支払期限、受検地、試験日を確認してください。UC級と同じ日に別の級を受ける場合は、試験時刻が重ならないか公式の級別スケジュールで確認します。
