# カラーコーディネーター検定 スタンダードクラス

## 概要
カラーコーディネーター検定試験は、ビジネスや日常生活における色彩の活用能力を測る試験です。
東京商工会議所が主催しています。
2020年にリニューアルされ、従来の1級・2級・3級から「アドバンスクラス」「スタンダードクラス」の2区分に変更されました。
スタンダードクラスは、日常から見た色彩に関する基礎的な知識を理解し、生活の中で色を使いこなす能力を認定します。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 90分 |
| 問題数 | 多肢選択式（IBT/CBT） |
| 合格ライン | 100点満点中70点以上 |
| 受験料 | 5,500円（税込） ※CBT利用料別途2,200円（CBTの場合） |
| 受験資格 | なし（誰でも受験可能） |
| 有効期限 | なし（永久資格） |
| 試験方式 | IBT（自宅受験）または CBT（テストセンター受験） |

## 学習範囲・シラバス
公式テキスト「スタンダードクラス」に準拠した以下の範囲から出題されます。

1.  **生活と色**: 色の役割、生活の中の色彩
2.  **色の分類と体系**: 色の三属性、PCCS、マンセル表色系
3.  **色の心理**: 色の寒暖感、軽重感、配色による心理効果
4.  **配色**: 色の調和、配色の基本的技法
5.  **光と色**: 光の性質、眼の構造、照明
6.  **色の表示**: 慣用色名、系統色名

## 難易度・勉強時間目安
- **難易度**: 初級
    - 色彩検定3級〜2級レベルに相当し、基礎的な理論が中心です。
    - 合格率は50%〜70%程度と比較的高いですが、専門用語の暗記が必要です。
- **勉強時間**:
    - 30〜60時間程度
    - 公式テキストを読み込み、用語を正しく理解すれば合格可能です。

## 現行名と旧級名
現在の区分はスタンダードクラスとアドバンスクラスです。旧3級・2級という呼び方は過去制度の情報を探す人には役立ちますが、今の申込画面では現行クラス名で手続きします。この記事のファイル名や検索結果に「3級」が残っていても、現行の試験級が3級という意味ではありません。受験時には東京商工会議所の当年度の案内で、試験方式、申込可能期間、受験料、教材の版を確認してください。

## 色彩検定との違いから選ぶ
カラーコーディネーター検定は、色の知識をビジネスに活かす観点を学ぶ東京商工会議所の検定です。色彩検定は色彩の基礎から専門領域までを学ぶ別の検定で、両者は主催者も試験体系も異なります。「配色センスの資格」という一括りにせず、商業・商品企画・販売など仕事の中で色をどう使いたいかを考え、公式シラバスの扱うテーマと照らして選びましょう。スタンダードは基礎知識を身につけたい人向け、アドバンスはより応用的な理解を目指す人向けです。

合格は実務経験やデザイン作品そのものの代わりにはなりません。学習後に販促物や資料の配色理由を説明できるようにすると、知識の使いどころが明確になります。現行の制度は[東京商工会議所のカラーコーディネーター検定案内](https://kentei.tokyo-cci.or.jp/color/)で確認してください。確認日: 2026-09-24。
