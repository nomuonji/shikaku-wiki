# カラーコーディネーター検定 スタンダードクラス

## 概要
カラーコーディネーター検定試験は、ビジネスや日常生活における色彩の活用能力を測る試験です。
東京商工会議所が主催しています。
2020年にリニューアルされ、従来の1級・2級・3級から「アドバンスクラス」「スタンダードクラス」の2区分に変更されました。
スタンダードクラスは、日常から見た色彩に関する基礎的な知識を理解し、生活の中で色を使いこなす能力を認定します。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 90分 |
| 問題数 | 多肢選択式（IBT/CBT） |
| 合格ライン | 100点満点中70点以上 |
| 受験料 | 5,500円（税込） ※CBT利用料別途2,200円（CBTの場合） |
| 受験資格 | なし（誰でも受験可能） |
| 有効期限 | なし（永久資格） |
| 試験方式 | IBT（自宅受験）または CBT（テストセンター受験） |

## 学習範囲・シラバス
公式テキスト「スタンダードクラス」に準拠した以下の範囲から出題されます。

1.  **生活と色**: 色の役割、生活の中の色彩
2.  **色の分類と体系**: 色の三属性、PCCS、マンセル表色系
3.  **色の心理**: 色の寒暖感、軽重感、配色による心理効果
4.  **配色**: 色の調和、配色の基本的技法
5.  **光と色**: 光の性質、眼の構造、照明
6.  **色の表示**: 慣用色名、系統色名

## 難易度・勉強時間目安
- **難易度**: 初級
    - 色彩検定3級〜2級レベルに相当し、基礎的な理論が中心です。
    - 合格率は50%〜70%程度と比較的高いですが、専門用語の暗記が必要です。
- **勉強時間**:
    - 30〜60時間程度
    - 公式テキストを読み込み、用語を正しく理解すれば合格可能です。
