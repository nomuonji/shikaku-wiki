# カラーコーディネーター検定 アドバンスクラス

## 概要
カラーコーディネーター検定試験 アドバンスクラスは、ビジネスにおける色彩の活用事例など、幅広い知識と応用力を問う試験です。
東京商工会議所が主催しています。
スタンダードクラスの上位に位置し、旧制度の1級に相当する高度な内容を含みます。
製品開発、建築・インテリア、環境色彩、ファッション、プレゼンテーションなど、実務で色彩を戦略的に活用するための専門的なスキルを認定します。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 90分 |
| 問題数 | 多肢選択式（IBT/CBT） |
| 合格ライン | 100点満点中70点以上 |
| 受験料 | 7,700円（税込） ※CBT利用料別途2,200円（CBTの場合） |
| 受験資格 | なし（誰でも受験可能） |
| 有効期限 | なし（永久資格） |
| 試験方式 | IBT（自宅受験）または CBT（テストセンター受験） |

## 学習範囲・シラバス
公式テキスト「アドバンスクラス」に準拠した以下の範囲から出題されます。

1.  **カラーマネジメントの実際**: 測色、XYZ表色系、CCIC、品質管理
2.  **カラーユニバーサルデザイン**: 色覚の多様性への配慮、安全色彩
3.  **色彩心理とマーケティング**: 色のイメージ、消費者心理、トレンド分析
4.  **配色と色彩調和**: オストワルト表色系、NCS、多様な調和論
5.  **光と色**: 分光分布、演色性、照明計画
6.  **歴史と文化**: 色彩文化史、芸術様式
7.  **各分野の色彩**: ファッション、プロダクト、インテリア、環境色彩、プレゼンテーション

## 難易度・勉強時間目安
- **難易度**: 中級〜上級
    - スタンダードクラスよりも専門的で、物理学的な光の知識や、マーケティング理論、歴史など多岐にわたる知識が必要です。
    - 実務で即戦力となる知識が問われるため、難易度は高いです。
- **勉強時間**:
    - 60〜100時間以上
    - 公式テキストの内容を深く理解する必要があります。
