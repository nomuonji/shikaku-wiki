# 園芸装飾技能士 2級

2026-10-03に、厚生労働省の職種案内、中央職業能力開発協会（JAVADA）の令和8年度前期資料、および各都道府県職業能力開発協会への申込案内を照合した。施行日・受検手数料・実務経験の該当欄は都道府県と経路で変わるため、申込前に受検する都道府県協会の公示を確認する。

## 直接の答え

園芸装飾技能士2級は、職業能力開発促進法に基づく技能検定の園芸装飾職種（室内園芸装飾作業）に合格した人に与えられる国家資格です。2級の合格証書は都道府県知事名で交付され、合格者は技能士と称することができます。対象となる技能は、観賞用植物による装飾とその維持管理です。

受検には原則として、その職種に関する実務経験が必要です。実務経験のみの場合、2級は2年以上です。学歴や職業訓練、3級合格後の経路で必要年数は短縮または0年になる欄があります。「3級合格者なら誰でも実務経験不要」とは書かず、厚生労働省の受検資格一覧表で自分の欄を確認してください。

## 令和8年度前期に確認できた試験内容

| 項目 | 確認できた内容 | 全国一律とは言えない点 |
| --- | --- | --- |
| 実技試験 | 令和8年度前期の概要では、(1) 鉢替え・剪定・整姿・清掃・繁殖・整理（標準時間35分、打切り時間50分）、(2) 課題図のインドアガーデン製作（標準時間1時間30分、打切り時間2時間） | 概要は一部変更される場合がある。実施日は都道府県ごと |
| 学科試験 | 都道府県実施職種は真偽式25問と多肢択一式25問の計50問。令和8年度前期の1・2級園芸装飾学科は2026-09-06、10:00開始で統一実施 | 学科の試験時間はこの照合では一次資料上の固定値を確認できなかった |
| 合格基準 | 100点満点で、原則として実技60点以上、学科65点以上 | 「原則として」の基準であり、職種ごとの例外までは断定しない |
| 受検手数料 | 標準金額は令和元年度以降、実技18,200円、学科3,100円 | 実額は検定職種ごとに都道府県が定める。年齢区分の減免もあり得る |
| 受検資格 | 実務経験のみなら2年以上。学歴・訓練・下位級合格で短縮される | 該当欄は一覧表と申込先で確認する |
| 合格の扱い | 実技と学科の両方合格が必要。片方だけ合格した場合は、次回以降に不合格側だけ受検できる | 特級の片方合格は合格日から5年間有効。2級合格そのものに更新期限があるとは一次資料に書かれていない |

令和8年度前期の学科試験は終了しています。次回以降の実施日、会場、持参物、手数料は後期公示と都道府県協会の案内が正本です。JAVADAは受検申込や合格発表を行いません。

## 学科と実技で問われる範囲

厚生労働省の試験基準（平成23年3月、園芸装飾）では、2級学科の科目は次のとおりです。求める知識の程度は科目ごとに「詳細」「一般的」「概略」などで分かれています。

- 室内園芸装飾法
- 材料
- 庭園
- 植物一般
- 観賞用植物の維持管理
- 園芸施設
- 安全衛生

令和8年度前期の2級実技は、上記の鉢替え・整理作業とインドアガーデン製作です。使用する植物や材料の一部は持参です。作業内容を「インドアガーデン製作4時間」の1課題とは読めません。

## 難易度と学習時間

JAVADAは、2級を「中級の技能労働者が通常有すべき技能の程度」と定義しています。これは合格率や個人の体感難度ではありません。

経験者の学習時間を50〜100時間とする一次資料は、この照合では見つかりませんでした。学習時間の目安は載せません。実技は植物・資材と作業手順が必要なため、職場や訓練先で練習できるかが受検判断の実務上の条件になります。

## 申込み前に確認すること

- 受検する都道府県職業能力開発協会が、当該年度に園芸装飾2級を実施するか。
- 自分の学歴・訓練・3級合格の有無が、受検資格一覧表のどの欄に当たるか。
- 実技と学科を同時に受けるか、片方だけか。手数料はその組み合わせと年齢区分で変わる。
- 実技の持参植物・材料と、当日の作業順序。
