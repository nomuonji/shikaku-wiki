# 色彩検定 UC級（色のユニバーサルデザイン級）

## UC級で学ぶこと

UC級は、色の見え方の多様性を踏まえ、色だけに情報を頼らないデザインを考えるための検定です。色覚特性の違いや加齢による見え方を知り、文字と背景のコントラスト、図表や案内表示の区別しやすさを検討します。ウェブや印刷物、施設サイン、教育資料などで配色を決める人に向いています。色彩検定3級の合格が受験条件ではなく、AFTはUC級の公式テキストで必要な知識を学べると案内しています。

## 2026年度の受検方法

色彩検定協会の2026年度案内では、UC級は夏期と冬期に実施されます。冬期の第67回は2026年11月8日で、申込みは8月10日から10月1日までです。試験はマークシート方式（一部記述式）、時間は60分、検定料は6,000円です。2026年夏期試験は6月28日に終了しており、これから受ける人は冬期の申込要領と会場・受検方法を確認してください。

検定料や日程は年度ごとに更新されます。手元の古いパンフレットではなく、AFTの受検案内に掲載される年度を確認してから申し込みます。受験にはマイページ登録が必要で、申込情報や支払方法も公式の手順に沿って進めます。

## 3級との違いと実務での使い分け

3級は色の三属性、PCCS、配色調和、色彩心理など、色を扱う基礎を広く学ぶ級です。UC級は色の識別しやすさやユニバーサルデザインに焦点を当てます。色彩の基礎用語を体系的に学びたい人は3級、既に配色に触れていて、見え方への配慮を実務で考えたい人はUC級が選びやすいでしょう。どちらから受けてもよく、3級合格がUC級の必須条件という扱いではありません。

学んだ知識を使う際は、色だけで意味を伝えない工夫が役立ちます。たとえばグラフの系列を色分けするだけでなく、線種やラベルも併用する、案内図では明度差と文字サイズを確認する、といった改善を考えます。資格取得だけでアクセシビリティへの適合が保証されるわけではないため、実際の制作物は利用者や関連ガイドラインに照らして検証してください。

## 学習方法

AFT公式のUC級テキストを基準に色覚多様性、配色、サインなどの用語を学びます。公式サイトの試験概要と級別案内で今年の出題範囲を確認し、模擬問題を解いたら「どの見え方の差を問題にしているか」「色以外にどう伝えられるか」を説明できるか振り返ります。3級の知識を持っている人も、UC級固有の出題内容を別に確認してください。
