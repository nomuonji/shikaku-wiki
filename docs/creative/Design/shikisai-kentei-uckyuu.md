# 色彩検定 UC級 (ユニバーサルデザイン級)

## 概要
色彩検定 UC級（色のユニバーサルデザイン級）は、色覚の多様性に配慮した「誰もが見やすい色使い」を実践するための知識を問う検定です。
公益社団法人 色彩検定協会（AFT）が主催する文部科学省後援の公的資格です。
高齢者や色覚特性を持つ人にとって見分けにくい色の組み合わせを理解し、看板、サイン、ウェブサイト、印刷物などで適切な配色を行うスキルを証明します。
「人にやさしい色づかい」を目指すデザイナー、公務員、教職員などに推奨されます。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 60分 |
| 問題数 | マークシート方式（一部記述がある場合も） |
| 合格ライン | 満点の7割程度 |
| 受験料 | 6,000円（税込） |
| 受験資格 | なし（誰でも受験可能） |
| 有効期限 | なし（永久資格） |
| 試験方式 | マークシート方式 |

## 学習範囲・シラバス
- **色覚の多様性**: ヒトの目の構造、色覚特性のメカニズム、高齢者の見え方
- **色のユニバーサルデザイン**: バリアフリーとユニバーサルデザインの違い、アクセシビリティ
- **配色**: 識別しやすい色の組み合わせ、コントラストの調整
- **環境・安全色彩**: サイン、標識、ハザードマップなどの事例
- **改善事例**: 実際に見にくい事例をどのように改善するか

## 難易度・勉強時間目安
- **難易度**: 初級〜中級
    - 専門的な知識が必要ですが、範囲は限定的で、テキストをしっかり学習すれば合格しやすい試験です。
    - 合格率は非常に高く（90%前後になることも）、まじめに取り組めば取得しやすい資格です。
- **勉強時間**:
    - 20〜40時間程度
    - 公式テキストを一通り読み、問題集を解くことで十分対策可能です。
