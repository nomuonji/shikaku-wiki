# フォトマスター検定 1級

## 概要
フォトマスター検定 1級は、写真とカメラに関する高度な実用知識と技法を問う、写真愛好家やプロフェッショナルを目指す人のための検定試験です。
撮影技術、カメラのメカニズム、レンズ光学、デジタル処理、写真史、関連法規など、写真に関わる幅広い分野から出題され、実践的な「写真力」を証明します。
1級は「高度な知識・技法」を習得しているレベルと定義されています。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 80分（14:10〜15:30） |
| 問題数 | 80問 |
| 合格ライン | 7割程度以上の正答 |
| 受験料 | 7,600円（税込） |
| 受験資格 | 誰でも受験可能（年齢・性別・学歴・職歴・経験不問） |
| 有効期限 | なし（永久資格） |
| 試験方式 | マークシート方式（筆記試験） |

## 学習範囲・シラバス
- **カメラとレンズのメカニズム**: 構造、機能、光学性能の理解
- **撮影技術・技法**: 露出、構図、ライティング、特殊撮影
- **デジタル写真**: 画像処理、レタッチ、ファイル形式、プリンター
- **フィルム写真**: フィルムの種類、現像、特性
- **周辺機器**: ストロボ、三脚、フィルターなどの活用
- **写真史・写真家**: 歴史的な流れ、主要な写真家とその作品傾向
- **関連法規・マナー**: 著作権、肖像権、撮影マナー
- **実践問題**: 写真や図版を見て解答する形式が含まれます

## 難易度・勉強時間目安
- **難易度**: 上級
    - 専門用語の正確な理解と、状況に応じた撮影設定の判断能力が求められます。
    - 合格率は年度によりますが、比較的高い知識レベルが必要です。
- **勉強時間**:
    - 経験者: 50〜100時間程度
    - 初学者: 150時間以上（基礎から積み上げる場合）
    - 公式テキストや過去問題集を中心とした学習が推奨されます。
