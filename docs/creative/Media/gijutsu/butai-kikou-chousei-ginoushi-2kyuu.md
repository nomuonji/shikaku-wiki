# 舞台機構調整技能士 2級

## 概要
舞台機構調整技能士は、劇場やホールなどの舞台における音響機構の調整・操作に関する技能を認定する国家資格（技能検定）です。
2級は、中級の技能労働者が通常有すべき技能の程度と定義されており、音響機器のセッティング、調整、ミキシング操作など、実務において指導的な立場に立ちうる技能が求められます。
プロの音響エンジニア（PAエンジニア）としての一つの目安となる資格です。

確認日: 2026-10-01（JAVADA公表資料を参照）

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験方式 | 学科試験および実技試験。実技は製作等作業試験（ミキシング作業）70点＋判断等試験（ヒアリングテスト）30点 |
| 学科試験 | 2級は真偽法及び四肢択一法、50題、1時間40分（JAVADA「学科試験の概要」） |
| 実技試験の時間 | 実施期ごとの「実技試験問題の概要」で公表される。固定の総所要時間としての「約20〜30分」は現行概要にない |
| 合格ライン | 原則として学科：65点以上（100点満点）、実技：60点以上（100点満点） |
| 受検料 | 標準額は実技：18,200円、学科：3,100円。実際額は都道府県職業能力開発協会が定める |
| 受検資格 | 2級の基準は実務経験2年以上。学歴・職業訓練等で短縮される場合がある |
| 有効期限 | なし（永久資格） |
| 実施 | 受検申請・試験実施・合格発表は各都道府県職業能力開発協会。JAVADA本部は受付・実施を行わない |

## 学習範囲・シラバス
- **学科試験**
    - 音響理論（音の性質、電気音響）
    - 舞台機構・設備（音響機器、舞台用語、関連法規）
    - 電気理論・電子回路
    - 安全衛生
    - 音楽概論
- **実技試験（音響機構調整作業、1級・2級）**
    - **製作等作業試験（ミキシング作業）**（70点）: セッティング、ミキシング（本番）、作業動作・作業態度など
    - **判断等試験（ヒアリングテスト）**（30点）: 音源の聞き分け・音質等の判別

旧称の「要素試験」「作業試験」ではなく、現行の公式用語は判断等試験（旧要素試験）と製作等作業試験です。

## 難易度・勉強時間目安
- **難易度**: 中級
    - 実技試験では、迅速かつ正確な機器操作と、適切な音響バランスを作る感性が求められます。
    - 筆記試験は過去問対策である程度対応可能ですが、音響理論の基礎理解が必要です。
- **勉強時間**:
    - 経験者: 50時間〜（試験対策中心）
    - 実務経験が必要なため、日常業務でのスキル向上が直結します。試験特有の手順（安全確認など）を練習する必要があります。
