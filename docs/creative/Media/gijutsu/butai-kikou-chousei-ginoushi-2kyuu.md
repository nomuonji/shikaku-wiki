# 舞台機構調整技能士 2級

## 概要

舞台機構調整技能士は、劇場やホールなどの舞台機構を調整する技能を検定する国家検定（技能検定）です。このページが扱う作業は音響機構調整作業です。合格すると技能士を名乗れます。2級の合格証書は都道府県知事名で交付されます。

2級が証明するのは、JAVADAが定める「中級の技能労働者が通常有すべき技能の程度」です。指導的立場や雇用条件を保証する資格ではありません。特定の大学を卒業しただけでは資格にはならず、受検資格を満たしたうえで学科と実技の両方に合格する必要があります。

確認日: 2026-10-05（JAVADA技能検定のご案内、学科試験の概要、実技採点項目、厚生労働省の受検資格一覧を参照）

## 2級を選ぶ前に確認すること

先に次の4点を分けて確認します。学歴だけで級が決まるわけではありません。

| 判断 | 2級で見る範囲 | 公式で確認する先 |
| --- | --- | --- |
| 自分は受けられるか | 原則は検定職種の実務経験2年以上。大学・短大・高専・専門高校・職業訓練など、検定職種に関する学歴・訓練歴があると短縮され、該当する場合は2級の実務経験年数が0年になる区分がある | [厚生労働省の受検資格一覧](https://www.mhlw.go.jp/general/seido/syokunou/ginou/aramashi/menjyo.html)。例外と該当学科の判定は都道府県職業能力開発協会 |
| 3級から進むか | 3級は初級の技能程度。関連学科に在学中、または関連訓練を受けている人も受検できる。実務経験が6か月未満でも受検できる | [JAVADAの受検資格](https://www.javada.or.jp/jigyou/gino/giken.html) |
| 1級との差 | 1級は上級の技能労働者が通常有すべき技能の程度。実務経験のみなら7年以上で、学歴により短縮される。合格証書は厚生労働大臣名 | 同上 |
| 実技で何をするか | 1級・2級は製作等作業試験（ミキシング作業）70点と判断等試験（ヒアリングテスト）30点 | [実技試験の採点項目及び配点](https://www.javada.or.jp/ex/jigyou/gino/giken/saitenkoumoku/saitenkoumoku.html) |

普通の大学を出ても、検定職種に関する学科でなければ短縮表の「大学卒業」には当たりません。該当するかどうかは学校名ではなく、厚生労働省の注記と申請先の協会で確認します。

## 1級・2級・3級の受検経路

| 級 | 技能の程度（JAVADA） | 実務経験のみの基準 | 主な短縮・例外 | 合格証書 |
| --- | --- | --- | --- | --- |
| 3級 | 初級の技能労働者が通常有すべき技能の程度 | 平成25年4月以降、6か月未満でも受検可 | 検定職種に関する学科の在学者、関連訓練科で職業訓練を受けている人も受検可 | 都道府県知事 |
| 2級 | 中級の技能労働者が通常有すべき技能の程度 | 2年以上 | 職業訓練歴・学歴で短縮。専門高校、短大・高専、大学などの該当区分では2級の必要実務経験が0年になる行がある | 都道府県知事 |
| 1級 | 上級の技能労働者が通常有すべき技能の程度 | 7年以上 | 専門高校卒業6年、短大・高専・高校専攻科卒業5年、大学卒業4年など。訓練歴でも短縮される | 厚生労働大臣 |

短縮年数は「検定職種に関する」学歴・訓練に限る注記があります。3級合格後に2級を受ける場合の年数も、実務経験のみの2年とは別の列です。この表は基準の読み方であり、個別の受検可否は都道府県職業能力開発協会が申請時に判定します。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験方式 | 学科試験と実技試験。両方の合格が必要。片方のみ合格した場合、次回以降は不合格側だけを受検できる |
| 学科試験 | 2級は真偽法および四肢択一法、50題、1時間40分。3級は真偽法、30題、1時間（JAVADA「学科試験の概要」） |
| 実技試験 | 1級・2級は製作等作業試験（ミキシング作業）70点、判断等試験（ヒアリングテスト）30点。旧称の要素試験・作業試験ではなく、現行用語は判断等試験と製作等作業試験 |
| 実技の時間 | 実施期ごとの「実技試験問題の概要」で公表される。固定の総所要時間は現行概要に書かれていない |
| 合格ライン | 原則として学科65点以上、実技60点以上（いずれも100点満点）。厚生労働省が定める |
| 受検料 | 標準額は実技18,200円、学科3,100円（令和元年度以降の標準金額）。実際の額は都道府県が定める |
| 受検資格 | 2級の基準は実務経験2年以上。学歴・職業訓練で短縮される場合がある |
| 有効期限 | 技能検定の合格に更新期限はない。特級の一部合格の有効期限とは別 |
| 実施 | 受検申請・試験実施・合格発表は各都道府県職業能力開発協会。JAVADA本部は受付・実施を行わない |
| 実施時期 | 前期・後期。公示、申請、実技、学科、合格発表の時期は年度と都道府県で異なる |

令和8年度後期の音響機構調整作業は、都道府県によって実施の有無や「2級のみ」などの条件が分かれます。受ける年の実施公示と、申請する都道府県協会の案内で確認します。

## 実技で評価されること

1級・2級の採点は次の配点です。配点の内訳はセッティング、本番のミキシング、作業動作、作業態度に分かれます。

| 実施形式 | 採点項目 | 配点 |
| --- | --- | --- |
| 製作等作業試験（ミキシング作業） | セッティングの仕様誤り・できばえ、ミキシング（本番）の仕様誤り・できばえ、作業動作、作業態度 | 70 |
| 判断等試験（ヒアリングテスト） | 音の判別 | 30 |
| 合計 |  | 100 |

3級も製作等作業試験（ミキシング作業）70点と判断等試験（ヒアリングテスト）30点です。3級のミキシング作業は、セッティングおよびリハーサル、本番、原状復帰、作業動作、作業態度に分かれます。級が上がると課題の範囲や要求水準が変わるため、3級の課題を2級の課題と同一視しません。課題の詳細は、受検する期の実技試験問題の概要で確認します。

## 申請先と年度の確認手順

1. 受検する都道府県の職業能力開発協会を、[都道府県協会一覧](https://www.javada.or.jp/kyoukai/itiran.html)から選ぶ。
2. その年度の実施公示で、舞台機構調整（音響機構調整作業）の対象級が含まれるか確認する。
3. 受検資格は、[厚生労働省の受検資格一覧](https://www.mhlw.go.jp/general/seido/syokunou/ginou/aramashi/menjyo.html)の該当行を見たうえで、協会の申請案内と照合する。
4. 受検料、申請期間、実技の日時は協会が定める額と日程を使う。JAVADAの標準額や概ねの日程をそのまま申請期限にしない。
5. 学科の形式・問題数・時間は[実施職種・試験概要](https://www.javada.or.jp/jigyou/gino/giken/giken_jisshi_itiran.html)、実技の配点は[採点項目及び配点](https://www.javada.or.jp/ex/jigyou/gino/giken/saitenkoumoku/saitenkoumoku.html)で再確認する。

## 難易度の見方

合格率や必要な勉強時間は、このページの確認日時点で一次資料から再現できないため掲載しません。負荷を見る材料は、学科50題・1時間40分に加えて、実技でセッティングと本番のミキシング、作業動作・作業態度、ヒアリングが採点される点です。筆記だけ、または実技だけでは技能士にはなりません。
