# 日本語検定 2級

## どんな日本語力を測るか

日本語検定2級は、日本語を母語とする人に限らず、日本語を使う人が敬語、文法、語彙、言葉の意味、表記、漢字の力を確かめる検定です。日本語能力試験（JLPT）とは対象や目的が異なります。2級は大学卒業から社会人中級程度を基準とし、新聞の社説や専門分野の文章を読み、場面に合った表現や論理的な文章を使う力を扱います。国語力の証明や、仕事・学習での日本語の振り返りをしたい人に向いています。

## 2026年度の試験と認定基準

公式の受検概要では、2026年第1回の一般会場は11月7日、準会場は11月6日・7日です。申込期間は8月3日から10月9日。2級の受検料は5,800円、試験時間は60分と掲載されています。受験資格に特別な学歴要件はありません。試験日や会場は回ごとに変わるため、申込み時に最新ページを確認してください。

認定基準は2025年度第1回から変更されています。2級は総合得点率70%程度以上が2級認定、60%程度以上が準2級認定です。全領域で50%以上という領域別足切りは撤廃されたと公式案内に明記されています。古い問題集や資格紹介ページには総合75%や領域別50%という旧基準が残っていることがあるので、現在の基準と混同しないでください。採点は得点率で行われ、各領域の成績は学習の弱点把握に使えます。

## 6領域をどう準備するか

試験は敬語、文法、語彙、言葉の意味、表記、漢字の6領域と総合問題で日本語力を見ます。敬語は尊敬語と謙譲語の形だけでなく、誰に対してどの立場から話すかを確認します。語彙や言葉の意味は、辞書的な意味を知るだけではなく、文脈に合う語を選べるかが問われます。表記・漢字では、常用漢字の知識や送り仮名なども復習します。

最初は公式のミニテストで領域ごとの問題を試し、間違いを分類します。敬語だけ弱いのか、似た語の使い分けで迷うのかを分けると、学習を必要以上に広げずに済みます。次に総合問題を時間内に解き、複数領域が混ざった文章でも根拠を持って選べるかを確認します。必修語彙リストや公式問題集は、受検級に対応したものを使ってください。

## 申込時の確認

一般会場と準会場では申込方法や会場が異なります。5人以上の団体受検では学校・会社の施設を会場にする準会場方式も案内されています。受検料の返金条件、結果の返却時期、併願できる級などは公式の受検概要とFAQを確認してください。
