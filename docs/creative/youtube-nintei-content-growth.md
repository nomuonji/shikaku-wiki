# YouTube 認定資格 (YouTube Certified)

## いま知るべきこと（誰が受けられるか／何を証明しないか）

YouTube 認定資格（YouTube Certified）は、一般公開の「YouTuber 資格」ではありません。公式ヘルプによると、2019年10月以降の受講対象は次のどちらかを満たすクリエイターまたはパートナーに限られます。

- YouTube パートナー マネージャーによるサポートを受けている
- Content ID へのアクセス権を持っている

以前にコースへ合格していても、上記条件を満たさなければ再認定の対象外です。申し込みはパートナー マネージャー経由が原則で、マネージャーがいない Content ID パートナーはクリエイター サポートへ問い合わせます。

公式が明示している「証明しないこと」は次のとおりです。

- コース修了は、YouTube がそのクリエイターやパートナーを推奨（endorse）することを意味しない
- YouTube は、修了者が高度なシステムやツールの知識・使い方を習得していることを保証・表明しない
- 個人向け認定バッジの新規付与は終了し、過去のバッジも無効。表示・使用しないこと
- 企業向け認定（YouTube 認定企業）はプログラム改善のため実施を見合わせ中

また、公開の [YouTube クリエイターアカデミー](https://www.youtube.com/creators/) の学習コンテンツや、YouTube パートナープログラム（収益化）の対象条件とも別物です。コース修了がチャンネル成長や収益化を保証するわけではありません。

## 概要
YouTube 認定資格は、条件を満たしたクリエイターやパートナーが、著作権管理や高度な分析など YouTube の高度なシステムやツールを活用できるようにするための一連のコースです。一般の視聴者向け資格や、個人の発信スキルを公式が保証する制度ではありません。

試験はオンラインで実施され、各コースの学習教材を完了した後に受験します。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 2時間 |
| 問題数 | 公式ヘルプは問題数を公開していない |
| 合格ライン | 正答率 75% 以上 |
| 受験料 | 公式ヘルプに受験料の記載なし（参加は招待・パートナー経路） |
| 受験資格 | パートナー マネージャーのサポート、または Content ID へのアクセス権を持つクリエイター／パートナー。加えて Google アカウントと現行の YouTube ポリシー遵守 |
| 有効期限 | 修了証は 18 ヶ月間有効。その後は再受験が必要 |
| 再受験 | 不合格の場合は 24 時間後以降に再受験可能。回数制限の記載なし |
| 試験方式 | オンライン |

## 学習範囲・シラバス
公式のプログラム概要は、ビジネス関連の 4 コースを示しています（「チャンネルの成長」コースは廃止）。

1.  **コンテンツの所有権 (Content Ownership)**
    - YouTube での著作権
    - CMS でのビジネス運営
    - Content ID での権利の行使
    - 対象例: コンテンツ管理者、ビジネス運営者

2.  **アセットの収益化 (Asset Monetization)**
    - 収益向上のためのアセット最適化
    - 収益に関する分析とレポート
    - 対象例: デジタル著作権の管理者、法務担当、ビジネス運営者

3.  **音楽 (Music)**
    - コンテンツ／チャンネル戦略、プロモーション、分析、収益、基本的な著作権管理
    - 対象例: デジタル著作権の管理者、法務担当、アーティスト チャンネル管理者、レーベル担当者

4.  **音楽著作権管理 (Music Rights Management)**
    - YouTube における音楽の著作権
    - 収益向上のためのアセット最適化
    - Content ID の申し立てとポリシー
    - コンテンツ配信とレポート
    - 対象例: デジタル著作権の管理者、法務担当、アーティスト チャンネル管理者、レーベル担当者

音楽パートナーは、該当する場合 SRAV で指定されたコース数を修了する必要があります。

## 難易度・勉強時間目安
- **難易度**: 中級（公式の難易度ラベルではなく、Content ID / CMS 実務寄りの内容であることの目安）
    - 著作権、CMS、Content ID、収益分析などパートナー業務の理解が中心です。
- **勉強時間**:
    - 公式は学習時間の固定値を公開していません。教材を自分のペースで完了してから試験を受けます。
