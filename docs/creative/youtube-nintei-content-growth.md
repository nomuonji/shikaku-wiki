# YouTube 認定資格 (YouTube Certified)

## 概要
YouTube 認定資格 (YouTube Certified) は、クリエイターやパートナーが YouTube の高度なシステムやツールを最大限に活用できるようにするための公式認定プログラムです。
YouTube の著作権管理、収益化、チャンネル成長戦略など、専門的な知識とスキルを証明します。
試験はオンラインで実施され、各コースの学習教材を完了した後に受験します。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 2時間 |
| 問題数 | コースにより異なる（約50〜75問程度） |
| 合格ライン | 正答率 75% 以上 |
| 受験料 | 無料（招待制またはパートナー資格が必要） |
| 受験資格 | YouTube パートナーマネージャーのサポートを受けている、または Content ID へのアクセス権を持つパートナー |
| 有効期限 | 18ヶ月（更新には再受験が必要） |
| 試験方式 | オンライン (CBT) |

## 学習範囲・シラバス
以下の4つの主要コースがあります：

1.  **コンテンツの所有権 (Content Ownership)**
    - YouTube での著作権の仕組み
    - CMS (コンテンツ管理システム) の運用
    - Content ID を使用した権利管理と申し立て
    - 著作権ポリシーと紛争解決

2.  **アセットの収益化 (Asset Monetization)**
    - 広告収益の最大化
    - アセットの最適化とメタデータ管理
    - 収益レポートの分析
    - 広告フォーマットと販売戦略

3.  **音楽 (Music)**
    - 音楽業界向けのチャンネル戦略
    - YouTube Music でのプロモーション
    - 楽曲の著作権管理と収益化
    - 公式アーティストチャンネル (OAC) の活用

4.  **音楽著作権管理 (Music Rights Management)**
    - 音楽出版と録音の権利構造
    - Content ID での音楽アセット管理
    - 楽曲配信とレポート分析

## 難易度・勉強時間目安
- **難易度**: 中級
    - YouTube のシステム（特に Content ID や CMS）に関する実務的な知識が問われます。
    - 資料持ち込み可（オープンブック形式）の場合が多いですが、制限時間があるため理解が必要です。
- **勉強時間**:
    - 各コースの学習教材（動画・テキスト）の消化に 約4〜8時間
    - 実務経験があればスムーズに学習できます。
