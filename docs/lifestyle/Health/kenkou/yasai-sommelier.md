# 野菜ソムリエ

## 概要

野菜ソムリエは、日本野菜ソムリエ協会が認定する**民間資格**です。

野菜・果物の品種、栄養、保存、調理、流通などを学び、その魅力や価値を人に伝える力を身につけることを目的としています。

試験だけを単独で受ける資格ではなく、協会の野菜ソムリエコースを受講し、課題提出と修了試験を経て取得します。

## 取得の流れ

1. 野菜ソムリエコースへ申込
2. 全7科目を受講
3. 課題を提出
4. 修了試験を受験
5. 合格後、認定書発行

受講資格に特別な学歴・職歴要件はなく、どなたでも受講できます。

## 費用・試験

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 民間資格 |
| コース受講料 | 148,000円（税込） |
| 内訳 | 入会金10,800円 + 受講料137,200円 |
| 初回試験料 | 受講料に含む |
| 追試 | 14,800円 |
| 修了試験 | マークシート方式 |
| 試験時間 | 2時間 |

通学・半通学・通信などの受講スタイルがあります。対象コースではWEB試験または協会指定会場の試験を選べます。

## 学習内容

野菜・果物を単に「健康に良い食品」として学ぶのではなく、品種・産地・旬・栄養・保存・調理・流通などを横断して扱います。

仕事で活用する場合は、商品の特徴を説明する力や、生活者に合わせた提案力も重要です。

## 難易度・勉強時間目安

協会FAQでは、野菜ソムリエコースの合格率は**約85%**と案内されています。

一律の標準勉強時間ではなく、講座7科目の受講・課題・復習をセットで進める資格です。

上位資格として「野菜ソムリエプロ」があり、こちらは別コース・別試験で、より専門的な提案・活動を想定しています。
