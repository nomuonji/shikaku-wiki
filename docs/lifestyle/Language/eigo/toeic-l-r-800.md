# TOEIC® Listening & Reading Test 800点突破

## 概要
TOEIC® L&R Testは、英語によるコミュニケーション能力を幅広く評価する世界共通のテストです。
合否ではなく10点から990点のスコアで評価されます。
800点以上のスコアは、英語を使って業務を遂行できるレベルと見なされ、就職・転職活動において大きなアピールポイントとなります。外資系企業や海外部門への異動要件として設定されることも多いラインです。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 約120分（リスニング約45分、リーディング75分） |
| 問題数 | 200問（リスニング100問、リーディング100問） |
| 満点 | 990点 |
| 受験料 | 7,810円（税込） ※割引制度あり |
| 受験資格 | なし |
| 有効期限 | 公式認定証の再発行は試験日から2年間だが、スコア自体の有効期限は定められていない（提出先による） |
| 試験方式 | マークシート方式（全国の会場で年回実施） |

## 学習範囲・シラバス
- **Listening Section (Part 1-4)**
    - 写真描写、応答、会話、説明文
- **Reading Section (Part 5-7)**
    - 短文穴埋め、長文穴埋め、読解（シングル～トリプルパッセージ）

ビジネスシーン（会議、電話、メール、出張、人事など）や日常生活に基づく英語が出題されます。

## 難易度・勉強時間目安
- **難易度**: 中上級 (800点レベル)
    - 基礎的な文法・単語力に加え、速読力と情報処理能力が求められます。
- **勉強時間**:
    - 現在600点の人: およそ 300 ～ 400 時間
    - 現在400点の人: およそ 700 ～ 1000 時間
    - 一般的に100点アップさせるのに200～300時間必要と言われています。
