# TOEIC L&R 800点

## 概要

TOEIC Listening & Reading Testは、英語の「聞く」「読む」力を測るスコア型テストです。

結果は合否ではなく**10〜990点**で示されます。

したがって「800点」は資格の合格ラインではなく、学習・就職・社内制度などで使われる**目標スコアの一つ**です。

## 試験形式

| 項目 | 内容 |
| --- | --- |
| Listening | 100問・約45分 |
| Reading | 100問・75分 |
| 合計 | 200問・約2時間 |
| スコア | 10〜990点 |
| 受験資格 | 特別な制限なし |

ListeningとReadingを合わせた公開テストです。SpeakingやWritingを直接測る試験ではありません。

## 2026年の受験料

公開テストの受験料は、紙の公式認定証を希望するかで異なります。

| 選択 | 受験料（税込） |
| --- | ---: |
| 紙の公式認定証を希望する | 7,810円 |
| 紙の公式認定証を希望しない | 7,700円 |

**デジタル公式認定証は受験者全員に発行**されます。

割引制度や申込条件は変更されることがあるため、受験回の申込画面を確認してください。

## 800点をどう読むか

800点を取ると特定の職種に就ける、または英語業務が必ずできると保証されるわけではありません。

企業、大学、採用制度、昇進制度ごとに必要スコアは異なります。

応募先がTOEICスコアを条件としている場合は、次の点も確認してください。

- 最低スコア
- 受験日の新しさ
- デジタル認定証・紙認定証のどちらが必要か
- TOEIC L&R以外の英語試験も対象か

## 800点を目指す学習

IIBCは「800点には一律○時間必要」という標準勉強時間を設定していません。

現在500点の人と750点の人では、必要な学習内容がまったく異なります。

最初に公式問題・模試で現在値を測り、失点を次のように分解します。

### Listening

- 音を認識できない
- 語彙・表現を知らない
- 文意を追えない
- 設問処理が遅い

### Reading

- 語彙不足
- 文法問題の処理が遅い
- 長文の情報探索が遅い
- Part 7で時間切れになる

「総合800」という数字だけを見るより、Listening / Readingの弱点を別々に改善する方が効率的です。

## スコアの有効期限

TOEIC Program自体が、すべての用途に共通する一律の「資格有効期限」を設定しているわけではありません。

一方、企業・大学などの提出先が「過去○年以内のスコア」のような独自条件を設けることがあります。

提出前に相手側の条件を確認してください。
