# TOEFL iBT 80点（旧スケール）／新4.0目安

## 概要

「TOEFL iBT 80点」は、留学要件などで長く使われてきた**旧0〜120スケールの代表的な基準**です。

ただし、TOEFL iBTは**2026年1月21日から1〜6の新スコアスケール**へ移行しました。現在の受験者は、Reading / Listening / Writing / Speakingの各セクションと総合スコアを0.5刻みの1〜6で受け取ります。

ETSは、旧スケールで「80点」を要件としていた教育機関に対し、新スケールでは**4.0**を一つの推奨目安として示しています。

## 旧80点は新スコアでどのくらい？

| 旧0〜120要件 | ETS推奨の新1〜6要件 | CEFRの目安 |
| ---: | ---: | --- |
| 70 | 3.5 | B1 |
| **80** | **4.0** | **B2** |
| 90 | 4.5 | B2 |
| 100 | 5.0 | C1 |

2026年1月21日以降の新スケールでは、4.0と4.5がCEFR B2、5.0と5.5がC1に対応します。

ただし、**出願先が旧80点を必ず新4.0として扱うとは限りません。** 入学・交換留学・奨学金などのスコア要件は各機関が決めるため、必ず出願先の最新要件を確認してください。

## 2026年からのスコア表示

新スコアは次のように算出されます。

- Reading：1〜6
- Listening：1〜6
- Writing：1〜6
- Speaking：1〜6
- Overall：4セクションの平均を0.5刻みに丸めた1〜6

移行を円滑にするため、**2028年1月までの2年間**は、新1〜6スコアに加えて、比較可能な旧0〜120形式の総合スコアもスコアレポートに表示されます。

つまり2026〜2027年は、大学側・受験者側の双方が新旧スコアを比較しやすい移行期間です。

## 現行TOEFL iBTの試験構成

2026年1月21日以降、ReadingとListeningを含む試験内容が刷新され、適応型の要素が導入されました。

| セクション | 主なタスク | 基準問題数 | 基準時間 |
| --- | --- | ---: | ---: |
| Reading | Complete the Words / Daily Life / Academic Passage | 50 | 約30分 |
| Listening | Response / Conversation / Announcement / Academic Talk | 47 | 約29分 |
| Writing | Build a Sentence / Email / Academic Discussion | 12 | 約23分 |
| Speaking | Listen and Repeat / Interview | 11 | 約8分 |

指示時間を除き、試験全体は**約2時間**です。適応型試験のため、実際の問題数や時間には変動があります。

## 受験方法

TOEFL iBTは主に次の方法で受験できます。

- 認定テストセンター
- TOEFL iBT Home Edition（自宅・オンライン監督）

受験料は受験国・地域によって異なります。ETSの予約画面で日本を選択し、申込時点の料金を確認してください。

## 難易度・勉強時間目安

TOEFLに合否はなく、「必要なスコア」が出願先によって変わります。

旧80点・新4.0はCEFR B2相当の目安ですが、4技能を均等に伸ばす必要があります。総合だけでなく、大学によってはSpeakingやWritingなど**セクション最低点**を設定する場合もあります。

学習では、まず公式模試などで現在値を測り、目標との差をセクション別に分解する方が、固定の「必要勉強時間」を置くより正確です。

## 「80点」という表現を見るときの注意

2026年以降も、古い大学ページ・ブログ・教材には「TOEFL 80」「TOEFL 100」という旧スコアが残っています。

その場合は次を確認してください。

1. その要件が現在も有効か
2. 新1〜6スケールでの要件が別途公表されていないか
3. 旧スコアを受け付ける場合、受験日からの有効期限内か
4. セクション別最低点があるか
