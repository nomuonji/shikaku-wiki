# TOPIK II（韓国語能力試験）4級

## 概要

TOPIK（Test of Proficiency in Korean）は、韓国政府の国立国際教育院が実施する韓国語能力試験です。

TOPIK IIは中・上級レベルを対象とし、取得点数によって3級〜6級に認定されます。

「TOPIK II 4級」という独立した試験を受けるのではなく、**TOPIK IIを受験して4級相当の点数を取る**ことで4級となります。

## PBTの4級基準

| 項目 | 内容 |
| --- | --- |
| 試験 | TOPIK II |
| 分野 | 聞き取り・読解・作文 |
| 問題数 | 聞き取り50・読解50・作文4 |
| 試験時間 | 合計180分 |
| 満点 | 300点 |
| 4級 | 150〜189点 |
| 5級 | 190〜229点 |
| 6級 | 230〜300点 |

PBTのTOPIK IIでは、150点以上190点未満が4級です。

## IBTは点数体系が異なる

TOPIK IIにはPBTのほか、IBTもあります。

IBTは満点・問題数・級認定点がPBTと異なるため、**PBTの150点基準をIBTへそのまま当てはめることはできません。**

受験方式ごとの最新基準を確認してください。

## 4級で求められる力

公式の評価基準では、4級は社会生活に必要な文章や、経済・社会・文化などをテーマとする文章を理解し、内容を推論できるレベルが想定されています。

日常会話だけでなく、新聞記事、説明文、随筆など、より長く抽象度の高い文章を扱います。

## 2026年度

韓国教育部は2026年にTOPIK I・IIについて、PBTを6回、IBTを6回実施する計画を公表しています。

日本国内の実施日・申込期間・受験料は、日本のTOPIK実施団体の当年度案内を確認してください。

## 難易度・勉強時間目安

公式は標準勉強時間を設定していません。

4級を目指す場合、語彙・文法だけでなく、長文読解、聞き取り、作文を同時に伸ばす必要があります。特にTOPIK IIでは作文が独立分野なので、文章構成の練習を後回しにしないことが重要です。
