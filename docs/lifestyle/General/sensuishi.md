# 潜水士

## 概要

潜水士は、労働安全衛生法に基づく**国家免許**です。

潜水器を使い、コンプレッサー・ポンプによる送気やボンベからの給気を受けて行う**潜水業務**に就くために必要です。

水中土木、サルベージ、水産物採取、海洋調査、構造物点検など、仕事として潜水作業を行う場面と関係します。

一般の趣味のスキューバダイビング認定カードとは別制度です。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 国家免許 |
| 受験資格 | 不要 |
| 試験方式 | 学科試験 |
| 問題数 | 40問 |
| 試験時間 | 4時間 |
| 試験手数料 | 8,800円 |
| 実技試験 | なし |

受験資格はありませんが、免許申請時には年齢など法令上の要件があります。

## 試験科目

| 科目 | 問題数 | 配点 |
| --- | ---: | ---: |
| 潜水業務 | 10問 | 30点 |
| 送気、潜降及び浮上 | 10問 | 25点 |
| 高気圧障害 | 10問 | 25点 |
| 関係法令 | 10問 | 20点 |

4科目合計40問です。

## 合格基準

学科試験は次の**両方**を満たす必要があります。

- 各科目の得点が40%以上
- 全科目の合計が60%以上

総合点だけではなく、科目ごとの足切りがあります。

## 2026年度の日程

潜水士試験は全国の安全衛生技術センター等で複数回実施されます。

2026年度（2026年4月〜2027年3月）も地域ごとに複数日程が設定されています。

たとえば関東では2026年4月23日、6月3日、7月16日、9月24日、12月14日、2027年2月8日などが設定されています。

会場によって実施回数が異なるため、受験するセンターの日程を確認してください。

## 学習範囲

### 潜水業務

潜水作業の方法、潜水器、作業計画など。

### 送気・潜降・浮上

送気設備、圧力、浮力、安全な潜降・浮上など。

### 高気圧障害

減圧症、高気圧による身体影響、予防・対応など。

### 関係法令

高気圧作業安全衛生規則など、潜水作業の安全に関する法令。

## 難易度・勉強時間目安

安全衛生技術試験協会は標準勉強時間を設定していません。

実技試験はありませんが、圧力・気体・人体への影響など、潜水特有の物理・生理を理解する必要があります。

公式サイトでは公表試験問題と正答が掲載されているため、学習後は実際の問題で科目ごとの正答率を確認するのが有効です。
