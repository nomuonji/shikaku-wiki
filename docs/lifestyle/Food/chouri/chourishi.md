# 調理師

## 概要

調理師は、**調理師法に基づき都道府県知事が免許を与える国家資格**です。免許を受けた人だけが「調理師」と名乗ることができます。

重要なのは、全国共通の一つの試験だけで取得する資格ではないことです。法律上、主に「指定養成施設を修了するルート」と「2年以上の調理実務を経て調理師試験に合格するルート」があります。

## 取得ルート

### 1. 調理師養成施設を修了する

高校入学資格に相当する学力要件を満たし、都道府県知事が指定する調理師養成施設で1年以上、調理・栄養・衛生に関する必要な知識と技能を修得したうえで、免許を申請します。

### 2. 実務経験 + 調理師試験

法令で定める施設・営業で**2年以上調理の業務に従事**した後、都道府県等が実施する調理師試験に合格し、免許を申請します。

実務経験として認められる施設・業務には条件があるため、勤務年数だけで自己判断せず、受験する都道府県の案内を確認してください。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 国家資格（免許） |
| 免許 | 都道府県知事が交付 |
| 試験実施 | 都道府県知事または指定試験機関 |
| 受験資格 | 主に2年以上の所定の調理実務経験 |
| 試験日・受験料 | 都道府県等により異なる |
| 養成施設ルート | 指定養成施設で1年以上修得後、免許申請 |

全国一律の日程・受験料ではありません。受験地の都道府県または指定試験機関の当年度案内が正本です。

## 学習範囲

厚生労働大臣が定める基準に基づき、調理・栄養・衛生に必要な知識・技能が対象です。具体的な試験科目・出題構成は受験する地域の案内を確認してください。

学習では、料理の作り方だけでなく、食品衛生、栄養、食文化、関係法規などを横断して理解する必要があります。

## 難易度・勉強時間目安

国は標準勉強時間を設定していません。実務経験ルートの受験者は、調理現場での経験があっても、衛生・栄養・法規など座学分野を別途整理する必要があります。

必要な学習量は、勤務先で担当してきた業務と、受験地域の出題範囲への習熟度によって変わります。

## 調理師免許の意味

調理師は名称独占資格です。飲食店で調理業務を行うこと自体が、すべて調理師免許保有者だけに限定されているわけではありません。

その一方で、調理・栄養・衛生の体系的な知識を持つことを示す国家資格であり、給食・外食・宿泊など幅広い調理現場と関連します。
