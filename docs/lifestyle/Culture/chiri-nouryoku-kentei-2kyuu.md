# 地理能力検定 2級（終了済み）

## 概要

地理能力検定は、地理・地図に関する知識を評価していた検定です。

**現在は実施されていません。**

観光庁の資料でも、地理能力検定の実施団体がすでに解散していることが明記されています。

## 現在の状態

| 項目 | 内容 |
| --- | --- |
| 新規受験 | 不可 |
| 実施団体 | 解散済み |
| 現行試験 | なし |
| このページの役割 | 過去資格の記録 |

古い履歴書や制度資料などで「地理能力検定1級・2級」という名称を見かけることがありますが、現在の受験候補にはできません。

## 代替候補：地図地理検定

地図・地理の知識を現在の試験で確認したい場合は、一般財団法人日本地図センターが実施する**地図地理検定**が候補になります。

2026年も地図地理検定の開催案内があり、地図・地理に関する知識を問う現役の検定です。

ただし、地理能力検定2級と地図地理検定は別制度です。過去資格をそのまま置き換えるものではありません。

## 履歴書・資格欄での扱い

過去に地理能力検定2級へ合格している場合、その取得事実自体が消えるわけではありません。

記載する場合は、取得当時の正式名称と取得年月を記載し、現在も実施中の試験であるような表現は避けるのが分かりやすいです。
