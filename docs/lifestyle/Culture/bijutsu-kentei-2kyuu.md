# 美術検定 2級

## 概要

美術検定は、美術史や作品の見方、アートを取り巻く社会・実務的な知識を確認する民間検定です。

2級では、美術史の知識だけでなく、作品や展覧会、美術館、アートに関する実践的な理解も問われます。

## 2026年度試験

| 項目 | 内容 |
| --- | --- |
| 実施方法 | オンライン試験 |
| 受験資格 | 2級は誰でも受験可能 |
| 試験日 | 2026年11月14日・15日 |
| 受験料 | 8,150円（税込） |
| 美術史問題 | 約85問・60分 |
| 実践問題 | 約10問・30分 |
| 合計 | 約95問・90分 |

2026年度の2級は、自宅等のパソコンまたはタブレットからオンラインで受験します。

## 学習範囲

2級では、西洋美術・日本美術などの歴史だけでなく、作品・作家・時代背景を関連づけて理解する力が必要です。

また、実践問題では、美術館・展覧会やアートを社会の中でどう扱うかといった実務寄りの視点も含まれます。

## 難易度・勉強時間目安

主催団体は標準勉強時間を設定していません。

作品画像を見て作家・時代・様式を判断する知識と、美術史を流れとして理解する力の両方が重要です。

単語カードの暗記だけでなく、「作品 → 作家 → 時代 → 社会背景」をつなげて整理すると効率的です。
