# 自転車技士

## 概要

自転車技士は、一般財団法人 日本車両検査協会（VIA）が実施する「自転車組立、検査及び整備技術審査」に合格することで取得できる資格です。

完成車の安全性に直結する組立・検査・整備の技能を、**実技試験と学科試験**の両面から確認します。自転車販売店や整備業務と関連性が高く、単なる知識検定ではなく実務技能を前提とする資格です。

## 受験資格

公式案内では、基準日時点で次の条件が定められています。

- 18歳以上
- 自転車の組立・検査・整備について2年以上の実務経験があること

年度によっては、日本車両検査協会が認定する専修学校の専門課程で2年以上の教育を修了していることを実務経験要件に代える扱いがあります。必ず受験年度の案内を確認してください。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 民間資格 |
| 試験構成 | 実技試験 + 学科試験 |
| 実施時期 | 例年8月頃 |
| 実技 | 自転車の分解・組立など |
| 学科 | マークシート方式 |
| 科目合格 | 前年度に合格した科目は翌年度に限り免除制度あり |

### 実技試験

持参した自転車を七分組の状態から分解し、その後、完成車へ組み立てる試験です。年度ごとの「受験者心得」で細かな条件を確認します。

### 学科試験

主に次の知識が問われます。

- 自転車の構造・機能・性能
- 組立・検査
- 整備
- 規格に関する知識
- 自転車の安全基準

## 2026年度の実施状況

2026年度試験はすでに終了しており、公式サイトでは2026年10月26日に合格発表予定と案内されています。

申請期間・会場は毎年変わります。2026年度は5月19日〜6月1日に受験申請が受け付けられました。

## 難易度・勉強時間目安

標準勉強時間は公表されていません。受験資格自体に実務経験が求められ、実技では実際の分解・組立技能を確認するため、机上学習だけでは完結しません。

学科は公式の手引・過去問題、実技は受験者心得と実技試験のポイントを使い、日常の整備作業を試験手順に合わせて再現できる状態を目標にします。
