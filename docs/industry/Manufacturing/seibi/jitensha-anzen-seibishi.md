# 自転車安全整備士

## 概要

自転車安全整備士は、自転車の点検・整備と、安全利用の指導について専門知識・技能を確認する資格です。

公益財団法人 日本交通管理技術協会が制度を運営し、自転車技士と同じ実技試験を利用しつつ、安全整備士独自の学科・面接試験も行います。

## 2026年度の受験資格

2026年度案内では、次の両方が必要です。

- 2026年9月16日時点で18歳以上
- 自転車の点検・整備および安全利用指導について2年以上の実務経験

単に自転車に乗っている経験ではなく、点検・整備・安全指導に関する実務経験が必要です。

## 試験構成

| 試験 | 内容 |
| --- | --- |
| 実技 | 自転車技士と共通 |
| 学科 | 自転車安全整備士学科 |
| 面接 | 安全利用指導等を確認 |

自転車技士と自転車安全整備士を同時受験することもできます。

## 2026年度

2026年度試験は終了しています。

2026年度は6月1日17時で受験申請を締め切り、受験票は7月上旬に発送されました。

次年度受験では、受験資格の基準日、申請期間、試験地、受験手数料が更新される可能性があるため、最新の受験案内を確認してください。

## 難易度・勉強時間目安

標準勉強時間は公表されていません。

受験資格に2年以上の実務経験が必要なため、机上学習だけで取得する資格ではありません。実技の作業手順、学科知識、安全利用を説明する力をそれぞれ準備します。
