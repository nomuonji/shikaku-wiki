# 電験一種

## 概要

【電験一種】電力分野の最上位。発電・変電の現場で指名される人材に。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格種別 | 国家資格（電気主任技術者。事業用電気工作物の工事・維持・運用の保安監督ができる） |
| 実施団体 | 一般財団法人電気技術者試験センター |
| 受験資格 | なし（学歴・実務経験を問わない。ただし免状交付には実務経験が必要） |
| 試験方式 | 一次試験（筆記・4科目）と二次試験（筆記・記述式）の二段階 |
| 受験料 | 13,800円（インターネット申込）／14,200円（郵送申込） |
| 合格ライン | 一次は各科目60点以上（科目合格制）。二次は総合評価 |

2026年度（令和8年度）の日程は、一次試験が8月30日、二次試験が11月15日です。一次の4科目は理論・電力・機械・法規で、科目合格は翌年・翌々年に持ち越せます。二次の科目は電力・管理と機械・制御です。令和6年度の結果は、一次受験1,433人・合格428人、二次受験720人・合格112人でした（試験センター公表）。

## 難易度と対策

電験一種は電気系資格の最高峰で、二次試験の合格率は1〜2割が近年の目安です。一次は科目合格制を活かして2〜3年計画で突破する受験者が多く、二次は記述式の論述対策が鍵です。取得後は発電所・変電所の主任技術者として選任され、大規模需要家の保安業務や電力コンサルタントとして活躍できます。第三種→第二種→第一種とステップアップするのが王道で、一種保有者は業界内で希少な人材として高く評価されます。
