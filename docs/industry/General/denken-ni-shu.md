# 電験二種（第二種電気主任技術者）

## 概要

電験二種は、正式には**第二種電気主任技術者**といい、電圧17万ボルト未満の事業用電気工作物の主任技術者として必要な知識を確認する国家試験です。発電所・変電所・工場・ビルなどの電気設備を安全に運用するための専門資格で、一次試験と二次試験の両方を突破する必要があります。

「高圧設備に関わる資格」というだけでなく、電力・設備管理の設計、保安、更新計画などを技術的に判断するための幅広い知識が問われます。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 国家資格 |
| 試験構成 | 一次試験 + 二次試験 |
| 一次試験 | 理論・電力・機械・法規の4科目、多肢選択方式 |
| 二次試験 | 電力・管理、機械・制御の2科目、記述方式 |
| 受験資格 | 試験自体に年齢・学歴等の制限なし |
| 2026年度一次試験 | 2026年8月30日 |
| 2026年度二次試験 | 2026年11月15日 |
| 2026年度受験手数料 | インターネット 13,800円 / 書面 14,200円（非課税） |

二次試験を受験できるのは、同年度の一次試験合格者または一次試験免除者です。

## 学習範囲・試験科目

一次試験は4科目で構成されます。

- **理論**：電気理論、電子理論、電気・電子計測
- **電力**：発変電、送配電、電気材料、設備の設計・運用
- **機械**：電気機器、パワーエレクトロニクス、自動制御、メカトロニクスなど
- **法規**：電気法規と電気施設管理

二次試験では、計算過程や判断根拠を記述する力まで問われます。

- **電力・管理**
- **機械・制御**

## 科目合格制度

一次試験は科目別に合否が決まります。一部科目だけ合格した場合、その科目は翌年度・翌々年度に申請によって免除されます。3年間で一次4科目をそろえる設計が可能です。

二次試験には科目合格制度はありません。ただし、一次試験に合格した年度の二次試験が不合格だった場合、翌年度は一次試験の免除を受けられます。

## 難易度・勉強時間目安

電験二種は、一次試験だけでも電気系4分野を横断し、二次試験では記述式の計算・論述まで求められるため、電気系資格の中でも学習範囲が広い試験です。

実施団体は「標準勉強時間」を公表していません。必要時間は、電験三種レベルの知識、電気系の学歴、実務経験、数学力によって大きく変わるため、固定時間ではなく過去問の到達度で計画するのが安全です。

## 2026年度情報

2026年度の申込期間は5月18日〜6月4日、一次試験は8月30日に実施されました。二次試験は11月15日の予定です。

年度ごとに日程・料金が変わる可能性があるため、次年度受験者は必ず最新の受験案内を確認してください。
