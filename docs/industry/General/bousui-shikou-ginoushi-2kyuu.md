# 防水施工技能士 2級

## 概要

防水施工技能士は、建築物への水の侵入を防ぐ防水工事について技能を評価する**国家検定「技能検定」**です。

2級は中級技能者相当の水準で、実技試験と学科試験の両方に合格する必要があります。

「防水施工」には複数の作業区分があるため、単に「防水2級」とだけ理解せず、自分が受検する作業の種類を確認することが重要です。

## 主な作業区分

防水施工では、年度・実施地域に応じて次のような作業区分があります。

- アスファルト防水工事作業
- 合成ゴム系シート防水工事作業
- 塩化ビニル系シート防水工事作業
- 改質アスファルトシート防水工事作業
- ウレタンゴム系塗膜防水工事作業
- アクリルゴム系塗膜防水工事作業
- セメント系防水工事作業
- シーリング防水工事作業
- FRP防水工事作業

実施される作業は地域・年度で異なることがあります。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 国家検定 |
| 等級 | 2級 |
| 水準 | 中級技能者 |
| 試験 | 実技 + 学科 |
| 合格基準の原則 | 実技60点以上・学科65点以上 |
| 実施 | 都道府県・職業能力開発協会 |

2級合格者は「2級防水施工技能士」と称することができます。

## 実技試験

実技は作業区分ごとに異なります。

材料の取扱い、下地処理、施工手順、仕上がり、寸法、作業姿勢、安全性、制限時間など、実際の施工に近い条件で技能が評価されます。

課題は原則として試験前に公表されるため、受検年度の実技課題・採点項目を確認して練習します。

## 2026年度

技能検定は前期・後期に分けて実施されます。防水施工のどの作業を実施するかは都道府県によって異なる場合があります。

受検申請期間、受検料、会場、作業区分は、受検予定地の職業能力開発協会で確認してください。

## 難易度・勉強時間目安

標準勉強時間は定められていません。

実技比重が大きいため、作業経験を試験課題の手順へ落とし込み、時間内に規定品質へ仕上げる反復練習が重要です。
