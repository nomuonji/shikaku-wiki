# 1級電気工事施工管理技士

## 概要

【電気施工1級】受変電から弱電まで管理。更新工事や省エネ提案に強い。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格種別 | 国家資格（建設業法に基づく技術検定。国土交通大臣指定試験機関が実施） |
| 実施団体 | 一般財団法人建設業振興基金 |
| 受験資格 | 実務経験年数（学歴・所有資格で異なる。新受検資格と経過措置の旧受検資格あり） |
| 試験方式 | 第一次検定（マークシート）と第二次検定（記述式）の二段階 |
| 受検手数料 | 第一次 15,800円、第二次 15,800円 |
| 合格ライン | 第一次は60点以上（応用能力問題の条件あり）、第二次は得点60%以上 |

2026年度（令和8年度）の日程は、第一次検定が7月12日、第二次検定が10月18日です。第一次合格で「1級電気工事施工管理技士補」、第二次合格で「1級電気工事施工管理技士」の称号が得られます。令和7年度の結果は、第一次が受験24,821人・合格10,290人・合格率41.5%、第二次が受験9,494人・合格6,607人・合格率69.6%でした。

## 難易度と対策

第一次の合格率は4割前後、第二次は5〜7割が近年の目安で、第二次は施工経験記述の対策が鍵です。取得後は電気工事の監理技術者・主任技術者として配置され、受変電設備や照明・弱電工事の施工管理、工程・安全・品質管理を担います。建設業の技術者不足を背景に需要は高く、資格手当や昇進要件にする企業も多くあります。2級からのステップアップや、電気工事士とのダブル取得も有効です。

## 受験の注意点

申込期間（例年2月中旬〜下旬）が短く、第一次のみ・同時・第二次のみの区分で手数料が異なるため注意してください。受験資格は学歴・実務経験で細かく分かれているため、申込前に建設業振興基金の受検の手引で必ず確認してください。
