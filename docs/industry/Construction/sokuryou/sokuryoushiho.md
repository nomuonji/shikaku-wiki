# 測量士補

## 概要
測量士補は、国土交通省国土地理院が実施する国家資格で、測量士が作成した計画に基づいて実際の測量作業を行う技術者です。
測量機器の操作や現地調査など実務が中心で、土木・建設業界で活躍できます。
土地家屋調査士試験の午前の部が免除されるメリットもあります。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| **試験日程** | 年1回（5月頃） |
| **試験時間** | 3時間 |
| **問題数** | 28問（択一式） |
| **合格基準** | 450点以上 / 700点満点（18問以上正解） |
| **受験資格** | なし（年齢・学歴・実務経験不問） |
| **受験料** | 2,850円 |

## 測量士との違い

| 資格 | 役割 | 難易度 | 合格率 |
| --- | --- | --- | --- |
| **測量士補** | 測量作業の実施 | やや易 | 約30% |
| **測量士** | 測量計画の作成・評価 | 難関 | 約13% |

## 難易度・合格率
- **難易度**: やや易しい (偏差値47程度)
  - 宅建より易しく、賃貸不動産経営管理士と同程度
- **合格率**: 31.4%（2024年度）
  - 過去5年平均: 約30-40%
- **勉強時間**: 約200時間が目安

## メリット
- 土地家屋調査士試験の午前の部が免除
- ドローン測量の導入に役立つ
- 測量業務の実務経験を積める
- 測量士へのステップアップも可能
