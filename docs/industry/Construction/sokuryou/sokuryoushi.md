# 測量士

## 概要
測量士は、国土交通省国土地理院が実施する国家資格で、測量計画の作成・実施の指導・結果の評価など、測量業務全体のマネジメントを行う責任者です。
土木・建設プロジェクトにおいて正確な測量データを提供し、用地取得や設計の精度を向上させる重要な役割を担います。
測量士補より高度な専門知識と応用力が求められる難関資格です。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| **試験日程** | 年1回（5月頃） |
| **試験構成** | 午前:択一式 + 午後:記述式 |
| **試験時間** | 午前2.5時間 + 午後2.5時間 |
| **合格基準** | 午前450点以上(700点満点) かつ 午前+午後910点以上(1400点満点) |
| **受験資格** | なし（年齢・学歴・実務経験不問） |
| **受験料** | 4,250円 |

## 出題範囲
- 測量に関する法規
- 多角測量、GNSS測量
- 水準測量、地形測量
- 写真測量、地図編集
- 応用測量(路線測量、河川測量など)
- 地理情報システム(GIS)

## 測量士補との違い

| 資格 | 役割 | 試験形式 | 合格率 |
| --- | --- | --- | --- |
| **測量士** | 計画作成・指導・評価 | 択一+記述 | 約13% |
| **測量士補** | 計画に基づく作業実施 | 択一のみ | 約31% |

## 難易度・合格率
- **難易度**: 難関 (日商簿記2級、社会福祉士と同程度)
- **合格率**: 13.0%(2024年度、受験者3,717名中485名合格)
  - 過去5年平均: 約12.7%
  - 例年10%前後で推移
- **勉強時間**: 400～600時間が目安
  - 記述試験対策には実務的な応用力が必要
