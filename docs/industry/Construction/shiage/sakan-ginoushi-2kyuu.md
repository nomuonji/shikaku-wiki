# 左官技能士 2級

## 概要

左官技能士は、左官作業の技能レベルを評価する**国家検定「技能検定」**の合格者に与えられる名称です。2級は、左官作業に必要な技能・知識を実技試験と学科試験の両方で確認します。

左官は、壁・床などの下地や仕上げをモルタル、しっくい等で施工する職種です。資格は特定の作業を独占する免許ではありませんが、技能水準を公的に示す手段になります。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 国家検定（技能検定） |
| 検定職種 | 左官 |
| 選択作業 | 左官作業 |
| 試験構成 | 実技試験 + 学科試験 |
| 2級の標準的な受検資格 | 原則2年以上の実務経験 |
| 合否ラインの原則 | 実技60点以上、学科65点以上 |
| 実施主体 | 都道府県職業能力開発協会等 |

学歴や職業訓練歴などによって必要な実務経験年数が短縮される場合があります。受検資格は個別条件で確認してください。

## 実技・学科試験

都道府県職業能力開発協会が実施する技能検定は、原則として実技試験と学科試験の両方に合格する必要があります。

### 実技試験

実際の作業に近い製作等作業試験などで技能を確認します。左官職種の具体的な課題・試験時間は年度の試験問題・実施公示を確認してください。

### 学科試験

都道府県実施職種の1級・2級学科は、真偽式と多肢択一式を組み合わせた出題が基本です。作業法だけでなく、安全衛生や関連知識も含まれます。

## 2026年度の実施

左官は都道府県が実施する技能検定職種に含まれます。2026年度も職種・都道府県ごとに前期・後期の実施状況が異なるため、全国一律の日付ではありません。

受検する都道府県の職業能力開発協会で、申請期間、実技日、学科日、会場を確認してください。

## 受検手数料

厚生労働省が示す都道府県実施職種の目安は、学科3,100円、実技18,200円です。ただし、都道府県や年齢区分等によって異なる場合があります。

## 難易度・勉強時間目安

公式の標準勉強時間はありません。2級は実務経験を前提とする制度であり、座学だけでなく、材料の扱い、鏝さばき、精度、作業手順、安全性など実技の再現性が重要です。

過去問題だけでなく、実技課題の概要と採点上の注意点を確認し、本番と同じ制限時間を意識した練習が必要です。
