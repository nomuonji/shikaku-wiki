# とび技能士 2級

## 概要

とび技能士は、職業能力開発促進法に基づく**国家検定「技能検定」**の「とび」職種に合格した人が名乗れる技能士です。

2級は、JAVADAの制度上「中級の技能労働者が通常有すべき技能の程度」と位置づけられています。

足場、仮設構造物、重量物の運搬・据付など、とび作業に必要な知識と技能を実技・学科の両方で確認します。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 国家検定 |
| 等級 | 2級 |
| 水準 | 中級技能者 |
| 試験構成 | 実技試験 + 学科試験 |
| 合格基準の原則 | 実技60点以上・学科65点以上 |
| 実施 | 都道府県・都道府県職業能力開発協会 |

2級合格者には都道府県知事名の合格証書が交付され、「2級技能士」と称することができます。

## 実技・学科

実技試験は職種ごとに課題が設定されます。技能検定では、製作等作業試験、判断等試験、計画立案等作業試験などが組み合わされることがあります。

学科試験では、とび作業に必要な施工知識、安全衛生、材料・工具などを確認します。

具体的な課題・試験時間は年度ごとの試験概要を確認してください。

## 2026年度

技能検定は前期・後期に分けて実施されます。

2026年度のJAVADA日程では、とび職種は暑熱対応によって実技期間が変更される可能性のある職種として明記されています。

受検する都道府県によって実施有無・会場・申請方法が異なるため、都道府県職業能力開発協会の案内を最終確認してください。

## 難易度・勉強時間目安

2級は中級技能者向けの検定です。国は一律の勉強時間を定めていません。

学科だけでなく実技があるため、作業手順・安全・精度・時間管理を本番課題に近い条件で再現する練習が必要です。
