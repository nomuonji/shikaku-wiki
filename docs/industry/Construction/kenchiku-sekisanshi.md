# 建築積算士

## 概要

建築積算士は、公益社団法人 日本建築積算協会が認定する資格です。設計図書や数量積算基準などを読み取り、建築工事に必要な数量を積算し、工事費を算定するための知識・技術を評価します。

建築プロジェクトの「いくらかかるか」を根拠を持って組み立てる役割に近く、積算事務所、設計事務所、ゼネコン、発注者側のコスト管理などで関連性の高い資格です。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 民間認定資格 |
| 試験構成 | 一次試験（学科）+ 二次試験（実技・記述） |
| 受験資格 | 受験年度の基準日時点で17歳以上（公式規程を確認） |
| 2026年度一次試験 | 2026年10月25日 |
| 2026年度二次試験 | 2027年1月24日 |
| 2026年度受験手数料 | 27,500円 |
| 登録有効期間 | 3年間。更新講習修了により更新 |

一次試験合格者は二次試験へ進みます。一級・二級・木造建築士、建築施工管理技士、建築コスト管理士、建築積算士補など、所定資格の保有者には一次試験免除制度があります。

## 学習範囲・シラバス

公式制度では、建築積算士に次のような知識が求められています。

- 建築生産プロセスと工事発注の仕組み
- 設計図書の構成
- 工事費の構成
- 数量積算基準
- 標準内訳書式
- 市場価格の把握
- データ分析と積算チェック
- 施工技術の概要
- LCC（ライフサイクルコスト）・VE
- 環境配慮

単純な数量拾いだけでなく、設計・施工・発注・コストを横断して理解する必要があります。

## 2026年度の試験

一次試験は2026年10月25日、二次試験は2027年1月24日に予定されています。

二次試験は実技試験と短文記述試験で構成され、2026年度案内では全体で5時間30分の時間割が示されています。一次試験は3時間です。

## 難易度・勉強時間目安

実施団体は一律の標準勉強時間を公表していません。建築図面を読む経験、数量積算の実務経験、施工・材料の知識によって準備量が大きく変わります。

初学者は、まず建築数量積算基準と設計図書の読み方を固め、過去問題で「数量を拾う → 内訳を組む → コストを説明する」流れを確認するのが重要です。

## 資格取得後・更新

試験合格だけでなく、所定の登録を行うことで「建築積算士」の称号が付与されます。登録の有効期間は3年間で、更新講習を修了して更新します。
