# 1級建築施工管理技士

## 概要
1級建築施工管理技士は、建設工事の現場において、施工計画の作成、工程管理、品質管理、安全管理などを行う「現場監督」のトップ資格です。
特定建設業の営業所ごとに必置の「専任技術者」や、大規模工事の「監理技術者」になることができます。
ゼネコンや工務店での昇進・昇格に必須の資格です。

## 試験詳細
試験は「第一次検定（旧・学科）」と「第二次検定（旧・実地）」に分かれています。

| 項目 | 内容 |
| --- | --- |
| 試験日程 | 一次: 6月・10月、二次: 10月 |
| 試験時間 | 一次: 午前2時間30分/午後2時間、二次: 3時間 |
| 合格ライン | 原則として得点率60%以上 |
| 受験料 | 一次: 10,800円、二次: 10,800円 |
| 受験資格 | 学歴や実務経験による要件あり（令和6年度より制度変更あり要確認） |
| 試験方式 | 一次: マークシート、二次: 記述式 |
| 称号 | 一次合格: 技士補、二次合格: 技士 |

## 学習範囲・シラバス
- **第一次検定**: 建築学、施工管理法、法規（四肢択一＋応用能力問題）
- **第二次検定**: 施工管理法（記述式）。経験記述（自身が担当した工事の管理内容）が重要。

## 難易度・勉強時間目安
- **難易度**: 難関（一次合格率 40-50%、二次合格率 40-50%、ストレート合格率は低い）
    - 二次検定の「経験記述」は、自分の実務経験を論理的に文章化する必要があり、対策が必要です。
- **勉強時間**:
    - およそ 200 ～ 400 時間

## 2026年度の受検資格は新旧区分を確認
建築施工管理技術検定では、第一次検定に合格すると「建築施工管理技士補」、第二次検定まで合格すると「建築施工管理技士」の称号につながります。1級第一次検定のみは年度内に19歳以上となる人が実務経験なしで受検できる一方、第二次検定は実務経験等の要件を満たす必要があります。旧制度での学歴・実務経験による受検経路も案内されるため、卒業年度、過去の受検歴、現在の経験年数を申請区分に照らし合わせてください。「1級は誰でも一次を受けられる」ことと「二次まで受検できる」ことは別です。

## 取得後の役割を分けて考える
第一次検定合格だけで監理技術者として扱われるわけではありません。技士の称号、監理技術者等の配置要件、勤務先での職務は関連する法令・実務経験・講習要件によって決まります。現場管理を目指す人は、施工計画・工程・品質・安全のどの業務経験を積めるかを勤務先に確認し、資格取得を実務経験の代替と考えないことが重要です。試験対策は検定問題や合格基準の公表資料を使い、第一次の知識問題と第二次の施工経験記述を別々に練習します。

令和8年度の日程・手数料と受検資格は更新されます。[建設業振興基金の1級建築施工管理技術検定案内](https://www.fcip-shiken.jp/ken1/)で申請区分と最新の手引を確認してください。確認日: 2026-09-24。
