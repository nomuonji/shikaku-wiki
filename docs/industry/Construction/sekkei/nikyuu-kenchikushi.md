# 二級建築士

## 概要

二級建築士は、建築士法に基づく国家資格です。建築物の設計・工事監理を行う専門資格の一つで、扱える建築物の規模・構造には法令上の範囲があります。

試験は「学科の試験」と「設計製図の試験」の二段階です。設計製図へ進むには、学科に合格するか、所定の学科免除要件を満たす必要があります。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 国家資格 |
| 試験構成 | 学科 + 設計製図 |
| 2026年度学科試験 | 2026年7月5日 |
| 2026年度設計製図 | 2026年9月13日 |
| 受験手数料 | 18,500円（非課税、別途決済手数料） |
| 学科 | 建築計画・建築法規・建築構造・建築施工 |
| 設計製図 | 課題に基づく設計製図、試験時間5時間 |

学科は午前に「建築計画・建築法規」、午後に「建築構造・建築施工」が実施されます。2026年度の時間割では、それぞれ3時間です。

## 受験資格

二級建築士の受験資格は、学歴・指定科目の履修・建築実務経験などの組み合わせで決まります。個別ケースの判定が複雑なため、「大学卒なら可」のように単純化せず、必ず建築技術教育普及センターの受験資格ページで確認してください。

木造建築士試験とは同じ受験資格で、両試験は日程が異なるため、それぞれ申込手続きを行えば併願も可能です。

## 学習範囲・シラバス

### 学科

- **建築計画**：計画原論、建築計画、設備など
- **建築法規**：建築基準法を中心とする関係法令
- **建築構造**：構造力学、各種構造、材料など
- **建築施工**：施工計画、各工種、品質・安全管理など

### 設計製図

指定された建築条件・要求室などを読み取り、時間内に設計条件を整理して図面へ落とし込む力が求められます。課題は年度ごとに公表されます。

## 難易度・勉強時間目安

実施機関は標準勉強時間を公表していません。学科4科目の知識に加え、設計製図では時間内に図面を完成させる反復訓練が必要です。

学科と製図は学習の性質が大きく異なるため、「学科の知識習得」と「製図の時間管理」を分けて計画するのが実務的です。

## 学科免除

学科合格者には、一定範囲で翌年度以降の学科免除制度があります。免除可能回数や対象年度には条件があるため、受験年の公式案内を確認してください。
