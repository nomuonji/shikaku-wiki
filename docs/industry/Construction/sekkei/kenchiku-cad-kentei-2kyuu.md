# 建築CAD検定 2級

## 概要

建築CAD検定は、一般社団法人 全国建築CAD連盟（AACL）が実施する民間検定です。2級は、CADを使って建築図面を作図する実務的な技能を、長時間の実技試験で確認します。

ソフトウェア固有の操作知識だけではなく、建築図面を読み取り、要求された図面を正確に作成する力が中心です。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 民間検定 |
| 受験資格 | 規定なし |
| 試験方式 | CADを使用する実技試験 |
| 2級試験時間 | 5時間 |
| 一般受験 | 4月・10月 |
| 一般受験料 | 12,500円（税込） |
| 団体受験 | 4月・7月・10月・1月 |
| 団体受験料 | 12,000円（税込、認定校料金） |

一般受験では、会場のパソコンを使う方式と、自分のノートパソコン・CADソフトを持ち込む方式があります。会場によって対応方式が異なります。

## 学習範囲・求められる力

2級では、建築図面を読み、CADで正確に作図する一連の技能が重要です。

- 建築製図の基本ルール
- 平面・立面など図面情報の読み取り
- 寸法・線種・レイヤー等を整理した作図
- CADソフトを使った正確な入力
- 5時間の試験時間内に完成させる作業計画
- 印刷・出力を見据えた図面の確認

## 難易度・勉強時間目安

実施団体は標準勉強時間を公表していません。CAD未経験者と、日常的に建築CADを使う人では必要な練習量が大きく異なります。

2級は5時間の実技試験なので、知識問題の暗記よりも「指定条件を読み、制限時間内に図面を完成させる」反復練習が重要です。使用予定のCADソフトで過去課題に取り組み、操作速度と作図精度を同時に確認してください。

## 2026年度について

2026年度も一般受験・団体受験の日程が公式サイトで案内されています。会場、申込期間、使用可能なCADソフトなどは受験方式によって異なるため、申込前に年度別実施要項を確認してください。
