# マンション管理士

## 概要
マンション管理士は、マンションの管理組合の管理者（理事長など）や区分所有者からの相談に応じ、管理組合の運営や大規模修繕などに関して専門的な助言・指導を行う国家資格です。
管理業務主任者が「管理会社側」の資格であるのに対し、マンション管理士は「管理組合（住民）側」のコンサルタント資格です。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験日程 | 年1回（11月下旬） |
| 試験時間 | 120分 |
| 問題数 | 50問（四肢択一） |
| 合格ライン | 34問～38問程度 / 50問（相対評価） |
| 受験料 | 9,400円（非課税） |
| 受験資格 | なし |
| 試験方式 | マークシート方式 |

## 学習範囲・シラバス
- 区分所有法、民法、不動産登記法
- マンション管理適正化法
- 標準管理規約
- 建築基準法、都市計画法、設備（水道、電気、消防など）
- 会計、税務

## 難易度・勉強時間目安
- **難易度**: 難関（合格率 7% ～ 9%）
    - 管理業務主任者よりも合格率が低く、問題の深さや法的解釈を問われる内容が多いです。
- **勉強時間**:
    - およそ 500 ～ 600 時間
    - 管理業務主任者合格者は一部免除（5問）があります。
