# 管理業務主任者

## 概要
管理業務主任者は、マンション管理業者（管理会社）が管理組合と管理受託契約を結ぶ際に、重要事項の説明や契約書への記名・押印を行うための国家資格です。
管理会社は、事務所ごとに一定数の管理業務主任者を設置する義務があります。
マンション管理士と試験範囲が重複しており、ダブル受験する人も多い資格です。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験日程 | 年1回（12月上旬） |
| 試験時間 | 120分 |
| 問題数 | 50問（四肢択一） |
| 合格ライン | 34問～38問程度 / 50問（相対評価） |
| 受験料 | 8,900円（非課税） |
| 受験資格 | なし |
| 試験方式 | マークシート方式 |

## 学習範囲・シラバス
- マンション管理適正化法
- 民法、区分所有法
- 標準管理規約、標準管理委託契約書
- 建築基準法、建築設備
- 会計・税務

## 難易度・勉強時間目安
- **難易度**: 中級（合格率 20%前後）
    - 宅建士に近い難易度ですが、設備系の問題が出るのが特徴です。
- **勉強時間**:
    - およそ 200 ～ 300 時間
    - マンション管理士合格者は一部免除（5問）があります。

## 試験合格と主任者としての登録は別
管理業務主任者はマンション管理会社の業務に関わる国家資格です。管理受託契約に関する重要事項の説明や契約書面への記名など、管理会社側の実務に結びつく役割があります。試験に合格したことと、実務で主任者として名乗り業務を行うための登録・主任者証は同じ段階ではありません。合格後に登録要件や実務講習が必要となる場合を含め、勤務先で必要な手続を確認してください。管理組合側で助言するマンション管理士とは立場が異なります。

## マンション管理士との選択・併願
二つの試験はマンション管理に関する法令・建物・管理実務など共通する学習領域を持ちますが、同じ資格ではありません。管理業務主任者は管理会社が契約・業務を進めるための資格、マンション管理士は管理組合などに専門的助言を行う資格という違いがあります。管理会社への就職・社内配置を目指すなら本資格を優先し、組合側の相談支援を志向するならマンション管理士の試験内容と登録制度も比べると選びやすくなります。併願では共通分野と固有分野を分けて計画します。

試験問題、年度の日程、受験手数料、合格後の登録案内は変更がありえます。[マンション管理業協会の試験案内](https://www.kanrikyo.or.jp/kanri/siken.html)と国土交通省の登録案内を確認してください。確認日: 2026-09-24。
