# AWS Cloud Practitioner

## 概要

AWS Cloud Practitionerは、AWS認定資格の中で最も基礎的な位置づけのエントリーレベルの資格です。AWSクラウドの基本的な概念、サービス、セキュリティ、料金モデルなど、幅広い知識が問われます。ITエンジニアだけでなく、営業、企画、マネジメント層など、クラウドに関わるすべての人におすすめの資格です。

## 対象者

- AWSやクラウドの初学者
- ITエンジニアとしてのキャリアをスタートしたい方
- 営業職、プリセールス、マネージャーなど、クラウドの基礎知識が必要な方

## 難易度

- **入門レベル**
- AWS認定資格の中では最も易しいとされています。IT未経験者でも十分に合格を目指せます。

## 学習時間の目安

- 20〜40時間

## 取得するメリット

- AWSクラウドの基本的な仕組みや主要なサービスについて体系的に理解できる
- クラウドを活用した提案や議論がスムーズに行えるようになる
- より上位のAWS認定資格（アソシエイトレベルなど）への足がかりとなる
