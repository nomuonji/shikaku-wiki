# 情報処理安全確保支援士試験 (SC)

## 概要
情報処理安全確保支援士試験（SC）は、サイバーセキュリティに関する専門的な知識・技能を活用して、企業や組織における安全な情報システムの企画・設計・開発・運用を支援する「情報処理安全確保支援士（登録セキスペ）」になるための国家試験です。
情報処理技術者試験の中で「高度試験」に分類され、セキュリティ分野の最難関資格の一つです。
合格後、所定の手続きを経て登録することで、国家資格「情報処理安全確保支援士」の名称を独占的に使用できます。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 午前I：50分、午前II：40分、午後：150分 |
| 問題数 | 午前I：30問、午前II：25問、午後：記述式（4問中2問選択） |
| 合格ライン | 午前I・II、午後ともに60%以上の得点 |
| 受験料 | 7,500円（非課税） |
| 受験資格 | なし |
| 有効期限 | 試験合格自体に期限はないが、登録資格（登録セキスペ）を維持するには定期的な講習受講が必要 |
| 試験方式 | 筆記試験（春期・秋期の年2回実施） |

## 学習範囲・シラバス
- **午前I・II**
    - セキュリティ技術全般、ネットワーク、システム開発、法務など
- **午後試験**
    - セキュリティインシデント対応
    - セキュアなシステム設計・開発
    - ネットワークセキュリティ
    - 暗号技術、認証技術
    - リスク管理、監査

## 難易度・勉強時間目安
- **難易度**: 高度（ITスキル標準 レベル4）
    - 高度な専門知識と、長文の記述問題に対応する国語力・論理的思考力が必要です。
- **勉強時間**:
    - 応用情報(AP)合格者: およそ 200 ～ 400 時間
    - 実務経験者: およそ 50 ～ 100 時間
