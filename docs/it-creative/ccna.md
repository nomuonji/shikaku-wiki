# CCNA (Cisco Certified Network Associate)

## 概要
CCNAは、世界最大手のネットワーク機器メーカーであるCisco Systems社が認定する、ネットワークエンジニアの登竜門的資格です。
ネットワークの基礎、IP接続、セキュリティ、自動化、プログラマビリティなど、現代のネットワークエンジニアに必要なスキルを幅広くカバーしています。
インフラエンジニアを目指すなら「まずはここから」と言われるほど、業界での信頼性と知名度は抜群です。

## 試験詳細
2024年8月20日よりマイナーアップデート（v1.1）が行われ、生成AIやクラウドネットワーク管理などのトピックが追加されました。

| 項目 | 内容 |
| --- | --- |
| 試験番号 | 200-301 CCNA |
| 試験時間 | 120分 |
| 問題数 | 約100問 |
| 合格ライン | 非公開（1000点満点中800～825点程度と言われています） |
| 受験料 | 42,900円（税込） ※為替レートにより変動の可能性あり |
| 受験資格 | なし |
| 試験方式 | CBT（テストセンターまたはオンライン） |

## 学習範囲・シラバス
- **ネットワークの基礎 (20%)**: ルーター、スイッチ、ケーブル、TCP/IPモデル、IPv4/IPv6
- **ネットワークアクセス (20%)**: VLAN、Trunking、EtherChannel、STP、無線LAN
- **IPコネクティビティ (25%)**: ルーティングプロトコル（OSPF）、静的ルーティング
- **IPサービス (10%)**: DHCP、DNS、NAT、NTP、SNMP
- **セキュリティの基礎 (15%)**: VPN、ACL、セキュリティポリシー、L2セキュリティ
- **自動化とプログラマビリティ (10%)**: SDN、REST API、構成管理ツール（Ansible等）、生成AI（v1.1～）

## 難易度・勉強時間目安
- **難易度**: 中級
    - 以前のCCNAより範囲が広がり（無線やセキュリティ統合）、難易度は上がっています。実機（またはシミュレータ）でのコマンド操作の理解が必須です。
- **勉強時間**:
    - 初学者: およそ 200 ～ 300 時間
    - 実務経験者: およそ 50 ～ 100 時間
