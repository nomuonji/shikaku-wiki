# Python 3 エンジニア認定基礎試験

## 概要
Python 3 エンジニア認定基礎試験は、Pythonの文法基礎を問う試験です。
一般社団法人Pythonエンジニア育成推進協会が実施しており、オライリー・ジャパン刊「Pythonチュートリアル」を主教材としています。
AIやデータ分析の需要増に伴い、受験者が急増している人気資格です。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 60分 |
| 問題数 | 40問（四肢択一） |
| 合格ライン | 70%以上（28問以上正解） |
| 受験料 | 11,000円（税込） |
| 受験資格 | なし |
| 試験方式 | CBT（全国のオデッセイコミュニケーションズCBTテストセンター） |

## 学習範囲・シラバス
主教材「Pythonチュートリアル（第4版）」の内容から出題されます。
- 気楽な入門
- Pythonインタプリタ
- 形式ばらないPythonの紹介
- 制御構造ツール（if, for, rangeなど）
- データ構造（リスト, 辞書, タプルなど）
- モジュール
- 入出力
- エラーと例外
- クラス（オブジェクト指向）
- 標準ライブラリ

## 難易度・勉強時間目安
- **難易度**: 初級（合格率 75%～80%）
    - 基礎的な文法理解があれば合格しやすい試験です。
- **勉強時間**:
    - プログラミング経験者: 10 ～ 20 時間
    - 初学者: 30 ～ 60 時間
