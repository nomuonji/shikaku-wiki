# 情報セキュリティマネジメント試験 (SG)

## 概要
情報セキュリティマネジメント試験（SG）は、情報セキュリティマネジメントの計画・運用・評価・改善（PDCA）を通して、組織の情報セキュリティ確保に貢献し、脅威から継続的に組織を守るための基本的なスキルを認定する国家試験です。
ITエンジニアだけでなく、業務部門でセキュリティ管理を担う担当者にも適しています。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 120分（科目A・科目Bまとめて実施） |
| 問題数 | 科目A：48問、科目B：12問 |
| 合格ライン | 総合評価点 600点以上／1,000点 |
| 受験料 | 7,500円（税込） |
| 受験資格 | なし |
| 有効期限 | なし（無期限） |
| 試験方式 | CBT（Computer Based Testing）方式 |

## 学習範囲・シラバス
- **科目A試験 (知識問題)**
    - 情報セキュリティ全般（ISMS、法規、攻撃手法、対策など）
    - 関連分野（ネットワーク、データベース、経営管理など）
- **科目B試験 (実践事例問題)**
    - 情報セキュリティ管理の実践的な事例を用いた問題
    - 状況判断力や対応力が問われます

## 難易度・勉強時間目安
- **難易度**: 初級～中級（ITスキル標準 レベル2）
    - 基本情報技術者試験（FE）と同じレベル2ですが、範囲がセキュリティに特化しているため、非エンジニアでも比較的取得しやすいとされています。
- **勉強時間**:
    - 初学者: およそ 100 ～ 200 時間
    - ITパスポート取得者: およそ 50 ～ 100 時間
