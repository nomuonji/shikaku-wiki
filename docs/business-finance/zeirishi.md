# 税理士

## 概要
税理士は、税務に関する専門家として、納税者の代わりに税金の申告を行ったり、税務書類の作成、税務相談に応じたりする国家資格です。
「税務代理」「税務書類の作成」「税務相談」は税理士の独占業務です。
会計事務所や税理士法人での勤務、独立開業、企業の経理財務部門での活躍など、キャリアの幅は広いです。

## 試験詳細

税理士試験は「科目合格制」をとっており、一度に全科目に合格する必要はありません。1科目ずつ受験し、累計で5科目に合格すれば資格取得となります。一度合格した科目は生涯有効です。

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 1科目 120分 |
| 問題数 | 科目により異なる（計算問題と理論記述） |
| 合格ライン | 各科目 満点の60% |
| 受験料 | 1科目: 4,000円、2科目: 5,500円 ... 5科目: 10,000円 |
| 受験資格 | 2023年度より、会計科目は誰でも受験可能。税法科目は学歴・職歴・資格要件あり。 |
| 有効期限 | 合格科目は生涯有効 |
| 試験方式 | 筆記試験（年1回 8月実施） |

## 学習範囲・シラバス
必修科目と選択科目があり、合計5科目の合格が必要です。

- **会計学に属する科目 (必修2科目)**
    - 簿記論
    - 財務諸表論
- **税法に属する科目 (選択必修・選択、計3科目)**
    - 所得税法 または 法人税法（どちらか必ず1科目は合格が必要）
    - 相続税法、消費税法、酒税法、国税徴収法、住民税、事業税、固定資産税

## 難易度・勉強時間目安
- **難易度**: 超難関（合格率 科目ごとに10～20%程度、官報合格率は数%）
    - 1科目ごとのボリュームが非常に大きく、5科目揃えるには数年単位の計画が必要です。
- **勉強時間**:
    - 1科目あたり: 500 ～ 1000 時間
    - 5科目合格トータル: 2500 ～ 5000 時間以上
