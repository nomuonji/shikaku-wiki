# メンタルヘルス・マネジメント®検定試験 II種 (ラインケアコース)

## 概要
メンタルヘルス・マネジメント®検定試験は、働く人々の心の健康管理（メンタルヘルスケア）に関する知識や対処方法を習得する検定です。
大阪商工会議所が主催しています。
II種（ラインケアコース）は、管理監督者（部長、課長、リーダー等）を対象としており、部下のメンタルヘルス不調の予防、早期発見、対応、職場環境の改善などを学びます。
管理職への昇進要件とする企業も増えています。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験日程 | 年2回（11月、3月） |
| 試験時間 | 120分 |
| 問題数 | 50問（四肢択一） |
| 合格ライン | 70点以上 / 100点満点 |
| 受験料 | 7,480円（税込） |
| 受験資格 | なし |
| 試験方式 | マークシート方式（2024年度よりCBT方式も導入予定 ※要確認） |

## 学習範囲・シラバス
II種の到達目標は「部下が不調に陥らないよう普段から配慮し、不調が見受けられた場合には安全配慮義務に則った対応ができる」ことです。
1.  メンタルヘルスケアの意義と管理監督者の役割
2.  ストレスおよびメンタルヘルスに関する基礎知識
3.  職場環境等の評価と改善の方法
4.  個々の労働者への配慮
5.  労働者からの相談への対応（話の聴き方、情報提供等）
6.  社内外資源との連携
7.  心の健康問題をもつ復職者への支援
