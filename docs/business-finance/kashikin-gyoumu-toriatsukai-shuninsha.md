# 貸金業務取扱主任者

## 概要
貸金業務取扱主任者は、貸金業を行う営業所ごとに設置が義務付けられている国家資格です。
貸金業法に基づき、貸付けの契約や取り立て行為が適正に行われるよう助言・指導・監督を行います。
消費者金融会社、クレジットカード会社、信販会社、不動産金融会社などで需要があります。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験日程 | 年1回（11月下旬） |
| 試験時間 | 120分 |
| 問題数 | 50問（四肢択一） |
| 合格ライン | 30問～34問程度 / 50問（相対評価） |
| 受験料 | 8,500円（非課税） |
| 受験資格 | なし |
| 試験方式 | マークシート方式 |

## 学習範囲・シラバス
1.  法及び関係法令（貸金業法、利息制限法、出資法、消費者契約法など）
2.  貸付け及び貸付けに付随する取引に関する法令及び実務（民法、商法、手形小切手法、電子契約法など）
3.  資金需要者等の保護の適正化に関する法令及び実務（個人情報保護法、犯罪収益移転防止法など）
4.  財務及び会計（家計診断、企業会計原則など）

## 難易度・勉強時間目安
- **難易度**: 中級（合格率 30%前後）
    - 宅建士よりやや易しい～同程度と言われますが、民法や貸金業法の詳細な知識が必要です。
- **勉強時間**:
    - およそ 100 ～ 200 時間
