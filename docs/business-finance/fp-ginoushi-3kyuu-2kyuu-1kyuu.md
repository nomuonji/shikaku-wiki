# ファイナンシャル・プランニング技能士 (FP) 1級・2級・3級

## 概要
FP技能検定は、顧客の資産に応じた貯蓄・投資計画の立案・相談（ファイナンシャル・プランニング）に必要な技能を認定する国家資格です。
「金財（きんざい）」と「日本FP協会」の2つの実施団体がありますが、取得できる資格は同じ国家資格「ファイナンシャル・プランニング技能士」です。
家計管理、老後の資金計画、教育資金、住宅ローン、保険、税金、相続など、生活に密着したお金の知識が身につきます。

## 試験詳細

### 3級
FPとしての基礎知識を問う入門レベル。

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 学科 120分、実技 60分 |
| 合格ライン | 学科・実技ともに60%以上 |
| 受験料 | 学科 4,000円、実技 4,000円（計8,000円）※CBT化により変動あり |
| 試験方式 | CBT（2024年度より完全CBT化） |

### 2級
実務レベルの知識が求められます。AFP資格認定の要件にもなります。

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 学科 120分、実技 90分 |
| 合格ライン | 学科・実技ともに60%以上 |
| 受験料 | 学科 5,700円、実技 6,000円（計11,700円） |
| 受験資格 | 3級合格、実務経験2年以上など |
| 試験方式 | ペーパー試験（2025年4月よりCBT移行予定） |

### 1級
極めて高度な知識を要するプロフェッショナルレベル。

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 学科（基礎・応用）計300分、実技（面接または筆記） |
| 合格ライン | 学科 120/200点、実技 60%以上 |
| 受験料 | 学科 8,900円、実技 25,000円（金財面接）/ 20,000円（FP協会筆記） |
| 受験資格 | 2級合格＋実務経験1年以上、実務経験5年以上など |

## 学習範囲・シラバス
以下の6分野から出題されます。
1.  **ライフプランニングと資金計画**: 社会保険、年金、教育資金、住宅ローンなど
2.  **リスク管理**: 生命保険、損害保険など
3.  **金融資産運用**: 株式、債券、投資信託、外貨、金融経済の仕組みなど
4.  **タックスプランニング**: 所得税、住民税、法人税など
5.  **不動産**: 不動産取引、法令、税金、有効活用など
6.  **相続・事業承継**: 相続税、贈与税、遺産分割、事業承継など

## 難易度・勉強時間目安
- **3級**:
    - 難易度: 初級
    - 勉強時間: 80 ～ 150 時間
- **2級**:
    - 難易度: 中級
    - 勉強時間: 150 ～ 300 時間
- **1級**:
    - 難易度: 上級
    - 勉強時間: 400 ～ 600 時間以上
