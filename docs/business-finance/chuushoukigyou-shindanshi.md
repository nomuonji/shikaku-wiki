# 中小企業診断士

## 概要
中小企業診断士は、中小企業の経営課題に対応するための診断・助言を行う専門家であり、「経営コンサルタント」の唯一の国家資格です。
経営戦略、財務・会計、運営管理、法務、マーケティング、ITなど、ビジネス全般に関する広範な知識が求められます。
企業内での昇進・昇格、転職、独立開業など、多様なキャリアパスに活かせる資格として人気があります。

## 試験詳細
試験は第1次試験（筆記）と第2次試験（筆記・口述）の2段階で行われます。

| 項目 | 内容 |
| --- | --- |
| 試験日程 | 1次: 8月上旬頃、2次筆記: 10月下旬頃、2次口述: 1月下旬頃 |
| 合格ライン | 1次: 総点60%以上かつ各科目40%以上、2次: 総点60%以上かつ各科目40%以上 |
| 受験料 | 1次: 14,500円、2次: 17,800円 |
| 受験資格 | なし（誰でも受験可能） |
| 試験方式 | 1次: マークシート、2次: 記述式・口述 |
| 有効期限 | 1次合格は翌年度まで有効（一部科目合格制度もあり） |

## 学習範囲・シラバス
**第1次試験 (7科目)**
1.  経済学・経済政策
2.  財務・会計
3.  企業経営理論（経営戦略論、組織論、マーケティング論）
4.  運営管理（生産管理、店舗・販売管理）
5.  経営法務（知的財産権、会社法など）
6.  経営情報システム
7.  中小企業経営・中小企業政策

**第2次試験 (4事例)**
実際の企業事例を元にした診断・助言を論述。
- 事例I: 組織・人事
- 事例II: マーケティング・流通
- 事例III: 生産・技術
- 事例IV: 財務・会計

## 難易度・勉強時間目安
- **難易度**: 難関（最終合格率 4%程度）
    - 1次試験の合格率が20-30%、2次試験の合格率が18-19%程度です。
- **勉強時間**:
    - およそ 1000 時間
    - 1次試験で体系的な知識をインプットし、2次試験で論理的思考力と記述力を鍛える必要があります。
