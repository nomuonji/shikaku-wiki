# 薬剤師

## 概要

薬剤師は、薬剤師法に基づき、調剤、医薬品の供給その他薬事衛生を担う**国家資格**です。

薬局・病院での調剤や服薬指導だけでなく、製薬企業、行政、医薬品卸など幅広い領域で専門知識が使われます。

国家試験へ合格した後、薬剤師名簿への登録・免許申請を経て薬剤師免許を取得します。

## 第112回国家試験

| 項目 | 内容 |
| --- | --- |
| 試験日 | 2027年2月20日・21日 |
| 受験手数料 | 6,800円 |
| 試験地 | 北海道・宮城・東京・石川・愛知・大阪・広島・徳島・福岡 |
| 合格発表 | 2027年3月25日 |
| 実施 | 厚生労働省 |

試験は2日間にわたって実施されます。

## 受験資格

標準的な受験ルートは、大学の**6年制薬学課程**を修めて卒業することです。受験年度に卒業見込みの人も、所定の要件で出願できます。

海外の薬学校卒業者や外国の薬剤師免許保有者などには、厚生労働大臣による受験資格認定の制度があります。

薬学部であっても教育課程によって国家試験受験資格との関係が異なるため、進学時は課程を確認してください。

## 試験科目

薬剤師国家試験は、必須問題と一般問題に分かれています。

主な領域は次のとおりです。

- 物理・化学・生物
- 衛生
- 薬理
- 薬剤
- 病態・薬物治療
- 法規・制度・倫理
- 実務

一般問題には、薬学理論問題と薬学実践問題があります。

単純な用語暗記だけでなく、病態、薬物療法、処方、患者情報を結びつけて判断する力が必要です。

## 合格基準の見方

薬剤師国家試験の合格判定は、単一の固定得点率だけでは決まりません。

厚生労働省が試験回ごとに合格基準を公表するため、過去回の得点を次回の確定基準として扱わないことが重要です。

参考として、第111回（2026年実施）は受験者12,774人、合格者8,749人、全体合格率68.49%でした。これは第112回の合格率を予測する数字ではありません。

## 難易度・勉強時間目安

厚生労働省は国家試験対策の標準勉強時間を設定していません。

6年制薬学教育の講義・実習を前提とするため、一般的な資格試験のように独学時間だけで難易度を表すことは適切ではありません。

学習では、必須問題の基礎知識、理論問題の根拠理解、実践問題の患者・処方判断を分けて弱点を確認します。

## 合格後

試験合格後は薬剤師免許の申請が必要です。

国家試験合格と薬剤師名簿への登録は別手続なので、勤務開始時期を考慮しながら必要書類を準備します。
