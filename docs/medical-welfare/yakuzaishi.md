# 薬剤師

## 概要
薬剤師は、医薬品全般についての幅広い知識を持つ「薬の専門家」です。
調剤、医薬品の供給、薬事衛生をつかさどることにより、国民の健康な生活を確保することを任務とする国家資格です。
6年制の薬学部を卒業することで受験資格が得られます。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験日程 | 年1回（2月下旬、2日間） |
| 試験時間 | 2日間で実施 |
| 問題数 | 必須問題90問、薬学理論問題105問、薬学実践問題150問（計345問） |
| 合格ライン | 総得点の65%程度（配点や足切り条件あり） |
| 受験料 | 6,800円 |
| 受験資格 | 6年制薬学課程を修了した者（または卒業見込みの者） |
| 試験方式 | マークシート方式 |

## 学習範囲・シラバス
- 物理・化学・生物
- 衛生
- 薬理
- 薬剤
- 病態・薬物治療
- 法規・制度・倫理
- 実務

## 難易度・勉強時間目安
- **難易度**: 難関（合格率 70%前後）
    - 6年間の専門教育を受けた上での合格率であり、試験範囲は膨大です。国家試験合格率は大学によって差があります。
- **勉強時間**:
    - 薬学部での6年間の学習に加え、国家試験直前期は1日10時間以上の学習が必要です。
