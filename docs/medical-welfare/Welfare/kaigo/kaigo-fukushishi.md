# 介護福祉士

## 概要

【介護福祉士】介護の専門性を証明。チームケアの中心として信頼を得る。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格種別 | 国家資格（社会福祉士及び介護福祉士法に基づく名称独占） |
| 実施団体 | 公益財団法人社会福祉振興・試験センター |
| 受験資格 | 実務経験3年以上＋実務者研修修了、福祉系高校卒業、養成施設卒業などのいずれか |
| 受験手数料 | 18,380円（第38回） |
| 試験方式 | 筆記試験（125問・マークシート）＋実技試験（筆記合格者のうち実技免除対象外の方が対象） |
| 合格ライン | 総得点の60%程度が目安（問題の難易度で補正あり） |

第38回（2026年1月25日実施）の結果は、受験者78,469人、合格者54,987人、合格率70.1%でした。第38回から「パート合格制度」が導入され、合格基準を満たしたパートは翌年・翌々年の受験で免除されます。近年の合格率は65〜84%で推移しており、実務経験者には比較的取得しやすい国家資格です。

## 受験ルートと注意点

主な受験ルートは、介護現場で3年以上働き実務者研修を修了する「実務経験ルート」です。実務者研修は原則として試験前年度の3月末までに修了している必要があります。EPA（経済連携協定）による外国人介護福祉士候補者の受験も増えており、第38回では外国人受験者が1万人を超えました。

受験申込は例年8月上旬〜9月上旬で、合格発表は翌年3月中旬です。受験手数料のほか、合格後の登録には登録免許税・手数料が別途必要です。日程・費用は回ごとに公表されるため、申込前に試験センターの公式発表を必ず確認しましょう。実務者研修の修了期限も併せて確認してください。
