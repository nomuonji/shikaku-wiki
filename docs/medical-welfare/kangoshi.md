# 看護師

## 概要
看護師は、傷病者やじょく婦（産後の女性）に対する療養上の世話、または診療の補助を行う国家資格です。
病院、診療所、訪問看護ステーション、介護施設など、医療・福祉の現場で中心的な役割を担います。
超高齢社会において、今後ますます需要が高まる専門職です。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験日程 | 年1回（2月中旬） |
| 試験時間 | 午前: 2時間40分、午後: 2時間40分 |
| 問題数 | 必修問題50問、一般問題130問、状況設定問題60問（計240問） |
| 合格ライン | 必修問題は80%以上（絶対評価）、一般・状況設定問題は変動（相対評価） |
| 受験料 | 5,400円 |
| 受験資格 | 看護師養成所（大学、短大、専門学校）を卒業する見込みの者など |
| 試験方式 | マークシート方式 |

## 学習範囲・シラバス
- 人体の構造と機能
- 疾病の成り立ちと回復の促進
- 健康支援と社会保障制度
- 基礎看護学
- 成人看護学
- 老年看護学
- 小児看護学
- 母性看護学
- 精神看護学
- 在宅看護論
- 看護の統合と実践

## 難易度・勉強時間目安
- **難易度**: 中級（合格率 90%前後）
    - 新卒者の合格率は非常に高いですが、必修問題で8割（40/50点）取れないと即不合格になるため、基礎知識の漏れは許されません。
- **勉強時間**:
    - 学校のカリキュラム内での学習に加え、最終学年での集中的な国試対策（300～500時間）が必要です。
