# 看護師

## 免許と国家試験

看護師は、厚生労働大臣の免許を受けて、療養上の世話や診療の補助を行う職種です。患者や家族に関わる仕事であり、国家試験の合格だけでは免許取得が完了しません。看護師名簿への登録と免許申請が必要です。

受験資格は、指定された大学、学校、養成所などで看護師になるために必要な教育課程を修めた人、または試験日までに修業を終える見込みの人などに限られます。海外の看護師学校を卒業した人や外国免許を持つ人には別の認定手続きがあります。進学前の人が試験だけを直接受けることはできません。入学を検討する場合は、学校が受験資格につながる指定課程かを確認してください。

## 2026年の試験と合格基準

第115回看護師国家試験は2026年2月に実施され、厚生労働省の発表では受験者59,614人、合格者52,666人、合格率88.3%でした。新卒者の合格率は94.1%です。この数字は第115回の実績で、次回の合格率を示すものではありません。

第115回の合格基準は必修問題40点以上/50点、一般問題・状況設定問題166点以上/249点の両方を満たすことでした。毎回の合格基準点は厚生労働省が公表する結果資料で確かめてください。問題数、採点除外問題、基準点の扱いは回により変わるため、過去の点数を次回にそのまま当てはめないでください。

## 学習と出願の準備

看護教育では人体の構造と機能、基礎・成人・老年・小児・母性・精神・在宅看護、社会保障などを学びます。国家試験対策では、全領域の知識に加え、状況設定問題で患者の状態と看護上の優先度を結び付ける練習が要ります。公式が保証する勉強時間や合格可能性はありません。

出願時は、学校の卒業見込証明書等、写真や受験願書などの提出物と期限を確認します。合格後は免許申請のための書類・登録手続きが別にあります。受験資格認定者は、認定書の原本など個別の提出条件を施行案内で確認してください。
