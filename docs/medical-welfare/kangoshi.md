# 看護師

## 概要

看護師は、保健師助産師看護師法に基づき、厚生労働大臣の免許を受けて、傷病者・褥婦への療養上の世話や診療の補助を行う**国家資格**です。

国家試験は誰でも直接受けられるものではなく、指定された大学・学校・養成所などで必要な教育課程を修めることが基本ルートです。

国家試験に合格した後、免許申請と看護師名簿への登録を経て看護師免許を取得します。

試験会場の詳細は受験票で案内されます。

## 受験資格

代表的な受験ルートは、文部科学大臣・都道府県知事等が指定する大学、学校、看護師養成所などで、看護師になるために必要な教育を修めることです。

海外の看護師学校卒業者や外国の看護師免許を持つ人には、別途、厚生労働大臣による受験資格認定の制度があります。

進学前に「国家試験受験資格につながる課程か」を必ず確認してください。

## 試験科目

第116回の試験科目は次のとおりです。

- 人体の構造と機能
- 疾病の成り立ちと回復の促進
- 健康支援と社会保障制度
- 基礎看護学
- 地域・在宅看護論
- 成人看護学
- 老年看護学
- 小児看護学
- 母性看護学
- 精神看護学
- 看護の統合と実践

知識だけでなく、患者の状態に応じて優先すべき看護を判断する状況設定問題も重要です。

## 合格基準の見方

看護師国家試験では、必修問題と一般問題・状況設定問題にそれぞれ合格基準があります。

合格基準点は試験回ごとに厚生労働省が発表します。

たとえば第115回では、必修問題40点以上 / 50点、一般問題・状況設定問題166点以上 / 249点が基準でした。これは第116回の確定基準ではありません。

過去回の点数をそのまま次回の合格ラインとして扱わないでください。

## 難易度・勉強時間目安

厚生労働省は国家試験対策の標準勉強時間を設定していません。

看護師国家試験は、数年間の看護教育を前提とした試験です。一般資格のように「独学○時間」で取得するものではありません。

国家試験対策では、学校で学んだ各領域を横断して復習し、必修問題の取りこぼしを減らしながら、状況設定問題で優先順位を判断する練習を進めます。

## 合格後

国家試験合格だけでは免許登録は完了しません。

合格後に免許申請を行い、看護師名簿へ登録されることで免許が交付されます。就職時期と免許登録の手続を見越して必要書類を準備してください。
