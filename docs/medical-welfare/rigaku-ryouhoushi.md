# 理学療法士 (PT)

## 概要
理学療法士（PT）は、ケガや病気などで身体に障害のある人に対し、基本的動作能力（座る、立つ、歩くなど）の回復を図るため、運動療法や物理療法（温熱、電気、マッサージ等）を行うリハビリテーションの専門職（国家資格）です。
「動作の専門家」として、病院、リハビリテーションセンター、介護老人保健施設などで活躍します。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験日程 | 年1回（2月下旬） |
| 試験時間 | 午前: 2時間40分、午後: 2時間40分 |
| 問題数 | 一般問題160問、実地問題40問（計200問） |
| 合格ライン | 総得点の60%以上、かつ実地問題で35%以上の得点（年度により補正あり） |
| 受験料 | 10,100円 |
| 受験資格 | 指定の養成校（3年以上）を卒業する見込みの者など |
| 試験方式 | マークシート方式 |

## 学習範囲・シラバス
- **一般問題**: 解剖学、生理学、運動学、病理学概論、臨床心理学、リハビリテーション医学、臨床医学大要、理学療法概論
- **実地問題**: 運動学、臨床心理学、リハビリテーション医学、臨床医学大要、理学療法

## 難易度・勉強時間目安
- **難易度**: 中級（合格率 80%～90%）
    - 養成校できちんと学習していれば合格できるレベルですが、解剖学や運動学などの基礎医学知識は非常に重要です。
- **勉強時間**:
    - 実習を含めた3～4年間の専門教育が必要です。

## 国家試験を受けるまでに必要なこと
理学療法士は、けがや病気、加齢などによって移動や基本動作に困難がある人に、医師の指示のもとで運動療法・物理療法等を行う医療専門職です。国家試験は誰でも申し込める一般資格試験ではなく、文部科学大臣等が指定する学校・養成施設で所定の教育課程を修了することが基本の受験要件です。高校卒業後に養成校へ進み、学内実習・臨床実習を経て卒業見込みとなる段階で受験します。進学を考える人は、養成校の修業年限、国家試験対策、実習場所、学費・通学期間を先に比較してください。

## 作業療法士との違い
理学療法士は、立つ・歩くなど基本動作の回復や維持を主に支援します。作業療法士は、食事や着替え、仕事、余暇といった生活行為への参加を支援します。現場では職種が連携するため、どちらが優れているかではなく、関心のある支援対象と訓練内容で進路を選ぶのが適切です。免許取得後の勤務先も病院だけではなく、介護・福祉、訪問、地域などに広がりますが、個々の採用条件や業務範囲は勤務先で確認します。
