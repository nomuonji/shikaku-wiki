# 管理栄養士

## 概要
管理栄養士は、病気の人や高齢者など、特別な配慮が必要な人に対して、専門的な知識に基づいて栄養指導や給食管理を行う国家資格です。
栄養士の上位資格であり、病院、学校、保健所、介護施設、スポーツ施設などで、「栄養のプロフェッショナル」として活躍します。
厚生労働大臣の免許を受けます。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験日程 | 年1回（2月下旬～3月上旬） |
| 試験時間 | 午前: 10:00～12:25、午後: 13:40～16:20（計約5時間） |
| 問題数 | 200問（五肢択一） |
| 合格ライン | 120点以上 / 200点満点（60%） |
| 受験料 | 6,800円 |
| 受験資格 | 管理栄養士養成課程（4年制大学等）修了、または栄養士養成施設修了＋実務経験（1～3年） |
| 試験方式 | マークシート方式 |

## 学習範囲・シラバス
以下の9科目から出題されます。
1.  社会・環境と健康
2.  人体の構造と機能及び疾病の成り立ち
3.  食べ物と健康
4.  基礎栄養学
5.  応用栄養学
6.  栄養教育論
7.  臨床栄養学
8.  公衆栄養学
9.  給食経営管理論

## 難易度・勉強時間目安
- **難易度**: 中級～難関
    - 管理栄養士養成課程（新卒）の合格率は80～90%と高いですが、既卒（働きながらの受験）の合格率は10～20%程度と低く、実務との両立が課題となります。
- **勉強時間**:
    - 既卒者の場合: およそ 300 ～ 500 時間
