# 医療秘書技能検定 2級

## 概要

【医療秘書】病院の受付や会計で頼られる。言葉づかいも身につく。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 実施団体 | 一般社団法人医療秘書教育全国協議会 |
| 級 | 1級・準1級・2級・3級（年2回実施） |
| 受験資格 | なし（医療秘書をめざす学生・社会人が対象） |
| 受験料 | 2級 6,000円（1級8,000円、準1級7,000円、3級5,000円） |
| 試験方式 | 筆記試験（2級は2時間） |
| 合格ライン | 全体300点中180点以上、かつ各領域で60%以上 |

2026年度の日程は、第76回が6月27日（土）、第77回が11月7日（土）です。出題は領域I（医療秘書実務・医療機関の組織運営・医療関連法規）、領域II（医学的基礎知識・医療関連知識）、領域III（医療事務・レセプト作成・診療報酬点数表）の3領域で、2級は「やや複雑な業務を遂行できる」レベルが求められます。合格した領域は「合格領域有効制度」で次回以降に持ち越せます。

## 難易度と対策

2級は医療事務系の代表的な検定で、病院・クリニックの受付・会計・クラーク職への就職で評価されます。レセプト作成と診療報酬点数表の理解が合否を分けるため、診療報酬改定（2026年度は改定対応で前期日程が例年より約3週間後ろ倒し）への対応も含めた学習が必要です。学習時間の目安は初学者で100〜200時間程度で、医療用語と法規の暗記が中心です。医師事務作業補助者や医療クラークなど関連職種と合わせると就職の幅が広がります。

## 受験の注意点

2025年から領域IIIの問題様式がマークシート形式に改定されており、最新様式での対策が必要です。受験料・日程は年度で変わるため、申込前に医療秘書教育全国協議会の公式発表を確認してください。
