# 救急救命士

## 概要

救急救命士は、救急救命士法に基づく**国家資格**です。傷病者を医療機関へ搬送するまでの間に、医師の具体的な指示の下で一定の救急救命処置を行う専門職です。

消防機関の救急隊員だけを対象にした資格ではありませんが、国家試験を受けるには指定された教育課程・養成課程などの受験資格を満たす必要があります。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 国家資格 |
| 試験実施 | 厚生労働大臣指定の試験機関・日本救急医療財団 |
| 試験形式 | 筆記試験 |
| 2026年第49回試験日 | 2026年3月8日 |
| 2026年第49回受験料 | 30,300円 |
| 試験地 | 北海道・東京都・愛知県・大阪府・福岡県 |
| 合格後 | 厚生労働大臣免許 |

2026年に実施された第49回試験では、受験者3,524人、合格者3,344人、合格率94.9%でした。

## 試験科目

厚生労働省の公告では、次の5分野が試験科目として示されています。

1. 基礎医学（社会保障・社会福祉、患者搬送を含む）
2. 臨床救急医学総論
3. 臨床救急医学各論（一）— 臓器器官別臨床医学
4. 臨床救急医学各論（二）— 病態別臨床医学
5. 臨床救急医学各論（三）— 特殊病態別臨床医学

第49回試験の合格基準は、必修問題44.0点以上 / 55.0点、通常問題132.0点以上 / 220.0点の両方を満たすことでした。

## 主な受験資格ルート

救急救命士国家試験は、誰でも直接受けられる試験ではありません。代表的なルートは次のとおりです。

### 指定養成所・学校で2年以上学ぶ

大学入学資格を持ち、文部科学大臣指定の学校または都道府県知事指定の救急救命士養成所で、2年以上必要な知識・技能を修得するルートです。

### 医療系科目を修めた上で1年以上の養成課程

大学・高専等で厚生労働大臣が指定する科目を修めた上で、指定施設において1年以上学ぶルートがあります。

### 大学で指定科目を修める

大学で厚生労働大臣指定の医学関連科目と臨地実習を修めて卒業するルートです。

### 消防機関などで救急業務経験を積む

所定の救急業務講習を修了し、原則5年以上または救急活動2,000時間以上の実務経験を経た上で、指定養成施設で所定期間学ぶルートがあります。

受験資格は複数の法定ルートに分かれているため、自分の学歴・職歴だけで判断せず、最新の厚生労働省公告を確認してください。

## 難易度・勉強時間目安

国は一律の標準勉強時間を設定していません。

国家試験の前提として養成課程で救急医学・臨床医学・救急救命処置を体系的に修得するため、一般的な資格試験のように「独学で何時間勉強すればよいか」という設計には向きません。

試験対策では、養成課程の復習と国家試験過去問題を組み合わせ、必修問題と通常問題の双方で合格基準を安定して上回れる状態を目指します。

## 2026年以降の受験

2026年9月25日時点で、日本救急医療財団は**第50回救急救命士国家試験の受験案内を2026年10月下旬から配布予定**と案内しています。

次回試験の正確な日程・申請期間・受験料は、最新の厚生労働省公告と日本救急医療財団の案内を確認してください。
