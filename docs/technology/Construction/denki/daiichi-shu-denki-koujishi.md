# 第一種電気工事士

## 概要
第一種電気工事士は、工場、ビル、大型店舗などの大規模な施設（最大電力500キロワット未満の需要設備）の電気工事を行うことができる国家資格です。
第二種電気工事士の範囲（一般住宅等）に加え、高圧受電設備の工事も可能になるため、ビルメンテナンスや建設現場での需要が高い上位資格です。
試験合格後、実務経験（原則3年）を経て免状が交付されます。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験日程 | 年2回（上期・下期）。2026年度上期は学科CBTが4月1日〜5月8日・技能が7月4日、下期は学科CBTが9月11日〜10月18日・学科筆記が10月4日・技能が11月21日 |
| 試験時間 | 筆記: 140分、技能: 60分 |
| 問題数 | 筆記: 50問（四肢択一） |
| 合格ライン | 筆記: 60点以上/100点、技能: 欠陥がないこと |
| 受験料 | 13,000円（インターネット申込・非課税） |
| 受験資格 | なし（免状交付には実務経験が必要） |
| 試験方式 | 学科試験（CBTまたは筆記。上期はCBTのみ）、技能試験（持参工具による実技） |

## 学習範囲・シラバス
- **筆記試験**:
    - 電気に関する基礎理論
    - 配電理論及び配線設計
    - 電気応用
    - 電気機器・蓄電池・配線器具・電気工事用材料・工具並びに受電設備
    - 電気工事の施工方法
    - 自家用電気工作物の検査方法
    - 配線図
    - 法令
- **技能試験**:
    - 配線図で与えられた問題を、支給される材料と持参した工具を使って、制限時間内に完成させる。高圧部分の結線なども含まれる。

## 難易度・勉強時間目安
- **難易度**: 中級～上級（合格率 筆記50%前後、技能60%前後）
    - 筆記は計算問題や高圧設備の知識が必要で、第二種より格段に難しいです。技能も作業量が多く、迅速な施工が求められます。
- **勉強時間**:
    - およそ 100 ～ 200 時間（第二種合格レベルから）
