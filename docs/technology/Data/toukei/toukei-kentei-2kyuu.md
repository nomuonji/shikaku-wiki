# 統計検定 2級

## 概要

統計検定2級は、一般財団法人 統計質保証推進協会が実施する統計学の検定です。

公式には、**大学基礎課程（1・2年次の学部共通）で習得すべき統計学**の知識と活用理解度を確認するレベルとして位置づけられています。

データを集め、仮説を立て、推定・検定・回帰などを使ってデータから結論を導く基本的な統計的問題解決力を扱います。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 民間検定 |
| 試験方式 | CBT |
| 出題形式 | 4〜5肢選択問題 |
| 問題数 | 35問程度 |
| 試験時間 | 90分 |
| 合格水準 | 100点満点中60点以上 |
| 一般受験料 | 7,000円（税込） |
| 学割受験料 | 5,000円（税込） |

統計検定1級以外の従来型PBT試験は2021年で終了し、2級はCBT方式で受験します。

## 出題範囲

主な範囲は次のとおりです。

- 1変数データの要約
- 2変数以上のデータ
- 相関・単回帰
- データ収集法
- 確率
- 確率分布
- 標本分布
- 推定
- 仮説検定
- カイ二乗検定
- 線形モデル
- 実験計画

大学初年度レベルの確率・統計を一通り扱うため、平均・分散だけでなく、推測統計まで理解する必要があります。

## 電卓

試験会場では、四則演算、百分率、平方根などを扱える一般電卓・事務用電卓を1台使用できます。

一方で、関数電卓、プログラム電卓、グラフ電卓、金融電卓、携帯端末等は持ち込めません。

## 難易度・勉強時間目安

実施団体は一律の標準勉強時間を示していません。

高校数学から統計学へ初めて進む人と、大学や業務で確率・統計を学んだ人では必要な時間が大きく違います。

最低限、次の項目を計算問題として自力で処理できる状態を目標にするとよいです。

- 平均・分散・標準偏差
- 確率分布
- 区間推定
- 仮説検定
- 相関・回帰
- カイ二乗検定

## 活かし方

統計検定2級は、データ分析、マーケティング、品質管理、研究、A/Bテストなど、データを根拠に判断する業務の基礎とつながります。

資格を持つだけで特定業務が可能になるものではありませんが、「統計学の基礎を一通り学んだ」ことを示す目安として利用できます。
