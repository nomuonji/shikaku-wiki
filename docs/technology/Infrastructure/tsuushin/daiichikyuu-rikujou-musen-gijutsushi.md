# 第一級陸上無線技術士（一陸技）

## 概要

第一級陸上無線技術士は、電波法に基づく**無線従事者の国家資格**です。

陸上無線技術士の最上位資格で、放送局、無線通信設備、携帯電話基地局など、陸上の無線局における高度な技術操作を扱います。

通称「一陸技」と呼ばれます。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 国家資格 |
| 実施団体 | 日本無線協会 |
| 試験方式 | 多肢選択式 |
| 試験科目 | 4科目 |
| 実施時期 | 原則 年2回（7月期・1月期） |
| 申請 | インターネット |
| 科目合格制度 | あり |

試験科目は次の4科目です。

1. 無線工学の基礎
2. 無線工学A
3. 無線工学B
4. 法規

電子・電気・通信工学と電波法規を広く扱います。

## 2026年度の日程

### 7月期

2026年7月7日〜8日に実施済みです。

### 次回：1月期

- 試験日：**2027年1月19日〜20日**
- 申請期間：**2026年11月1日〜20日**

2026年9月25日時点では、次回申請開始前です。

## 試験手数料の注意

2026年度の当初試験案内では、第一級陸上無線技術士の試験手数料は16,500円と案内されていました。

ただし日本無線協会は、**2026年10月1日から無線従事者国家試験手数料を改定**すると告知しています。

次回1月期の申請は2026年11月なので、過去の16,500円を前提にせず、申込時点の最新料金を確認してください。

## 科目合格・免除

無線従事者国家試験には、過去の科目合格、他資格、認定学校の卒業などによる科目免除制度があります。

自分が免除要件を満たす場合は、申請時に過去の受験番号・資格番号・証明書等が必要になる場合があります。

免除制度は条件が細かいため、最新の試験案内で確認してください。

## 学習範囲

### 無線工学の基礎

電気回路、電子回路、電磁気、計測など、無線工学の基礎となる理論。

### 無線工学A

送信機、受信機、変調、無線設備など。

### 無線工学B

アンテナ、電波伝搬、給電線、測定など。

### 法規

電波法令、無線局の運用、技術基準など。

## 難易度・勉強時間目安

日本無線協会は標準勉強時間を設定していません。

4科目すべてが専門性の高い内容で、特に電気・電子・通信系の数学・物理を使うため、初学者は基礎工学から段階的に学ぶ必要があります。

公式サイトでは過去1年間の試験問題・解答が公開されています。問題レベルを把握してから学習計画を立てるのが有効です。
