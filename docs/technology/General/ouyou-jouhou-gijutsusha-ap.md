# 応用情報技術者試験 (AP)

## 概要
応用情報技術者試験（AP）は、高度IT人材となるために必要な応用的知識・技能をもち、高度IT人材としての方向性を確立した者を対象とした国家試験です。
基本情報技術者試験（FE）の上位資格に位置し、技術的な知識だけでなく、プロジェクトマネジメントや経営戦略などの実務的な能力も深く問われます。
記述式問題が含まれるため、論理的な文章力も求められます。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 午前：150分、午後：150分 |
| 問題数 | 午前：80問（四肢択一）、午後：記述式（11問中5問選択） |
| 合格ライン | 午前・午後ともに60%以上の得点 |
| 受験料 | 7,500円（税込） |
| 受験資格 | なし |
| 有効期限 | なし（無期限） ※合格から2年間は高度試験の午前I試験免除が可能 |
| 試験方式 | 筆記試験（春期・秋期の年2回実施） |

## 学習範囲・シラバス
- **午前試験**
    - テクノロジ系、マネジメント系、ストラテジ系の全範囲から出題（FEより高度な内容）
- **午後試験 (記述式)**
    - 情報セキュリティ（必須）
    - 以下の分野から4問選択：
        - 経営戦略、プログラミング、システムアーキテクチャ、ネットワーク、データベース、組込みシステム開発、情報システム開発、プロジェクトマネジメント、サービスマネジメント、システム監査

## 難易度・勉強時間目安
- **難易度**: 中上級（ITスキル標準 レベル3）
    - 記述式試験があるため、単なる暗記では対応できません。実務経験があると有利です。
- **勉強時間**:
    - FE合格者: およそ 200 ～ 500 時間
    - 初学者（非推奨）: 500時間以上
