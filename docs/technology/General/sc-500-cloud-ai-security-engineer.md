# Microsoft 認定: クラウドおよび AI セキュリティ エンジニア アソシエイト（SC-500）

## まず判断したいこと

AZ-500（Azure Security Engineer Associate）は2026年8月31日に廃止されます。新規受験はできなくなり、旧試験で新規認定を取得することはできません。既存のAZ-500保有者は、個人の認定有効期限までその資格が有効で、退職後に更新することはできません。自動的にSC-500へ変換されるわけではありません。

SC-500は現行の中級ロールベース認定です。ID、データ、アプリケーション、インフラストラクチャを保護し、規制コンプライアンスを維持するため、Azure、ハイブリッド、AI対応環境全体でエンドツーエンドのセキュリティ制御を設計・実装・管理する能力を検証します。単なる名称変更ではなく、AIワークロードの保護とハイブリッド環境への対応が明示的に含まれます。

## 現行試験で問われる範囲

公式ページ（確認日: 2026-10-20）では、試験時間は120分です。評価領域は次の4つです。

- ID、アクセス、ガバナンスを管理する
- ストレージ、データベース、ネットワークをセキュリティで保護する
- セキュリティで保護されたコンピューティング
- セキュリティ体制の管理と監視

日本語を含む複数言語で提供されます。対象経験として、Azureとハイブリッド環境の管理に関する実践的な経験、Microsoft Entra IDに関する深い知識、Microsoft 365管理に関する知識が求められます。

役割には、Microsoft Entra IDとAzure Key Vaultを使ったアクセス保護、セキュリティと規制コンプライアンスの適用、ストレージ・データベース・ネットワークの保護、コンピューティングの保護、AIソリューションの保護、セキュリティ体制の管理と監視が含まれます。

## 経路別の判断

| 状況 | 判断 |
|------|------|
| これから受験する人 | SC-500を受験。公式学習ガイドと予約入口を確認し、現行仕様（120分・4領域）に沿って準備する。 |
| 旧AZ-500教材を持つ人 | 教材のドメインは参考になるが、AIワークロード保護とハイブリッドの範囲が追加されている。公式学習ガイドで差分を確認し、SC-500を受験する。 |
| 既存AZ-500保有者 | 個人の有効期限まで資格はactive。退職後の更新は不可。自動SC-500変換は公式に確認されていないため断言しない。新規受験が必要な場合はSC-500を検討する。 |
