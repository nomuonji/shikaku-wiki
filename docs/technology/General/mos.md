# Microsoft Office Specialist（MOS）

## 概要

Microsoft Office Specialist（MOS）は、Word、Excel、PowerPointなどMicrosoft Office製品の操作スキルを確認する認定資格です。

知識を選択肢で答えるだけの試験ではなく、試験会場のパソコンで実際にOfficeを操作する**実技型CBT**です。

科目は独立しており、Word、Excel、PowerPointなど必要な科目から受験できます。

## 現行試験の概要

MOSはOfficeのバージョンごとに試験が分かれています。

2026年時点では、MOS 365やMOS 2019の各科目が案内されています。

| 項目 | 内容 |
| --- | --- |
| 試験方式 | コンピュータを使った実技試験（CBT） |
| 試験時間 | 50分 |
| 受験資格 | 年齢・国籍の制限なし |
| 一般価格 | 12,980円（税込） |
| 学割価格 | 9,680円（税込） |
| 更新制度 | なし |

受験料は現行の公式料金表に掲載されているWord・Excel・PowerPoint等の主要科目で共通です。

## MOS 365の主な科目

- Word 365
- Excel 365
- PowerPoint 365
- Word 365 エキスパート
- Excel 365 エキスパート

科目ごとに出題範囲が異なります。

たとえばExcel 365では、セルや数式・関数、テーブル、グラフなどを実際に操作します。

## 一般レベルとExpert

### 一般レベル

Officeの主要機能を使って、文書・表計算・プレゼンテーション等を作成・編集する能力を確認します。

### Expert

WordやExcelの高度な機能を扱います。

一般レベルへ先に合格しなければExpertを受けられない、という受験順序の制限はありません。

## 受験方法

2026年時点では、全国一斉試験と随時試験が案内されています。

ただしMOS公式サイトは、**全国一斉試験を2026年12月までで終了する**と告知しています。

今後は随時試験を中心に受験方法を確認してください。

随時試験は、各試験会場が日程を設定し、会場へ直接申し込みます。

## 再受験ルール

同じ科目を再受験する場合、公式ルールがあります。

- 2回目：前回受験から24時間待つ
- 3回目以降：前回受験から48時間待つ

不合格時だけでなく、合格後に同じ科目を再受験する場合も対象です。

## 合格点・合格率について

MOS公式サイトは、すべての科目に共通する固定の「○点で合格」「合格率○%」という形では案内していません。

そのため、このページでは非公式な合格率や推定合格点を断定値として掲載しません。

合格に向けては、受験する科目・バージョンの公式出題範囲を確認し、実際のOffice操作を反復することが重要です。

## 難易度・勉強時間目安

公式の標準勉強時間はありません。

日常的に対象アプリを使っている人と、初めて触る人では必要な準備量が大きく違います。

模擬試験や対策教材で、制限時間内に指示どおりの操作を再現できるかを確認する方法が適しています。
