# Microsoft Office Specialist (MOS)

## 概要
Microsoft Office Specialist (MOS) は、Word、Excel、PowerPointなどのマイクロソフト オフィス製品の利用スキルを証明する国際資格です。
世界中で実施されており、累計受験者数は日本国内だけで500万人を超える超人気資格です。
就職・転職時のPCスキル証明として最も一般的であり、事務職を目指す人には必須級の資格です。

## 試験詳細
バージョン（365, 2019, 2016）ごとに試験が分かれています。
レベルは「Associate（一般レベル）」と「Expert（上級レベル）」があります（Word/Excelのみ）。

| 項目 | 内容 |
| --- | --- |
| 試験日程 | 全国一斉試験（月1～2回）または 随時試験（各会場で毎日実施） |
| 試験時間 | 50分 |
| 問題数 | 30～50問程度（マルチプロジェクト形式など） |
| 合格ライン | 1000点満点中550点～850点程度（科目・難易度により変動） |
| 受験料 | 一般レベル: 10,780円、上級レベル: 12,980円（税込） ※学割あり |
| 受験資格 | なし |
| 試験方式 | CBT（PCを使った実技試験） |

## 科目とレベル (MOS 365/2019の場合)
- **Associate (一般レベル)**:
    - Word, Excel, PowerPoint, Outlook
    - 基本的な操作、文書作成、表計算、プレゼンテーション作成。
- **Expert (上級レベル)**:
    - Word Expert, Excel Expert, Access Expert (※Accessは上級のみ)
    - 高度な機能、スタイル管理、マクロ作成、ピボットテーブルなど。

**称号の認定**:
規定の科目に合格すると、「MOS Associate」や「MOS Expert」の称号が認定されます。

## 難易度・勉強時間目安
- **Associate (一般)**:
    - 難易度: 初級（合格率 80%以上と言われます）
    - 普段PCを使っている人なら、対策テキストを1冊やれば合格できます。
- **Expert (上級)**:
    - 難易度: 中級（合格率 60%前後）
    - 実務であまり使わない機能も出るため、しっかりとした学習が必要です。
- **勉強時間**:
    - 各科目 20 ～ 40 時間
