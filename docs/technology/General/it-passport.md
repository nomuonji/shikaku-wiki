# ITパスポート試験 (i-Pass)

## 概要
ITパスポート試験（i-Pass）は、ITを利活用するすべての社会人・これから社会人となる学生が備えておくべき、ITに関する基礎的な知識を証明する国家試験です。
新しい技術（AI、ビッグデータ、IoT など）や新しい手法（アジャイルなど）の概要に関する知識をはじめ、経営戦略、マーケティング、財務、法務など、IT以外の幅広いビジネス知識も問われます。
エンジニアだけでなく、事務職や営業職など幅広い職種で取得が推奨されています。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 120分 |
| 問題数 | 100問（四肢択一） |
| 合格ライン | 総合評価点 600点以上／1,000点、かつ分野別評価点（ストラテジ、マネジメント、テクノロジ）がそれぞれ300点以上／1,000点 |
| 受験料 | 7,500円（税込） |
| 受験資格 | なし |
| 有効期限 | なし（無期限） |
| 試験方式 | CBT（Computer Based Testing）方式 |

## 学習範囲・シラバス
出題範囲は以下の3つの分野から構成されています。

- **ストラテジ系（経営全般） (約35%)**
    - 企業活動、法務、経営戦略、システム戦略など
- **マネジメント系（IT管理） (約20%)**
    - システム開発技術、プロジェクトマネジメント、サービスマネジメントなど
- **テクノロジ系（IT技術） (約45%)**
    - 基礎理論、コンピュータシステム、技術要素（セキュリティ、ネットワーク、DBなど）

## 難易度・勉強時間目安
- **難易度**: 初級（ITスキル標準 レベル1）
    - IT初心者でも比較的取り組みやすい難易度です。
- **勉強時間**:
    - 初学者: およそ 100 ～ 180 時間
    - 情報系学生・社会人: およそ 30 ～ 50 時間

## 公式情報
- [公式サイト (IPA 独立行政法人 情報処理推進機構)](https://www.ipa.go.jp/shiken/kubun/ip.html)

## 受験の注意点

ITパスポートは全国のCBT会場で随時実施され、申込から受験まで自分のペースで進められます。受験手数料7,500円（税込）はIPAの公式発表どおりで、支払いはクレジットカード・コンビニ・バウチャーが使えます。シラバスは改定されることがあるため、申込前にIPAの公式サイトで出題範囲を確認してください。

（確認日: 2026-09-04。料金・制度はIPAの公表値。最新情報は公式サイトで確認してください。）
