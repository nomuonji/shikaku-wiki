# Azure Security Engineer (AZ-500)

## 概要

【AZ-500】Azureの守りを仕組みに。怪しい動きを見つけて止められる。

**注**: この試験は2026年8月31日に提供終了しました。新規受験はできません。現行の後継は [SC-500 クラウドおよび AI セキュリティ エンジニア](/docs/technology/General/sc-500-cloud-ai-security-engineer/) です。既存保有者の資格は個人の有効期限まで有効ですが、廃止済み認定の更新についてはMicrosoft公式の有効期限・更新ポリシーを確認してください。
