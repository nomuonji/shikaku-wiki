# HTML5プロフェッショナル認定試験 レベル1

## 概要
HTML5プロフェッショナル認定試験 レベル1は、HTML5、CSS3、JavaScriptなど、最新のマークアップ言語技術を使ってWebコンテンツを制作・デザインするスキルを認定する資格です。
LPI-Japanが主催しており、Webデザイナーやフロントエンドエンジニアの技術力を客観的に証明できます。
レスポンシブWebデザインやマルチデバイス対応の知識も問われます。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| バージョン | Ver 2.5（2024年現在） |
| 試験時間 | 90分 |
| 問題数 | 約60問 |
| 合格ライン | 70%程度（非公開） |
| 受験料 | 16,500円（税込） |
| 受験資格 | なし |
| 有効期限 | 5年間 |
| 試験方式 | CBT（テストセンターまたはオンライン） |

## 学習範囲・シラバス
- **Webの基礎知識**: HTTP、URI、SEO、アクセシビリティ
- **HTML5**: 要素、属性、コンテンツモデル
- **CSS3**: セレクタ、ボックスモデル、レイアウト（Flexbox, Grid）、アニメーション、メディアクエリ
- **レスポンシブWebデザイン**: マルチデバイス対応
- **オフラインWebアプリケーション**: 基本的な知識

## 難易度・勉強時間目安
- **難易度**: 初級～中級
    - 実務で使うタグやプロパティの正確な知識が問われます。特にCSSの仕様に関する細かい問題が出ます。
- **勉強時間**:
    - Web制作経験者: 20 ～ 40 時間
    - 初学者: 80 ～ 120 時間
