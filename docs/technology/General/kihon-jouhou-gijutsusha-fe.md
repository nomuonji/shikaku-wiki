# 基本情報技術者試験 (FE)

## 概要
基本情報技術者試験（FE）は、ITエンジニアとしてキャリアをスタートさせるために必要な基本的知識・技能を証明する国家試験です。
「ITエンジニアの登竜門」として位置づけられており、プログラミング、ネットワーク、セキュリティ、データベース、システム開発など、IT全般の幅広い知識が問われます。
2023年4月から通年受験可能なCBT方式に変更され、試験内容も「科目A」「科目B」に再編されました。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 科目A：90分、科目B：100分（計190分） |
| 問題数 | 科目A：60問、科目B：20問 |
| 合格ライン | 科目A、科目Bともに600点以上／1,000点 |
| 受験料 | 7,500円（税込） |
| 受験資格 | なし |
| 有効期限 | なし（無期限） |
| 試験方式 | CBT（Computer Based Testing）方式 |

## 学習範囲・シラバス
- **科目A試験 (知識問題)**
    - テクノロジ系（基礎理論、セキュリティ、ネットワークなど）
    - マネジメント系（プロジェクトマネジメントなど）
    - ストラテジ系（経営戦略など）
- **科目B試験 (技能問題)**
    - 「アルゴリズムとプログラミング」および「情報セキュリティ」を中心に出題
    - 擬似言語を用いたプログラム読解問題が出題されます（個別のプログラミング言語知識は不要）

## 難易度・勉強時間目安
- **難易度**: 中級（ITスキル標準 レベル2）
    - ITパスポートよりも技術的な深掘りが必要です。特に科目Bのアルゴリズム問題は論理的思考力が求められます。
- **勉強時間**:
    - 初学者: およそ 200 時間 ～
    - 情報系バックグラウンドあり: およそ 50 ～ 100 時間
