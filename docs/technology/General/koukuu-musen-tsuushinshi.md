# 航空無線通信士

## 概要

航空無線通信士は、電波法に基づく**無線従事者の国家資格**です。

航空機局、航空局などの航空無線通信に必要な無線設備の操作・通信を担うための資格で、航空業界の無線通信業務と直接関係します。

「航空特殊無線技士」とは別資格で、航空無線通信士では無線工学・法規だけでなく、**英語と電気通信術**も試験科目です。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 国家資格 |
| 実施団体 | 日本無線協会 |
| 試験方式 | 多肢選択式 + 電気通信術 |
| 試験科目 | 無線工学・法規・英語・電気通信術 |
| 実施時期 | 原則 年2回（8月期・2月期） |
| 申請 | インターネット |

英語と電気通信術は開始後に試験室へ入れないため、試験案内でも特に時間厳守が注意されています。

## 2026年度の日程

### 8月期

2026年8月20日〜21日に実施済みです。

### 次回：2月期

- 申請期間：**2026年12月1日〜20日**
- 無線工学・法規・英語：**2027年2月25日**
- 電気通信術：
  - 東京以外：2027年2月25日
  - 東京：2027年2月26日

2026年9月25日時点では、次回申請開始前です。

## 試験手数料の注意

2026年8月期の試験案内では、航空無線通信士の試験手数料は9,300円でした。

ただし、日本無線協会は**2026年10月1日から無線従事者国家試験手数料を改定**すると案内しています。

次回2月期の申請は12月なので、9,300円を次回料金として固定せず、申込時の最新手数料を確認してください。

## 試験科目

### 無線工学

航空無線設備の技術的な基礎・構成・運用に必要な無線工学を扱います。

### 法規

電波法令や航空無線通信に必要な運用規則を扱います。

### 英語

航空通信で必要となる英語力を確認します。

### 電気通信術

実際の通信運用に必要な通信技量を確認します。

知識問題だけでなく、通信を正確に扱う技能が必要な点が特徴です。

## 科目免除

過去の科目合格、所定の資格保有、認定学校卒業、業務経歴などによる免除制度があります。

初めて免除を申請する場合は、卒業証明書や経歴証明書などの提出が必要になるケースがあります。

## 難易度・勉強時間目安

日本無線協会は標準勉強時間を公表していません。

無線工学・法規に加えて英語・電気通信術があるため、工学知識だけでは完結しません。

過去問題は日本無線協会が公開しているため、まず4分野それぞれの現在地を確認し、弱点を分けて学ぶのが効率的です。
