# Google Cloud Digital Leader

## 概要
Google Cloud Digital Leader は、クラウド コンピューティングの基礎知識と、Google Cloud のプロダクトとサービスを活用して組織の目標を達成する方法を理解していることを証明する認定資格です。
技術的な役割に限らず、クラウドを活用したデジタルトランスフォーメーション（DX）を推進するビジネスリーダーや担当者に適しています。

初めて受ける場合、または認定が失効している場合は標準試験が必要です。更新は、標準試験、短い更新試験、または Google Skills の指定コースやスキルバッジのいずれかで行えます。

確認日: 2026-10-02。下記の数値と区分は、同日に確認した [Google Cloud 公式認定ページ](https://cloud.google.com/learn/certification/cloud-digital-leader) と、そのページが指す [Cloud Digital Leader 試験ガイド（英語、2026-08-12 公開）](https://services.google.com/fh/files/misc/cloud_digital_leader_exam_guide_english.pdf) によります。公式ページは、8月12日以降、新版試験が実施中で出題範囲は試験ガイドを見るよう案内しています。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 標準試験 90分。更新試験は 45分 |
| 問題数 | 標準試験は 50～60問の多肢選択・複数選択。更新試験は 20問 |
| 合格ライン | 公式認定ページと試験ガイドには公表がない。推測値は記載しない |
| 受験料 | 標準試験は 99米ドル（該当する場合は税別）。更新試験は 60米ドル（該当する場合は税別） |
| 受験資格 | 標準試験の前提条件はなし。更新試験は有効な認定を持ち、更新対象期間内であること |
| 有効期限 | 標準試験または更新試験による認定は 3年。Google Skills の指定コース等による更新は 1年 |
| 試験方式 | オンライン監督、またはテストセンターでの受験 |
| 対応言語 | 標準試験は英語・日本語・スペイン語・ポルトガル語・フランス語。更新試験は英語・日本語 |

## 学習範囲・シラバス
2026-08-12 公開の試験ガイドでは、標準試験と更新試験の双方で出題され得る範囲を次の 6 区分としています。割合は同ガイドの目安です。

- **Digital Transformation with Google Cloud（約 18%）**
    - クラウドが事業を変える理由と、基本概念、サービスモデル（IaaS / PaaS / SaaS）
- **Exploring Data Transformation with Google Cloud（約 18%）**
    - データの役割、データベース・ウェアハウス・データレイク、分析と可視化
- **Innovating with Google Cloud Artificial Intelligence（約 18%）**
    - AI / ML と生成 AI の基本、ビジネス上の用途、責任ある AI
- **Modernize Infrastructure and Applications with Google Cloud（約 18%）**
    - 移行、仮想マシン、コンテナ、サーバーレス、API
- **Trust and Security with Google Cloud（約 18%）**
    - セキュリティの基本、共同責任、暗号化、コンプライアンス
- **Scaling with Google Cloud Operations（約 10%）**
    - コスト管理、信頼性と運用

細項目は試験ガイド本体で確認してください。割合は目安であり、各回の出題数を保証するものではありません。

## 難易度
- **難易度**: 初級（Foundational）。公式説明では、Google Cloud の主要プロダクトとサービスの能力、組織にとっての利点、一般的なビジネス用途を説明できることが対象です。深い実装手順は主たる問いではありません。
- **勉強時間**: 公式に固定の目安時間はありません。個人の必要時間は推定しません。
