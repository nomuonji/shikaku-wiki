# Google Cloud Digital Leader

## 概要
Google Cloud Digital Leader は、クラウド コンピューティングの基礎知識と、Google Cloud のプロダクトとサービスを活用して組織の目標を達成する方法を理解していることを証明する認定資格です。
技術的な役割に関わらず、クラウドを活用したデジタルトランスフォーメーション（DX）を推進するビジネスリーダーや担当者に適しています。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 90分 |
| 問題数 | 50 ～ 60問 |
| 合格ライン | 公式非公開（70%程度と言われています） |
| 受験料 | 99 USD（税別） |
| 受験資格 | なし |
| 有効期限 | 3年間（再認定が必要） |
| 試験方式 | CBT（テストセンターまたはオンラインプロクタリング） |

## 学習範囲・シラバス
主な出題範囲は以下の通りです。

- **デジタルトランスフォーメーションとGoogle Cloud (10-20%)**
    - クラウド技術がビジネスにもたらす価値
    - イノベーションの促進
- **データとGoogle Cloudによるイノベーション (20-30%)**
    - データ管理、データベース、データウェアハウス
    - ビッグデータとAI/MLの活用
- **インフラストラクチャとアプリケーションのモダナイゼーション (30-40%)**
    - コンテナ、サーバーレス、IaaS/PaaSの理解
    - アプリケーションの移行とモダナイゼーション
- **Google Cloudのセキュリティと運用 (10-20%)**
    - セキュリティのベストプラクティス
    - コスト管理とリソース階層

## 難易度・勉強時間目安
- **難易度**: 初級
    - Google Cloudのサービス概要とビジネス価値に重点が置かれています。深い技術的実装スキルは問われません。
- **勉強時間**:
    - 初学者: およそ 15 ～ 30 時間
    - 他クラウド経験者: およそ 5 ～ 10 時間
