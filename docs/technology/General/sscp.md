# SSCP（Systems Security Certified Practitioner）

## 概要

SSCPは、ISC2が運営する情報セキュリティ実務者向けの国際認定資格です。セキュリティの運用、アクセス制御、リスク、インシデント対応、暗号、ネットワーク、システム・アプリケーションセキュリティを横断して扱います。

CISSPよりも現場運用に近い領域を中心にしており、セキュリティ管理・運用を担当する実務者の知識体系を確認する資格です。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 国際認定資格 |
| 実施団体 | ISC2 |
| 試験方式 | CAT（Computerized Adaptive Testing） |
| 問題数 | 100〜125問 |
| 試験時間 | 最大2時間 |
| 合格基準 | 1,000点満点中700点 |
| 対応言語 | 英語・日本語・スペイン語 |
| 試験会場 | Pearson Testing Center |

SSCPは2025年10月1日からCAT方式に移行しました。古い教材に「125問・3時間」などの旧仕様が残っている場合があるため注意が必要です。

## 出題範囲・7ドメイン

1. Security Concepts and Practices
2. Access Controls
3. Risk Identification, Monitoring and Analysis
4. Incident Response and Recovery
5. Cryptography
6. Network and Communications Security
7. Systems and Application Security

CAT方式では受験者の回答状況に応じて次の問題が選ばれるため、出題数は100〜125問の範囲で変動します。

## 認定に必要な実務経験

SSCP認定には、7ドメインのうち1つ以上で**1年以上のフルタイム相当の実務経験**が必要です。

コンピュータサイエンス、ITなど関連分野の学士・修士学位は、最大1年分の経験要件を満たす扱いになる場合があります。パートタイムやインターンの経験も条件に従って算入できる場合があります。

経験要件を満たしていない状態で試験に合格した場合は、Associate of ISC2として必要な経験を積むルートがあります。

## 難易度・勉強時間目安

ISC2は標準勉強時間を定めていません。7ドメインの範囲が広いため、日常業務で扱っていない領域を特定して補う方法が効率的です。

特に、アクセス制御・ネットワーク・暗号・インシデント対応などを「用語」としてではなく、運用場面でどう選択するかまで理解する必要があります。
