# AWS認定 クラウドプラクティショナー（CLF-C02）

## まず判断したいこと

AWS Certified Cloud Practitioner（CLF）は、特定の職種の実装力を証明する試験ではなく、AWSクラウドを使う組織で共通言語を持つための基礎認定です。営業、企画、調達、管理部門など、AWSを使った提案や費用・リスクの説明を受ける人にも向いています。サービスを設計・運用する仕事を目指すなら、この認定だけで実務力が示せるとは考えず、Developer、Solutions Architect、SysOpsなどの職種別学習へ進む入口として使うのが現実的です。

## 現行試験で問われる範囲

2026年9月24日に確認したAWS公式の試験ガイドでは、現行版はCLF-C02です。出題比率はクラウドの概念24%、セキュリティとコンプライアンス30%、クラウド技術とサービス34%、請求・料金・サポート12%。サービス名の暗記だけでなく、どの場面で使うか、責任共有モデルで誰が何を担うか、利用料金をどう把握するかを結びつけて理解する必要があります。

AWSは試験ガイドで合格をスケールドスコア700以上として説明しています。各分野ごとに合格点が設定される形式ではないため、苦手分野を放置せず全体を整えるのが先です。出題対象サービスの完全な一覧は公式ガイドの更新に従ってください。新機能の追加に伴い、教材やサービスの呼び方が変わることがあります。

## 受験する価値がある人

- AWSを使う案件の提案、調達、費用管理に関わる人
- クラウド用語やセキュリティ責任の分担を整理したい人
- AWSの職種別認定に進む前に全体像をつかみたい初学者

すでにAWS環境を構築・運用している人は、基礎用語を広く学ぶより、担当職種に合う上位試験のガイドを読み、必要な認定から始める方法もあります。受験資格として事前のAWS実務経験を求める試験ではありませんが、公式の準備案内に沿ってクラウドの基本用語を学んでから申し込むと、学習範囲を絞りやすくなります。

## 学習の組み立て方

最初に公式試験ガイドのドメインとタスク文を読み、知らない言葉を一覧化します。次にAWS Skill Builderの公式学習教材と公式練習問題で、概念をサービスの用途に結びつけます。たとえば、単にS3やEC2の定義を覚えるのではなく、保存、計算、可用性、アクセス制御、料金のどの課題に使うのかを説明できる状態を目指します。

模擬問題の誤答は、正答だけを暗記せず、他の選択肢がなぜ適さないかを試験ドメインに戻して確認してください。試験時間や問題数、料金、受験可能な言語・会場は予約時の公式ページに表示される条件を優先します。通貨換算や実施方式は地域・予約方法で変わることがあるため、古い教材の金額を前提にしないでください。

## 試験時間・問題数

AWS公式の資格ページでは、CLF-C02は**90分・65問**と案内されています。受験前には、[AWS Certified Cloud Practitioner公式ページ](https://aws.amazon.com/jp/certification/certified-cloud-practitioner/)で現行試験コードと試験仕様を再確認してください。

## 受験料・申し込み前の確認

AWSの[認定試験料金ページ](https://aws.amazon.com/jp/certification/policies/before-testing/)を2026年9月28日に確認した時点で、Foundational試験の日本円表示価格は**15,000円**です。

この15,000円を「常に税込15,000円」とは扱いません。AWSは料金ページで、地域や取引条件によって税が別途適用される場合があること、料金を更新する場合があることを案内しています。実際に支払う金額は予約フローに表示される内容を優先してください。

資格取得者向けの割引・特典が利用できる場合がありますが、適用資格や条件はアカウント状況によって確認が必要です。この記事では割引を前提に実質料金を計算せず、予約時にAWS Certification Account側の利用可能な特典を確認する方針にします。

また、有効期間や再認定条件、受験可能な言語・会場も変更される可能性があります。受験枠を選ぶ前に、CLF-C02が引き続き現行版か、希望する受験方法と日時が選べるかを公式ページで確認してください。
