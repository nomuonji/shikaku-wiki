# AWS認定 クラウドプラクティショナー (CLF)

## 概要
AWS認定 クラウドプラクティショナー (AWS Certified Cloud Practitioner) は、AWSクラウドの知識を全体的に理解していることを証明する基礎レベルの認定資格です。
エンジニアだけでなく、営業、マーケティング、アナリストなど、AWSクラウドに関わる全てのビジネスパーソンを対象としています。
クラウドの概念、AWSの基本サービス、セキュリティ、アーキテクチャ、料金モデルなどの基礎知識が問われます。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 90分 |
| 問題数 | 65問 |
| 合格ライン | 700点 / 1000点満点 |
| 受験料 | 15,000円（税別） ※為替レートにより変動の可能性あり |
| 受験資格 | なし（6ヶ月程度の基礎的なAWS経験推奨） |
| 有効期限 | 3年間（再認定が必要） |
| 試験方式 | CBT（テストセンターまたはオンラインプロクタリング） |

## 学習範囲・シラバス
主な出題範囲（バージョン CLF-C02）は以下の通りです。

- **クラウドのコンセプト (24%)**
    - AWSクラウドの価値提案
    - クラウドエコノミクスの理解
- **セキュリティとコンプライアンス (30%)**
    - AWSの責任共有モデル
    - クラウドセキュリティとコンプライアンスの概念
- **クラウドテクノロジーとサービス (34%)**
    - AWSの主要サービス（EC2, S3, RDS, Lambdaなど）
    - テクノロジーサポートリソースの特定
- **請求、料金、およびサポート (12%)**
    - AWSの料金モデル
    - 請求サポートと各種ツール

## 難易度・勉強時間目安
- **難易度**: 初級
    - IT資格の入門としても適しています。AWSの各サービスの概要レベルの知識が必要です。
- **勉強時間**:
    - 初学者: およそ 20 ～ 40 時間
    - IT経験者: およそ 10 ～ 15 時間
