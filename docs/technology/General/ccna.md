# CCNA (Cisco Certified Network Associate)

## 概要：受験日で学ぶ版が変わる

CCNAは、Ciscoが認定するネットワーク技術の資格です。試験番号は**200-301**。ネットワークの接続・ルーティング・セキュリティ・運用などを扱い、認定を得るには対応する試験に合格する必要があります。

**2027年2月3日から試験範囲がv2.0へ切り替わります。** 2026年10月21日時点で、Ciscoはv1.1の最終受験日を**2027年2月2日**、v2.0の初回受験日を**2027年2月3日**と案内しています。試験番号が同じ200-301でも、受験日によって参照すべき出題範囲が異なります。

## いつ受験する？ 試験日・教材の選び方

| 受験予定日 | 適用される版 | 教材と演習の確認事項 |
| --- | --- | --- |
| 2027年2月2日まで | **CCNA 200-301 v1.1** | v1.1の公式Exam Topicsに対応した教材・ラボを使う。予約できる日程を先に確認する。 |
| 2027年2月3日以降 | **CCNA 200-301 v2.0** | v2.0の公式Exam Topicsを基準にする。旧教材を使う場合は、運用・トラブルシューティング・AI関連の差分を補う。 |
| 受験日が未定 | **日程確定後に判断** | まずCiscoの切替日とPearson VUEの予約画面を確認。教材の表紙に「200-301」とだけ書かれていても版まで確認する。 |

すでにv1.1を勉強している人が、必ずv2.0まで待つ必要はありません。Ciscoも、現在の学習を続けて切替前に受験する選択肢を案内しています。一方、受験日が切替後になるなら、**v1.1教材だけで試験範囲を網羅したと考えない**ことが重要です。

## 試験詳細：料金・時間・受験資格

| 項目 | Cisco公式で確認できる内容 |
| --- | --- |
| 試験番号 | 200-301 CCNA |
| 試験時間 | **120分**（v1.1・v2.0） |
| 公式の基本受験料 | **300米ドル**（USD、Ciscoの公表価格） |
| 日本円での支払額 | 円換算、地域・税、支払方法等によって異なるため、**予約・決済画面の最終表示を確認**。固定の税込円価格として扱わない。 |
| 受験資格 | 前提資格なし |
| 対応言語 | 英語・日本語（試験詳細で提供状況を確認） |
| 予約 | Ciscoの試験案内からPearson VUEの予約導線へ進む |
| 認定の有効期間 | 原則3年。期限内の再認定条件を別途確認する |

Ciscoは合格判定をPass/Failで案内しています。**固定の合格点や問題数を、公式に保証された数値として扱わないでください。** 問題形式には選択式だけでなく実技的な設問も含まれるため、設問数を決め打ちした学習計画より、公式の出題項目ごとの実践が適切です。

受験料は[シスコ認定試験の日本語公式案内](https://www.cisco.com/site/jp/ja/learn/training-certifications/exams/index.html)でも、アソシエイトレベル**300米ドル・税別**と記載されています。受験地・支払通貨・税の適用は申し込み時に再確認してください。

## 学習範囲・シラバス：v1.1とv2.0の違い

### v1.1：6つの出題分野

2027年2月2日までのv1.1は、次の6分野で構成されます。詳細な技術項目は必ず[公式v1.1 Exam Topics](https://learningnetwork.cisco.com/s/ccna-exam-topics)で確認してください。

| 分野 | 配点比率 |
| --- | ---: |
| Network Fundamentals（ネットワークの基礎） | 20% |
| Network Access（ネットワークアクセス） | 20% |
| IP Connectivity（IP接続） | 25% |
| IP Services（IPサービス） | 10% |
| Security Fundamentals（セキュリティの基礎） | 15% |
| Automation and Programmability（自動化・プログラマビリティ） | 10% |

v1.1では、IPv4/IPv6、VLAN、ルーティング、DHCP/NAT、ACLなどに加え、生成AIやクラウドネットワーク管理なども試験範囲に含まれます。

### v2.0：公式blueprintの5つの配点区分

v2.0では分野の再編が行われ、Ciscoの[公式v2.0 Exam Topics](https://learningnetwork.cisco.com/s/ccna-v2-exam-topics)は**以下の5つの番号付き配点区分**を掲載しています。概要で挙げられる「IP routing」「AI」などの話題名の数と、配点区分の数は同じではありません。

| v2.0の配点区分 | 配点比率 | 学習時の着眼点 |
| --- | ---: | --- |
| Network Infrastructure and Connectivity | 25% | ケーブル・インターフェース障害、IPv4/IPv6設定、クライアント接続の診断 |
| Switching and Network Access | 25% | VLAN・トランク・LACP・STP、接続確認とトラブルシューティング |
| IP Routing | 20% | ルーティングテーブル、静的経路、OSPFv2/v3、冗長化 |
| Network Services and Security | 20% | AAA、NAT/PAT、DNS、VPN、ACL、L2セキュリティ |
| AI, and Network Operations and Management | 10% | ネットワーク運用におけるAI、プロンプト、SNMP、Ansible、syslog |

**差分の読み方：** v1.1の6分野が、v2.0で5つの配点区分に再構成されています。特にv2.0は障害切り分け・設定の検証などの実務的な作業や、ネットワーク運用でのAIの利用を明示しています。「旧版の全項目がなくなった」「新しい5分野だけを丸暗記すればよい」という意味ではありません。各分野の**小項目**を公式blueprintで照合してください。

## 難易度と勉強法：時間の断定より、できる操作を確認する

CCNAはネットワークの基本概念を知っているだけでなく、設定・確認・障害切り分けを問う試験です。経験の有無によって必要な準備量は大きく変わるため、**一律の合格までの勉強時間や合格点の推定値は掲載しません。**

学習順序の一例は、IPアドレス・サブネット・スイッチングの基礎を理解し、VLAN・ルーティング・ACLをラボで設定し、最後に試験版に対応する公式Exam Topicsの各項目を「説明できる／設定できる／診断できる」で確認することです。v2.0受験者はAI・ネットワーク運用分野も漏らさず照合してください。

Ciscoは[Cisco U.の学習教材や演習](https://www.cisco.com/site/us/en/learn/training-certifications/certifications/enterprise/ccna/index.html)を案内しています。教材や問題集は、購入前に**v1.1/v2.0の対応版と更新日**を確認しましょう。

## 受験予約・認定の更新

1. [Cisco公式CCNA案内](https://www.cisco.com/web/go/ccna/)で受験予定日の適用版を確認する。
2. 版に合う公式Exam Topicsを開き、学習教材・演習内容を照合する。
3. Ciscoの案内から**Pearson VUE**の試験予約へ進み、受験日時・言語・会場/オンラインの提供条件と**決済画面の最終料金**を確認する。
4. 合格後は認定期限を確認し、期限内に再認定の要件を満たす。CCNAは原則3年間有効で、対象試験への合格やCiscoが認める継続教育（CE）などの更新方法がある。詳しくは[公式CCNA認定・再認定案内](https://www.cisco.com/site/us/en/learn/training-certifications/certifications/enterprise/ccna/index.html)を参照する。
