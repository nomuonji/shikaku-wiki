# Microsoft Azure Fundamentals (AZ-900)

## 概要
Microsoft Azure Fundamentals (AZ-900) は、クラウドサービスの基礎知識と、Microsoft Azureが提供するサービスについての理解を証明する入門資格です。
技術的な背景を持つ受験者だけでなく、クラウドベースのソリューションやサービスの販売・購入に関わる非技術者も対象としています。
AWS Cloud PractitionerのAzure版といった位置付けで、Azure資格体系の最初のステップとなります。

## 学習範囲・シラバス
主な出題範囲は以下の通りです。

- **クラウドの概念 (25-30%)**
    - クラウドコンピューティングの利点、モデル（IaaS, PaaS, SaaS）、種類（パブリック、プライベート、ハイブリッド）
- **Azureのアーキテクチャとサービス (35-40%)**
    - Azureの主要コンポーネント（リージョン、可用性ゾーンなど）
    - 主要サービス（Compute, Networking, Storage, Database）
- **Azureの管理とガバナンス (30-35%)**
    - コスト管理、SLA
    - ID管理、ガバナンス、セキュリティツール

## 難易度・勉強時間目安
- **難易度**: 初級
    - クラウド初心者に最適です。Microsoft Learn（無料のオンライン学習）のみでも合格可能です。
- **勉強時間**:
    - 初学者: およそ 15 ～ 30 時間
    - クラウド経験者: およそ 5 ～ 10 時間
