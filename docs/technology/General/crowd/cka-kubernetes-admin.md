# Certified Kubernetes Administrator（CKA）

## 対象と試験の特徴
CKAはKubernetesクラスターの管理者を想定した実技認定です。運用・SRE・プラットフォーム担当者が、クラスタ構築、ワークロード管理、ストレージ、ネットワーク、障害調査をコマンドラインで実行できるかを確認します。用語を選ぶ多肢選択試験ではなく、試験環境上で複数の作業を時間内に完了する実技試験なので、模擬問題を読むだけでは操作速度と検証手順を身につけにくい資格です。

Linux Foundationの公式案内では、試験時間は2時間、オンライン監督下で実施されるパフォーマンスベース試験です。前提資格は求められません。試験範囲はバージョン変更に応じて更新され、2026年9月24日に確認した公式案内ではKubernetes v1.35を対象としています。マイナーリリース後、試験環境が更新されるまでの時差が示される場合があるため、予約時に対象バージョンを再確認してください。認定の有効期間は2年です。

## 何を練習するか
出題ドメインにはクラスターのアーキテクチャ・インストール・構成、ワークロードとスケジューリング、サービスとネットワーク、ストレージ、トラブルシューティングがあります。公式の現行比率ではトラブルシューティングが大きな割合を占めます。Podが起動しない、Serviceから接続できない、ボリュームがマウントされないなどの状況で、イベント、ログ、設定を順に調べ、修正後に状態を確認する練習が重要です。

まず公式試験ドメインを読み、kubectlの基本操作、YAML編集、リソースの作成・変更・削除を反復します。練習環境で、壊れた設定の切り分けから復旧までを時間を計って行いましょう。試験中に使えるドキュメントや操作条件は変更されることがあるため、受験直前に試験案内のポリシーを読みます。

## 受験を決める前に
CKAは、Kubernetesに触れている技術者が操作力を示す場面で役立ちます。コンテナやLinuxの基本操作が初めてなら、まずローカル検証環境でDeployment、Service、ConfigMap、Secretなどを動かしてから受験する方が現実的です。受験料や再受験、試験バンドル、利用可能言語は購入ページの最新条件で確認してください。
