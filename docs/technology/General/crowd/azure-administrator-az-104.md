# Azure Administrator Associate（AZ-104）

## どんな仕事を想定した資格か
AZ-104は、Azure環境の日常運用を担う管理者向けの認定です。IDとガバナンス、ストレージ、コンピューティング資源、仮想ネットワーク、監視とバックアップなどを管理する知識を確認します。Azureを初めて学ぶ人にはサービス全体を触る入口になり、すでに運用を担当している人には、権限設定や障害対応などを体系立てて振り返る材料になります。設計専門職や開発者資格とは対象タスクが異なります。

## 試験範囲の読み方
Microsoft LearnのAZ-104学習ガイドでは、ID・ガバナンス、ストレージ、Azure計算資源のデプロイ・管理、仮想ネットワーク、リソース監視と保守が中心です。試験の比率やタスク一覧は変更されるため、学習を始める日と受験前に最新版のStudy Guideを確認してください。ポータル上の操作手順だけを暗記せず、Azure CLIやPowerShellを使う場面、ロールベースアクセス制御、可用性や復旧を含め「どの設定をなぜ選ぶか」を説明できるようにします。

受験準備では、無料のMicrosoft Learn教材で各タスクの理解を進め、サンドボックスまたは自分で管理する検証環境で操作を試します。たとえば、ユーザーへの最小権限付与、ストレージへのアクセス制御、仮想マシンのバックアップ、ネットワーク到達性の確認を小さな演習にします。クラウド環境は操作によって課金が発生することがあるため、学習後はリソースを停止・削除し、料金の有無を確認してください。

## 受験・認定の維持
受験にあたっては、Microsoft Learnの資格ページで試験の言語、予約方法、地域ごとの料金と利用可能な試験方式を確認します。試験は内容が更新されることがあり、合格基準の数値だけで準備度を測らず、公式スキル概要の各タスクを説明・実行できるかで判断します。

MicrosoftのAssociate認定は有効期限があり、現行制度では無料のオンライン更新評価に合格すると更新できます。更新可能期間、評価の開始日、合格点は資格ページに表示される条件を確認してください。資格名を履歴書に記載する場合は、認定の有効状態をMicrosoft Learnプロフィールで保つ必要があります。

## 向いている人・向かない人
Azureの利用企業で運用・サポートを担当する人、オンプレミスからクラウドへ移るチームで基礎を整えたい人には有用です。一方、受験だけで職務経験や設計実績を証明できる資格ではありません。実際に扱うAzure環境での構築・障害対応の経験と組み合わせて活用してください。
