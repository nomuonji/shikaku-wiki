# Google Professional Data Engineer

## 概要

【GCP データエンジニア】集める・ためる・分析するの流れを設計できる。数字で意思決定がしやすくなる。

## 公式情報

- [公式サイト](https://cloud.google.com/learn/certification/data-engineer)

## Data Engineer認定の評価領域
Google Cloud Professional Data Engineerは、データを取り込み、変換・処理し、安全に保存・提供するクラウドデータ基盤の設計・運用を評価する認定です。公式試験ガイドでは、データ処理システムの設計、データの取り込み・処理・保存、分析用データの準備、ワークロードの保守・自動化・監視といった領域を扱います。BigQueryの操作だけに限定されず、要件に応じてストリーム処理やバッチ処理、アクセス管理、可用性、コストを選ぶ力が必要です。受験前は試験ガイドの各タスクを自分の実務・演習経験に照らし、弱い領域のハンズオンを優先してください。

## Associate Cloud Engineer等との違い
Associate Cloud EngineerはGoogle Cloud環境へのデプロイや運用の基礎を広く確認するのに対し、Professional Data Engineerはデータ業務に専門を寄せています。BigQueryでSQLを実行した経験だけでなく、データの流れや品質・セキュリティ、処理失敗時の運用まで説明できる人に向きます。公式は実務経験を推奨していますが、必須の前提資格とは限りません。Professional認定には有効期間と更新試験があるため、資格維持に必要な継続学習も取得判断に含めましょう。

試験時間・形式・受験料・推奨経験・更新期間は改訂される可能性があります。[Google CloudのProfessional Data Engineer公式ページ](https://cloud.google.com/learn/certification/data-engineer)と現行試験ガイドで確認してください。確認日: 2026-09-24。
