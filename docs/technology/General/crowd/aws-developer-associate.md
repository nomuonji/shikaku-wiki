# AWS Certified Developer – Associate（DVA-C02）

## 対象者と資格の役割
この認定は、AWS上でアプリケーションを開発・テスト・デプロイ・デバッグする開発者を想定しています。AWSサービスを使う開発職へ進む人や、すでに開発経験がありAWS運用も担当する人が、クラウドアプリの実装知識を整理するのに向きます。クラウドの仕組みを広く知るCloud Practitionerや、構成設計を中心とするSolutions Architectとは、対象業務が異なります。認定だけで実務経験の代わりになるわけではありません。

## 現行試験の範囲
2026年9月24日に確認したAWS公式試験ガイドでは現行版はDVA-C02です。試験時間は130分、全65問で、採点対象50問と採点されない15問を含みます。スケールドスコア720点以上が合格基準です。ドメイン比率は開発32%、セキュリティ26%、デプロイ24%、トラブルシューティングと最適化18%。アプリケーションコードやAWS SDK、Lambda等を使った連携、認証・権限、CI/CD、ログや監視、性能・コスト改善などが範囲です。

試験ガイドは、アーキテクチャ全体のネットワーク設計など、この試験の対象外とする領域も示しています。設計者試験と同じ勉強を広く行うより、開発者の仕事としてコードとサービスの連携、失敗時の診断、データ保護を説明できるかに集中します。AWSサービスや機能の名称は更新されるため、古い問題集で現行ガイドにない機能を暗記しないようにしてください。

## 学習の進め方
最初にガイドの各タスク文を読み、経験のあるサービスと未経験のサービスを分けます。次に公式のサンプル問題や学習教材で、IAM権限、暗号化、API・イベント連携、デプロイ方式、CloudWatchの診断などを一つずつ確認します。正解を覚えるだけでなく、別の選択肢を選んだ場合の運用上の問題も説明してみると判断力がつきます。ハンズオンでは小さなアプリを作成し、テスト・デプロイ・ログ確認まで一連の流れを経験すると、用語が実務に結びつきます。

## 申込前の確認
事前のAWS実務経験は受験資格として要求されませんが、開発経験や基礎的なAWS操作があると学習を進めやすくなります。料金、利用言語、試験会場、予約枠、認定有効期間は地域や時点で変わるため、申込時に公式の資格ページを確認してください。
