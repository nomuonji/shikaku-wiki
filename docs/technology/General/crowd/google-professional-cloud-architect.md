# Google Cloud Professional Cloud Architect

## 対象者

Professional Cloud Architectは、Google Cloud上で事業要件に沿ったクラウド設計を行うプロフェッショナル認定です。可用性、セキュリティ、性能、費用、運用を考慮し、要件に合う構成を選ぶ力を評価します。Googleは3年以上の業界経験と、そのうちGoogle Cloudを使った設計・管理経験1年以上を推奨しています。必須の事前資格はありませんが、コンソールでの操作だけでなく、アーキテクチャを選んだ理由を説明できる実務知識が想定されています。

## 試験概要

標準試験は2時間、50～60問の選択式・複数選択式で、日本語または英語で受験できます。受験料は200米ドルと適用される税で、テストセンターまたはオンライン監督方式を選びます。認定の有効期間は2年です。更新対象者には、通常試験のほか短い更新試験やGoogle Skillsの指定コース・スキルバッジを使う方法が設けられています。更新方法と対象期間は有効な認定の状態によって異なります。

出題は、ソリューションアーキテクチャの設計、インフラの管理・提供、セキュリティとコンプライアンス、技術・事業プロセスの分析、実装管理、運用の最適化などを含みます。試験では2つのケーススタディが提示され、問題の20～30%を占めます。公開済みのケーススタディは試験画面で参照できるため、固有の架空企業の状況を読み、要件と制約から設計案を選ぶ練習が重要です。

## 試験準備

Google公式の試験ガイドで出題領域を読み、4種類の公開ケーススタディを確認します。サービス名だけで覚えると、費用、可用性、規制、既存環境など複数の要件がある設問で選択肢を比べにくくなります。学習時は「なぜこの構成か」「どの条件なら別案を選ぶか」を書き出してください。公式のProfessional Cloud Architect学習パスやサンプル問題を使い、古い模擬問題は現在の試験ガイドと照らします。

Google Cloud Professional Cloud DeveloperやCloud Engineerとは役割が異なります。アプリケーション実装、基盤運用、組織全体の設計のどれが仕事の中心かを考えて認定を選ぶと、学習範囲を決めやすくなります。資格取得だけで職務経験が置き換わるわけではありません。
