# Azure Fundamentals（AZ-900）

## どんな資格か

Azure FundamentalsはMicrosoftの初級認定で、クラウドの基本概念、Azureの主要サービス、管理とガバナンスの基礎を扱います。Azureを使う職種に進む前に全体像を学びたい人や、クラウド用語を事業・営業の場で説明する人に向いています。ネットワークやサーバーの設計・運用経験を証明する資格ではなく、専門的なAzure技術者認定の代わりにもなりません。

## 試験と費用

試験コードはAZ-900です。Microsoft Learnの2026年7月更新ガイドでは、試験時間は45分と案内されています。評価領域は、クラウド概念、Azureのアーキテクチャとサービス、Azureの管理とガバナンスです。合格基準や出題範囲は試験ガイドの更新で変わるため、受験前に最新のSkills Measuredを読みます。

日本語版の資格ページに表示される受験価格は12,180円です。地域や税制によって価格は違うことがあるため、予約画面に出る金額を最終的な費用として確認してください。試験予約はMicrosoft LearnのAZ-900資格ページから進み、本人のMicrosoft認定プロフィールと受験する国・地域を指定します。受験の予約変更、本人確認、再受験の条件も公式ポリシーに従います。

## 学習範囲の見方

初学者は、まずIaaS、PaaS、SaaSの違い、責任共有モデル、可用性や従量課金の考え方を整理します。次にAzureのリージョン、リソース、コンピューティング、ネットワーク、ストレージを用語だけでなく用途と結びつけます。最後にID、アクセス制御、コスト管理、監視、ガバナンス機能を確認します。試験ガイドの領域別比率が変わるため、古い動画や問題集だけで出題範囲を決めないでください。

AZ-900の取得後に、クラウド運用の仕事に直結するスキルを身に付けたい人はAzure Administrator Associateなど役割別資格の要件を比較できます。AI、セキュリティ、データ分析の基礎に関心がある場合は、AZ-900とは別の認定を選ぶ方が目的に合う場合があります。
