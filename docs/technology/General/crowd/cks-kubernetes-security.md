# CKS（Kubernetes Security）

## 概要

【CKS】K8sの守り方を理解。権限や秘密情報の扱いが安全に。

## 受験前提としてCKAが必要
Certified Kubernetes Security Specialist（CKS）は、Kubernetesクラスターのセキュリティを構築・運用する技術者向けの認定です。受験には有効なCertified Kubernetes Administrator（CKA）認定が必要です。CKAを持っていない場合、CKSの学習内容に進む前にクラスター管理の基礎を固めてください。CKS試験は選択問題で知識を問う形式ではなく、実環境でクラスタ設定やワークロードを変更する実技型です。試験ガイドのタスクを確認し、制限時間内に必要な操作へたどり着くため、kubectlのオプションや公式ドキュメントの参照方法まで練習しておく必要があります。

## CKAD・CKAとの役割分担
CKAはクラスタ管理者としてクラスターを構築・保守する知識、CKADはその上でアプリをデプロイする開発者の知識、CKSはクラスターとワークロードを保護する知識が主軸です。現場で求められる担当業務から選び、前提となるCKAの有効期限にも注意しましょう。認定の有効期間があるため、受験時期だけでなく再認定をいつ行うかも計画に含めます。試験環境、言語、購入時の受験回数・スケジュール期間は変更されるので、古いブログや教材の条件をそのまま前提にしないでください。

詳細は[Linux FoundationのCKS公式案内](https://training.linuxfoundation.org/certification/certified-kubernetes-security-specialist-cks/)と現行試験ガイドで確認してください。確認日: 2026-09-24。
