# AWS Data Analytics Specialty

## 概要

【AWS データ分析】大量データの集め方・まとめ方を理解。レポート作りが速くなる。

## 2024年に試験受付が終了
AWS Certified Data Analytics – Specialtyは、AWSが2024年4月9日に試験を終了した認定です。これから新たに受験して取得することはできません。既に認定を得た人は、取得日から認定有効期間中は資格を保持できますが、試験終了後に同じ試験を受けて再認定することはできません。古い教材や日程表を見かけても、現在申込可能な試験のように扱わないでください。このページは旧認定名で検索する人が「まだ受験できるか」「保有資格はどうなるか」を確認するための案内として読み替える必要があります。

## 後続の学習先は目的で選ぶ
AWSはデータ分析・データエンジニアリング領域で別の認定や学習教材を提供しています。AWS Certified Data Engineer – Associateは、データの取り込み・変換・保管・管理などデータエンジニアの職務を扱いますが、終了したData Analytics Specialtyの単純な名称変更・同一試験ではありません。既存資格の内容をそのまま移行できるとも限らないため、現行試験ガイドを読み直してください。分析基盤の構築を目指すのか、AWS上の分析サービス運用を目指すのかで学習範囲を決めます。

終了日と移行案内は[AWS認定の終了告知](https://aws.amazon.com/blogs/training-and-certification/aws-certification-retirements-and-launches/)を根拠にしています。現行資格を選ぶ際はAWSの資格一覧と各試験ガイドも確認してください。確認日: 2026-09-24。
