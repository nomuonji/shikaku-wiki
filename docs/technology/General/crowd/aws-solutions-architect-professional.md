# AWS Certified Solutions Architect - Professional（SAP）

## 対象者

AWS Certified Solutions Architect - Professionalは、複雑なクラウド要件を設計に落とし込む上級認定です。複数アカウントや組織をまたぐ構成、セキュリティ、コスト、可用性、移行、運用を比較し、要件に沿った選択ができることを評価します。AWS公式は、AWSを使ったクラウドソリューションの設計・実装経験が2年以上ある候補者を推奨しています。これは受験必須条件ではありませんが、実務経験なしで問題文の前提やトレードオフを理解するのは難しい資格です。

## 試験概要とバージョン移行

2026年9月時点の現行試験はSAP-C02です。試験時間は180分、問題数は75問、出題形式は単一選択または複数選択です。受験料は300米ドルで、テストセンターまたはオンライン監督方式を選べます。日本語を含む複数言語で提供されています。

AWSは更新版SAP-C03を発表し、登録開始を2026年10月27日、提供開始を11月17日としています。現行SAP-C02の最終受験日について、AWS公式認定ページには11月17日、AWS Japanの告知には11月16日という記載があり、公式ページ間に1日のずれがあります。予約可能な最終日時は変更される可能性があるため、受験を急ぐ場合は予約画面で確認してください。SAP-C03ではクラウドネイティブ設計、セキュリティ、コスト、レジリエンスと移行、運用自動化などが示されています。詳細な試験ガイドは公開後に確認します。

## 受験する版を選ぶ

すでにSAP-C02対策が終わっていて、認定を早く得る必要がある場合は現行版の試験可能期間を確認します。これから準備を始める場合は、新版の登録・試験ガイド公開後に出題範囲を見て選ぶ方法があります。新旧の試験名だけで判断せず、試験終了日、予約枠、言語、学習資料の公開状況を比較します。資格を取得した後はその認定の有効期限に従います。

## 学習計画

まず最新の試験ガイドを読んで各ドメインの比重を確認し、AWS Skill Builderの公式学習計画と練習問題を使います。個別サービス名を知っているだけでなく、要件に対して複数案のコスト・セキュリティ・運用負担を比べる練習が必要です。AWSは合格率や必要学習時間を公表していないため、時間数は一律に示しません。
