# LinuC Level 2

## 概要
LinuC Level 2は、Linuxシステムの構築、運用、保守、トラブルシューティング、キャパシティプランニングなどの高度なスキルを証明する資格です。
Level 1が「定型的な運用」なら、Level 2は「設計・構築・非定型トラブル対応」ができるエンジニアを目指します。
Webサーバー、メールサーバー、DNSサーバーなどの主要なサーバー構築スキルが含まれます。

## 試験詳細
認定には「201試験」と「202試験」の両方に合格する必要があります。

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 90分（各試験） |
| 問題数 | 約60問（各試験） |
| 合格ライン | 非公開（65～70%程度と言われています） |
| 受験料 | 16,500円（税込）/ 1試験 ※計33,000円 |
| 受験資格 | LinuC Level 1認定を持っていること（試験自体は先に受けることも可能だが、認定はLevel 1有効期間内に行う必要あり） |
| 有効期限 | 5年間 |
| 試験方式 | CBT（テストセンターまたはオンライン） |

## 学習範囲・シラバス
**201試験**
- Linuxカーネルの起動と管理
- システムの起動とサービス管理（systemdなど）
- ファイルシステムとストレージ管理（LVM、RAID）
- ネットワーク構成とトラブルシューティング

**202試験**
- ドメインネームサーバー (DNS)
- Webサーバー (Apache, Nginx) / プロキシ
- ファイル共有 (Samba, NFS)
- メールサービス (Postfix, Dovecot)
- システムのセキュリティ

## 難易度・勉強時間目安
- **難易度**: 中上級
    - サーバー構築の実践的な知識が必要です。設定ファイルのパスやパラメータを正確に覚える必要があります。
- **勉強時間**:
    - Level 1取得者: およそ 100 ～ 200 時間

## 認定に必要な試験とLevel 1の関係
LinuC Level 2認定は、Linuxシステムの設計・構築・運用に関する上位の知識を示します。認定取得には201試験と202試験の両方に合格する必要があり、Web・DNS・メールなどのサーバー構築、ストレージ、ネットワーク、セキュリティといったテーマを段階的に学びます。Level 1の認定はLevel 2試験を申し込むための必須条件ではありませんが、Level 2認定を成立させるための有効期間等の条件があるため、先に試験だけ受ける場合は申請ルールを確認してください。両試験を別日程で受ける場合は、受験資格・合格結果の有効期限を逆算して予約します。

## LinuCとLPICは別の認定体系
どちらもLinux技術を扱うため試験範囲が重なる部分はありますが、主催・認定体系・国内の学習教材が異なります。会社が指定する認定がある場合はその名称を確認し、履歴書には試験合格だけでなく認定条件を満たした正式名称を記載してください。Level 2はLinuxの基本コマンドだけではなく、障害対応や設定の根拠を説明できる実務水準を目指すものです。仮想マシンやコンテナ環境で設定変更と復旧を練習し、暗記と実機操作を分けて準備するとよいでしょう。

試験範囲、認定成立条件、価格、有効期間は改訂されるため、[LPI-JapanのLinuC Level 2案内](https://linuc.org/level2/)と受験要綱を参照してください。確認日: 2026-09-24。
