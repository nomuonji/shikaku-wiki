# ITパスポート（iパス）

## 概要

ITパスポート試験（iパス）は、情報処理の促進に関する法律に基づく**国家試験**です。

IT技術者だけを対象にした試験ではなく、ITを活用するすべての社会人・学生が備えておきたい、デジタル・経営・マネジメントの共通知識を扱います。

AI、データ、セキュリティ、ネットワークなどの技術だけでなく、企業活動、法務、経営戦略、マーケティング、会計、プロジェクト管理まで横断するのが特徴です。

## 現行試験の概要

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 国家試験 |
| 実施方式 | CBT |
| 実施時期 | 全国で随時 |
| 試験時間 | 120分 |
| 出題数 | 100問 |
| 形式 | 四肢択一 |
| 受験資格 | 制限なし |
| 受験手数料 | 7,500円（税込） |

CBT会場の空席状況に応じて試験日を選びます。身体上の事情等によりCBT方式で受験できない人向けには、特別措置試験も実施されています。

## 合格基準

ITパスポートはIRT（項目応答理論）に基づく評価点で判定されます。

次の**両方**を満たす必要があります。

- 総合評価点：600点以上 / 1,000点
- 分野別評価点：ストラテジ・マネジメント・テクノロジの各分野で300点以上 / 1,000点

総合点が600点を超えていても、一つの分野が300点未満なら合格できません。

## 出題分野

### ストラテジ系

- 企業活動
- 法務
- 経営戦略
- システム戦略
- データ活用
- AI・DXに関する基礎

### マネジメント系

- システム開発
- プロジェクトマネジメント
- サービスマネジメント
- システム監査

### テクノロジ系

- コンピュータシステム
- データベース
- ネットワーク
- 情報セキュリティ
- アルゴリズム・プログラミング的思考
- 情報デザイン

2026年の現行シラバスは**Ver.6.5**です。

## 2027年度に制度内容の変更予定

IPAは、**2027年度から情報処理技術者試験の新制度へ移行する予定**を公表しています。

ITパスポートは廃止ではなく継続されますが、ビジネスパーソンに求められるデジタルリテラシーとして、基礎知識だけでなく「マインド・スタンス」も含めた評価へ内容を変更する予定です。

IPAが2026年8月31日に新制度向けITパスポートのサンプル問題も公開しています。

2027年度以降に受験する人は、教材が新制度・新シラバスに対応しているか確認してください。

## 難易度・勉強時間目安

IPAは一律の標準勉強時間を定めていません。

初学者は、まず3分野を一周してから公開問題で分野別評価を確認する方法が効率的です。合格基準に分野別の足切りがあるため、得意分野だけで総合点を稼ぐ学習は避けた方が安全です。

IT実務経験者でも、経営・法務・会計などストラテジ系の補強が必要になることがあります。

## 次に学ぶ資格

ITパスポートはIT活用者向けの基礎試験です。

より技術寄りに進む場合は、基本情報技術者試験、情報セキュリティマネジメント試験などが次の候補になります。
