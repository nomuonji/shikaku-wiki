# LPIC-2

## 概要

LPIC-2は、Linux Professional Institute（LPI）が提供するLinux技術者向け国際認定資格です。

LPIC認定の第2段階にあたり、単一Linuxサーバの基本操作だけではなく、**中小規模の混合ネットワークを管理・運用できる能力**を確認します。

カーネル、ストレージ、ネットワーク、DNS、Web、ファイル共有、メール、セキュリティなど、Linuxサーバ運用を幅広く扱います。

## 認定要件

LPIC-2認定を取得するには、次の両方が必要です。

1. **有効なLPIC-1認定を保有していること**
2. **201試験と202試験の両方に合格すること**

201と202はどちらから受験しても構いません。

LPIは2026年中にLPIC-2試験の更新を計画していると公表しているため、受験前に試験コード・Exam Objectivesが切り替わっていないか確認してください。

## 201試験の主な範囲

- Capacity Planning
- Linux Kernel
- System Startup
- Filesystem and Devices
- Advanced Storage Device Administration
- Networking Configuration
- System Maintenance

システム起動・カーネル・ストレージ・ネットワークなど、OS基盤側の高度な管理が中心です。

## 202試験の主な範囲

- Domain Name Server
- Web Services
- File Sharing
- Network Client Management
- E-Mail Services
- System Security

DNS、Webサーバ、Samba / NFS、メール、クライアント管理、セキュリティなどネットワークサービス側を扱います。

## 認定の有効期間

LPIC認定は、原則として認定日から**5年間**有効です。

有効状態を維持する方法として、LPIは次の選択肢を案内しています。

- メンバーシップを利用する
- 上位レベルの認定を取得する
- 現行版の試験を再受験する

LPIC-2を取得すると、下位のLPIC-1もLPIC-2と同じ有効期限へ更新されます。

## 難易度・勉強時間目安

LPIは一律の標準勉強時間を設定していません。

LPIC-1レベルの操作を前提に、ネットワークサービスや障害対応、セキュリティまで広がるため、Linuxを実際に構築・運用しながら学ぶ方が効率的です。

コマンド暗記だけでなく、DNS・Web・ファイル共有・メールなどを自分で構築し、設定ミスや障害を切り分けられる状態を目標にします。
