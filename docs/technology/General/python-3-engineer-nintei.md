# Python 3 エンジニア認定基礎試験

## 資格の対象

Python 3 エンジニア認定基礎試験は、Pythonの文法基礎を確認する民間試験です。実施団体は一般社団法人Pythonエンジニア育成推進協会で、プログラミング学習を始めた人が、文法や標準的な書き方を理解しているか確認する目的に向いています。データ分析、AI、Web開発の実務力全体を証明する試験ではありません。職務に必要な応用経験は、別途コードや実績で示す必要があります。

## 試験方式・範囲

試験は全国のオデッセイコミュニケーションズCBTテストセンターで通年実施されます。40問の選択式で、時間は60分、正答率70%が合格基準です。2026年の一般受験料は税別10,000円、学割は税別5,000円です。2026年9月14日から職業訓練受講者も学割の対象に加わったと協会が案内しています。学割を使う場合は対象条件と試験当日の証明方法を申込先で確認してください。

出題範囲はオライリー・ジャパンの『Pythonチュートリアル』第4版を中心に、制御構造、データ構造、例外、クラス、標準ライブラリ、仮想環境などを含みます。協会は章ごとの問題数と出題率を公開しています。たとえば制御構造は9問、データ構造は7問、例外は4問で、章により比重が違います。最新の出題表を見て学習時間を配分すると、全章を同じ深さで読むより復習範囲を決めやすくなります。

## 申込みと準備

受験日は会場の予約枠から選びます。申込み方法や受験料の支払いはオデッセイの受験者ページに従い、学割対象者は申込時に割引を選んで、当日は学生証・教員証など指定書類を持参します。会場によって予約締切や空席状況が違うため、試験日を決める前に空き枠を確認してください。

試験対策は、公式に指定された主教材の章別出題比率を見ながら、短いコードを書いて実行結果を確かめます。特に条件分岐、ループ、リストや辞書、例外処理は、用語の暗記ではなく出力を追う練習が役立ちます。協会は認定スクールの模擬試験も案内していますが、模試はスクールが提供するサービスであり、試験問題と同じとは限りません。合格率や勉強時間は公式に固定値として確認できないため、ここでは記載しません。
