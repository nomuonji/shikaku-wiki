# Google Professional Cloud Security Engineer

## 概要

【GCP セキュリティ】権限やネットの守りを設計。社外への情報漏れを防ぎやすい。

## 公式情報

- [公式サイト](https://cloud.google.com/learn/certification/cloud-security-engineer)

## 受験対象と公式試験範囲
Professional Cloud Security Engineerは、Google Cloud上のワークロードや基盤を安全に設計・運用する専門職向け認定です。公式試験はアクセス制御、通信の保護と境界防御、データ保護、運用監視、コンプライアンス対応を評価します。組織階層やポリシー、IAM、暗号化、ネットワーク防御、脅威監視などを組み合わせるため、用語だけを暗記する学習では不十分です。公式は業界経験3年以上、そのうちGoogle Cloudのソリューション設計・管理経験1年以上を推奨しています。これは必須の前提資格ではなく、試験の難度と実務範囲を理解するための目安です。

## 試験条件と認定の維持
公式案内では、試験は2時間、50〜60問の選択式で、日本語と英語に対応し、遠隔監督または試験会場で受験できます。受験資格として特定の前提認定は示されていません。Professional認定は通常2年間有効で、更新には所定の更新期間内に再認定試験を受ける必要があります。受験料・手続・更新可能期間は試験案内や認定規約の変更対象なので、申し込み時にあらためて確認してください。

資格を目指す前に、Google CloudのIAM・ネットワーク・データ保護・監視の設計を実務またはハンズオンで説明できるかを試験ガイドで自己評価しましょう。[Google Cloudの公式認定ページ](https://cloud.google.com/learn/certification/cloud-security-engineer)を確認してください。確認日: 2026-09-24。
