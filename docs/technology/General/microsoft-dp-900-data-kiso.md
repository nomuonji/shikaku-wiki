# Microsoft DP-900（Data基礎）

## 概要

【DP-900】データの基本を広く学べる。用語の壁がなくなる。

## 公式情報

- [公式サイト](https://learn.microsoft.com/ja-jp/credentials/certifications/azure-data-fundamentals/)

## ハッシュタグ

- #資格 #Azure #データ
## 何を測る基礎資格か
DP-900: Microsoft Azure Data Fundamentalsは、クラウドデータの基本概念とAzure上のデータサービスへの理解を示す初級認定です。Microsoft公式の学習項目は、リレーショナル／非リレーショナルデータ、Azureでのデータベース、分析ワークロードなどを扱います。Azureを使ったデータエンジニア経験を証明する上位資格ではなく、データ職へ進む前の概念整理や、Azureのデータ製品を使う非エンジニアの基礎確認に向きます。認定を採用条件として求める企業は多様なので、職務要件と実際のスキルを照らして取得優先度を決めましょう。

## 上位資格への進み方
MicrosoftはDP-900をデータ領域のロールベース認定に進む準備に活用できると案内していますが、Azure Database Administrator AssociateやAzure Data Engineer Associateなどの必須前提ではありません。データ基盤を構築するなら、学習パスだけでなくSQLやデータ変換の実践も加えてください。Power BIで分析レポートを作る役割が目的ならPL-300の方が直接的な試験範囲になる場合があります。DP-900の合格だけで高度なAzure運用経験や設計能力が証明されるわけではありません。

Microsoft公式では本試験は45分、料金は受験地域ごとに異なり、日本語試験も提供されています。試験範囲・予約条件は更新されるため、[DP-900公式試験ページ](https://learn.microsoft.com/en-us/certifications/exams/dp-900)と日本語の試験ガイドを確認してください。確認日: 2026-09-24。
