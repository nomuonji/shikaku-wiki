# 理容師・美容師国家試験

## 概要

【理美容師】ヘアケアのプロ。提案と再現性で指名が増える。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格種別 | 国家資格（理容師法・美容師法に基づく業務独占。無免許での営業はできない） |
| 実施団体 | 公益財団法人理容師美容師試験研修センター |
| 受験資格 | 養成施設（美容専門学校等）の卒業（見込みを含む） |
| 試験方式 | 年2回。実技試験＋筆記試験 |
| 受験料 | 実技・筆記両方 25,000円／いずれかのみ 12,500円 |
| 合格ライン | 筆記は55問中60%以上かつ無得点科目なし。実技は減点方式（各課題で減点30点以下が目安） |

2026年は第52回（実技2月1日・筆記3月1日）と第53回（実技8月2日前後・筆記9月6日）の2回実施です。実技はカッティングと、ワインディングまたはオールウェーブセッティングの2課題で、課題は試験の約3か月前に発表されます。筆記は関係法規、衛生管理、美容保健、美容の物理化学、美容文化論、美容技術理論の6科目・55問です。一部科目合格の持ち越し制度（次回1回のみ有効）があります。

## 難易度と対策

最終合格率は春期（偶数回）が50〜65%程度、秋期（奇数回）が80〜90%台と時期で大きく変動します（第53回は受験者19,850人・合格者17,273人・合格率87.0%）。実技不合格の主因はタイムオーバーと仕上がりの不均一で、毎日2回以上の通し練習を3か月続けるのが目安です。筆記は関係法規・物理化学の無得点を避けるため全科目の基礎固めが必要です。合格後は美容所での勤務のほか、フリーランス、ブライダル、美容メーカーなど進路は多彩です。

## 受験の注意点

願書受付は試験の3〜4か月前で期間が短いため、養成施設経由か試験センター公式サイトで早めに入手してください。受験料・日程・会場は回ごとに変わるため、申込前に試験センターの公式発表を確認してください。合格通知書は免許申請に必要なため大切に保管してください。
