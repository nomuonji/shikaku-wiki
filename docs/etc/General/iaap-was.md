# IAAP WAS（Web Accessibility Specialist）

## 概要

WAS（Web Accessibility Specialist）は、IAAP（International Association of Accessibility Professionals）が運営する**Webアクセシビリティの中級技術者向け国際認定資格**です。

アクセシブルなWebコンテンツやサービスを、設計・開発・実装・評価・管理する専門家を対象としています。IAAPは、WASを初心者向け・入門向けの資格とは位置づけていません。

## 求められる実務経験

IAAPの現行Candidate & Certificant Handbookでは、WASに**3〜5年の実践的なWebアクセシビリティ経験**を求めています。

主な経験領域は次の3つです。

1. **Technical code components**
2. **QA and usability**
3. **Accessibility testing**

さらに、複数OS・ブラウザ・支援技術を使ったアクセシビリティテスト、Webサイト監査、改善提案など、実際の顧客・利用者に関わる業務経験が前提です。

学習・研修・授業だけでは、WASが求める「実務上のjob tasks」の代替にはならないと明記されています。

## 対象となる知識・実務

公式ハンドブックでは、WAS候補者に高い責任レベルを期待する領域として、次のような例が挙げられています。

- HTMLの構造を理解しアクセシビリティ上の問題を特定する
- JavaScriptを含むプログラム的コンテンツの問題を理解する
- ARIAの適切な利用
- WCAGを理解・実装する
- Windows / iOS / Android等でのテスト
- 複数の支援技術を使ったアクセシビリティ・ユーザビリティテスト
- Webアクセシビリティ監査
- 修正方針・remediation recommendationの作成
- 障害当事者への影響を文脈として理解する

「コードを書けること」そのものよりも、コードやUIの問題を認識・説明し、テスト結果を改善へつなげる能力が重視されます。

## 試験・申請

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 国際認定資格 |
| 実施団体 | IAAP |
| 申請 | 実務経験を記載してCertification Portalから申請 |
| 試験機会 | 年間複数のExam Session |
| 受験方法 | Pearson OnVUE / Pearson VUE Test Center / IAAP Hosted Exam |
| 試験料（Member） | US$455 |
| 試験料（Non-Member） | US$555 |
| 新興・開発途上国向け料金 | US$225 |
| 合否 | PASS / FAIL（cut score・raw scoreは非公開） |

申請は、まず経験要件を確認し、IAAP Certification Teamの審査を受けてから支払い・試験予約へ進みます。

## 難易度・勉強時間目安

IAAPはWASを**intermediate-level technical professional certification**と定義し、初心者向けではないとしています。

試験準備時間を一律に決めるより、Content OutlineとBody of Knowledgeを使い、自分の経験が薄い領域を特定するのが適切です。WCAGの文言を覚えるだけではなく、実際のUI・コード・支援技術で問題を説明できるレベルが求められます。
