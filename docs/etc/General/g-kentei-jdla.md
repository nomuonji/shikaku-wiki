# G検定（JDLA Deep Learning for GENERAL）

## 概要

G検定は、一般社団法人 日本ディープラーニング協会（JDLA）が実施する、**AI・ディープラーニングの活用リテラシー**を確認する検定です。

AIモデルを実装するエンジニア技能だけを測る試験ではなく、「AIで何ができるか」「どこに適用できるか」「事業で使うときに何が必要か」を判断するための基礎知識を体系的に扱います。

## 試験詳細

| 項目 | オンライン試験 | 会場試験 |
| --- | --- | --- |
| 受験資格 | 制限なし | 制限なし |
| 試験時間 | 100分 | 120分 |
| 出題数 | 145問程度 | 145問程度 |
| 出題形式 | 多肢選択式の知識問題 | 多肢選択式の知識問題 |
| 受験料 | 一般13,200円 / 学生5,500円 | 一般13,200円 / 学生5,500円 |
| 方式 | 自宅オンライン | 指定会場 |

2026年はオンライン試験が年6回、会場試験が年3回の計画で実施されています。

## 出題範囲・シラバス

出題はJDLAの公式シラバスに基づきます。AI・機械学習・ディープラーニングの基礎だけでなく、活用時に必要な法律・倫理・社会的論点なども含めて体系的に学びます。

G検定は技術用語の暗記だけを目的にせず、AIを利用する側として適切な活用方針を判断する力を想定しています。

## 難易度・勉強時間目安

JDLAは一律の標準勉強時間を設定していません。

直近の2026年第5回では、オンライン・会場合計で**14,908名が受験し11,475名が合格**しました。合格率は受験回ごとに変動するため、過去回の数字だけで難易度を固定的に判断しない方が安全です。

初学者は公式シラバスを基準に学習範囲を確認し、AI用語だけでなく、活用・法律・倫理まで漏れなく整理することが重要です。
