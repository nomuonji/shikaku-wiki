# E資格（JDLA）とは

E資格（JDLA Deep Learning for ENGINEER）は、深層学習の理論を理解し、目的に合った手法を選んで実装する能力を認定する資格です。深層学習を実務で扱うエンジニアや、モデルの仕組みから実装まで学びたい人に向いています。

**受験には、試験日の過去2年以内にJDLA認定プログラムを修了していることが必要です。** 試験の申込み前に、修了日と受験予定日を確認してください。

## 受験資格と試験内容

| 項目 | 内容 |
| --- | --- |
| 受験資格 | 試験日の過去2年以内にJDLA認定プログラムを修了 |
| 試験時間 | 120分 |
| 問題形式 | 多肢選択式の知識問題。公式概要では100問程度 |
| 試験会場 | 各地の指定試験会場 |
| 受験料 | 一般33,000円、学生22,000円、JDLA会員27,500円（いずれも税込） |

認定プログラムは、大学や民間事業者などが提供する教育プログラムです。講座ごとに内容や受講条件が異なるため、受講先とJDLAの認定プログラム一覧で最新情報を確認してください。旧シラバス対応の認定プログラムを修了した人も受験できますが、対応状況は受講先に確認が必要です。

## 試験日程

### 2027年の開催予定

| 回 | 試験日 | 申込開始日 |
| --- | --- | --- |
| 2027年 第1回 | 2027年2月19日（金）〜2月21日（日） | 2026年12月1日 |
| 2027年 第2回 | 2027年8月27日（金）〜8月29日（日） | 2027年6月1日 |

申込は試験日前日23:59までと案内されています。会場の空き状況などで希望どおりに選べない場合があるため、申込ページで条件を確認してください。

### 2026年第2回の実績

2026年8月28日〜30日に実施された第2回は、受験者1,062名、合格者712名、合格率67.04%でした。これは当該回の実績であり、次回の合格率を示すものではありません。同回の試験概要では105問が出題されました。

## 出題範囲と使用フレームワーク

出題範囲は、2026年第2回から適用されたシラバスに基づきます。主な領域は次のとおりです。

- 数学的基礎：確率・統計、情報理論
- 深層学習の基礎：ネットワーク、最適化、正則化、畳み込み・再帰型ネットワーク、Transformer
- 機械学習の基礎
- 深層学習の応用：画像認識、物体検出、自然言語処理、生成モデル、深層強化学習など
- 開発・運用環境：エッジコンピューティング、分散処理、アクセラレータ、環境構築

ソースコードを含む問題はPythonで記述されます。問題ではPyTorchまたはTensorFlowのいずれかを選択します。選択した後にフレームワークを変更できないため、受験前に片方の基本的な実装に慣れておくと、試験時の操作を確認しやすくなります。JDLAは2026年第2回について、動作確認済みライブラリのバージョンも公開しています。

## 受験準備で先に確認すること

1. 受験予定日から逆算し、JDLA認定プログラムを修了できる講座を選ぶ。
2. 受験する回に適用されるシラバスを確認する。
3. PyTorchかTensorFlowのどちらを使うか決め、選んだ環境でコードを読めるようにする。
4. 受験料、会場、申込期限を申込ページで確認する。

勉強時間や難易度は、これまでの数学・機械学習・プログラミング経験や受講プログラムによって変わります。ここでは公式に一律の目安が示されていないため、特定の時間数や難易度を断定しません。
