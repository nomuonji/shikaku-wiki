# NESTA-PFT

## 概要

NESTA-PFTは、NESTA（全米エクササイズ＆スポーツトレーナー協会）のパーソナルフィットネストレーナー認定です。

日本ではNESTA JAPANが認定制度を運営しており、運動指導・トレーニング・安全管理など、パーソナルトレーナーとして必要な知識を扱います。

国家資格ではなく、民間のトレーナー認定です。

## 主な受験要件

公式案内では、次の基礎要件が示されています。

- 満18歳以上
- 高校卒業以上、または高卒認定等
- CPR・AEDの技能を習得・保持していること
- 日本国籍、または日本で就労可能な在留資格
- NESTA JAPANからPFTテキストを購入していること

このほか、実務経験・関連学歴・NESTA認定教育などの要件があります。

条件を満たしていない場合は、NESTA認定養成講座を修了して受験要件を満たすルートがあります。

## 直接受験の費用

| 項目 | 金額（税込） |
| --- | ---: |
| PFTテキスト | 14,960円 |
| 認定試験受験料 | 8,250円 |
| 受験登録・合格後資格登録料 | 40,040円 |
| 合計 | 63,250円 |

教材をすでに公式から購入済みの場合など、実際の支払額は条件によって変わります。

## 学習内容

- 解剖・生理
- 運動生理
- トレーニング原則
- プログラム設計
- 安全管理
- クライアント評価
- 指導・コミュニケーション
- パーソナルトレーナーとしての職業倫理

## 難易度・勉強時間目安

公式は一律の標準勉強時間を示していません。

トレーナー実務経験がある人と未経験者では必要な準備量が異なるため、受験要件を満たしているかを先に確認し、その後テキストと試験範囲で不足領域を整理するのが適切です。
