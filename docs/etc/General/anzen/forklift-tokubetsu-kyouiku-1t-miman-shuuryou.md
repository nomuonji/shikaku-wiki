# フォークリフト（最大荷重1トン未満）の特別教育

## まず確認：1トン「未満」と「以上」で必要な教育・講習が違う

**業務で運転するフォークリフトの「最大荷重」で判断します。** 今回持ち上げる荷物の重さではありません。最大荷重1トン未満の機体の運転業務にはフォークリフト運転特別教育、**最大荷重1トン以上（ちょうど1,000kgを含む）** の機体の運転業務にはフォークリフト運転技能講習の修了等が必要です。特別教育だけで1トン以上の機体を業務運転することはできません。根拠は労働安全衛生法第59条・第61条、同法施行令第20条第11号、労働安全衛生規則第36条です。区分は[岩手労働局の案内](https://jsite.mhlw.go.jp/iwate-roudoukyoku/news_topics/kantokusho_oshirase/hanamakikantokusyo/anzeneisei_forklift.html)で確認できます。

| 運転する機体の最大荷重 | 業務運転に必要な教育・講習 | このページでの判断 |
| --- | --- | --- |
| **最大荷重1トン未満**（例：900kg） | フォークリフト運転**特別教育**の修了等 | 特別教育の対象 |
| **最大荷重1トン以上**（1,000kgちょうどを含む） | **フォークリフト運転技能講習**の修了等 | 特別教育だけでは不可 |

### 具体例：積荷が軽くても機体の区分は変わらない

| 作業例 | 必要な区分と理由 |
| --- | --- |
| 最大荷重**900kg**の機体で荷物を運ぶ | **特別教育**の対象。最大荷重が1トン未満のため |
| 最大荷重**1,000kg**の機体で荷物を運ぶ | **技能講習**の対象。1トン「以上」に該当 |
| 最大荷重**1,500kg**の機体で**500kg**の荷物を運ぶ | **技能講習**の対象。積荷が500kgでも、機体の最大荷重は1トン以上 |

機体の銘板・仕様書で「最大荷重」を確認してください。「最大積載量」や当日の荷物重量だけで資格区分を決めないことが重要です。[宮崎労働局の作業計画案内](https://jsite.mhlw.go.jp/miyazaki-roudoukyoku/jirei_toukei/saigaitoukei_jirei/oshirase/forklift_01.html)は、機械の能力と荷の種類・形状を踏まえた作業計画も求めています。

## 特別教育は学科6時間＋実技6時間の計12時間

[東京労働局の特別教育一覧](https://jsite.mhlw.go.jp/tokyo-roudoukyoku/hourei_seido_tetsuzuki/anzen_eisei/a-kyoiku.html)では、**「フォークリフト（最大荷重1トン未満）の運転の業務」について、学科6時間・実技6時間（計12時間）** と示しています。これらは教育時間の最低時間として掲載されています。受講先の案内が「半日だけ」「オンラインだけ」などの場合は、実技を含む教育内容・時間を必ず確認してください。

| 確認項目 | 受講申込前に確認すること |
| --- | --- |
| 対象 | 「最大荷重1トン未満のフォークリフト運転特別教育」であるか。技能講習や別機械の教育と混同していないか |
| 時間 | 学科6時間・実技6時間の両方が組まれているか |
| 実施者 | 事業者が実施する教育か、事業者に代わって教育を行う団体・教習機関か。実施主体と修了記録の扱いを確認 |
| 費用・日程 | 受講先ごとに最新の募集要項を確認。全国共通の一律料金とは扱わない |
| 修了後 | 修了証・教育記録の交付や保管方法、勤務先での確認方法を確認 |

東京労働局の一覧には、事業者に代わって特別教育を行う団体等の例も掲載されています。ただし、**一覧への掲載は現在の募集枠・料金・受講可能日を保証するものではありません**。申込時点の主催者案内を確認してください。

## 倉庫内の運転と公道走行は別の話

特別教育や技能講習は、労働安全衛生法に基づく**業務上の運転資格・教育**の区分です。**これだけで公道を走行できるわけではありません。** 公道での走行には、車両の区分に応じた道路交通法上の運転免許など、別途必要な条件があります。業務資格の修了証を普通自動車免許などの代わりに使うことはできません。詳しくは[岩手労働局のフォークリフト災害防止案内](https://jsite.mhlw.go.jp/iwate-roudoukyoku/news_topics/kantokusho_oshirase/hanamakikantokusyo/anzeneisei_forklift.html)を参照してください。

倉庫の敷地内でも、運転者の教育・講習の区分だけでなく、作業計画、運行経路、始業前点検などの安全管理が必要です。作業場所の「構内」という呼び方だけで道路交通法上の公道・道路該当性を断定しないでください。

## すでに技能講習を修了している場合

フォークリフト運転技能講習は、最大荷重1トン以上の機体の業務運転を対象とする講習です。**1トン未満の機体について追加の特別教育を省略できるか**は、労働安全衛生規則第37条の「十分な知識及び技能を有する労働者」に対する教育科目の省略規定も関係します。技能講習修了証を持つ人について、別途特別教育が常に必須とも、勤務先の確認なしで一律不要とも断定せず、修了内容・教育記録・実際の担当業務を事業者が確認してください。

反対に、**特別教育の修了だけで1トン以上の機体を運転することはできません**。必要なフォークリフト運転技能講習等の資格を先に確認してください。
