# 第二種電気工事士

## 概要
第二種電気工事士は、一般住宅や小規模な店舗など（一般用電気工作物）の電気工事を行うために必要な国家資格です。
コンセントの増設、照明器具の交換、エアコンの設置工事など、身近な電気工事を行うにはこの資格が必須です。
DIY愛好家からプロの職人まで、年間10万人以上が受験する超人気資格です。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 試験日程 | 上期・下期の年2回（筆記CBT期間あり、技能は指定日） |
| 試験時間 | 筆記: 120分、技能: 40分 |
| 問題数 | 筆記: 50問（四肢択一） |
| 合格ライン | 筆記: 60点以上/100点、技能: 欠陥がないこと |
| 受験料 | 9,300円（インターネット申込） |
| 受験資格 | なし |
| 試験方式 | 筆記試験（CBTまたは筆記）、技能試験（持参工具による実技） |

## 学習範囲・シラバス
- **筆記試験**:
    - 電気理論（オームの法則など）
    - 配電理論、配線設計
    - 電気機器、材料、工具
    - 施工方法、検査方法
    - 配線図記号
    - 法令
- **技能試験**:
    - 事前に公表される13問の候補問題の中から1問が出題される。
    - 電線の切断、被覆剥き、結線、器具の取り付けなどを制限時間内に行う。

## 難易度・勉強時間目安
- **難易度**: 初級（合格率 筆記60%前後、技能70%前後）
    - 国家資格としては合格率が高く、文系や未経験者でも十分合格可能です。
    - 技能試験は練習さえすれば必ず受かると言われますが、欠陥（重大なミス）が一つでもあると不合格になるため注意が必要です。
- **勉強時間**:
    - およそ 50 ～ 100 時間
    - 筆記対策に30～50時間、技能練習に20～50時間程度。
