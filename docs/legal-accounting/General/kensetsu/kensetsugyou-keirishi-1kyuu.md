# 建設業経理士 1級

## 概要

建設業経理士1級は、一般財団法人 建設業振興基金が実施する**建設業経理士検定試験**の最上位級です。

1級・2級は、建設業法施行規則に基づく**登録経理試験**として実施されています。1級では一般的な簿記だけでなく、建設業特有の原価計算、財務諸表、財務分析を高度な水準で扱います。

建設会社の経理・財務、工事原価管理、経営分析などと強く結びつく資格です。

## 1級取得の条件

1級は1回の試験だけで完結する資格ではありません。

次の**3科目すべて**に合格する必要があります。

1. 原価計算
2. 財務諸表
3. 財務分析

各科目の合格は、合格通知書に記載された日から**5年間**有効です。

その有効期間内に3科目をそろえると「1級建設業経理士」となり、合格証明書が交付されます。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 登録経理試験 |
| 実施団体 | 建設業振興基金 |
| 受験資格 | 制限なし |
| 1級科目 | 原価計算・財務諸表・財務分析 |
| 1科目の試験時間 | 90分 |
| 科目合格有効期間 | 5年間 |
| 複数科目受験 | 同日に1級3科目まで受験可能 |

1級と他の級を同日に受験することはできませんが、1級の複数科目は同日受験できます。

## 出題内容

### 原価計算

建設工事の原価計算、工事別原価、部門別原価、予算管理など、建設業におけるコスト管理を扱います。

### 財務諸表

建設業会計、会社法・会計基準、財務諸表作成などを扱います。

### 財務分析

財務諸表を用いた収益性・安全性・生産性などの分析を行います。

単純な仕訳力だけではなく、建設会社の数字を経営判断へつなげる水準が求められます。

## 経営事項審査との関係

1級・2級建設業経理士の合格者は、一定期間、経営事項審査の「公認会計士等の数」の評価対象になります。

公式案内では、試験合格日から5年を経過する日の属する年度末までは評価対象となり、その期間を過ぎた後は**登録経理講習**の修了により評価対象となる制度です。

「一度取れば経審で永久に評価される」という制度ではない点に注意してください。

## 難易度・勉強時間目安

実施団体は一律の標準勉強時間を公表していません。

日商簿記などで会計の基礎を学んでいる人でも、建設業特有の原価計算や財務分析を追加で理解する必要があります。

3科目を一度に狙う方法も、5年間の科目合格制度を使って分割する方法もあります。実務・学習時間に合わせて受験戦略を組めるのが特徴です。
