# 弁理士

## 概要

弁理士は、特許・実用新案・意匠・商標などの**知的財産権に関する専門家**です。

特許庁への出願手続の代理だけでなく、企業の知財戦略、権利化、権利活用、紛争対応など、技術・ブランド・事業を知的財産の側面から支援します。

弁理士になるには、原則として弁理士試験に合格した後、弁理士法に基づく**実務修習**を修了する必要があります。

## 試験詳細

| 項目 | 内容 |
| --- | --- |
| 資格区分 | 国家資格 |
| 受験資格 | 学歴・年齢・国籍等による制限なし |
| 試験構成 | 短答式 → 論文式 → 口述 |
| 受験手数料 | 12,000円（特許印紙） |
| 短答試験地 | 東京・大阪・仙台・名古屋・福岡 |
| 論文試験地 | 東京・大阪 |
| 口述試験地 | 東京 |

受験資格に学歴・年齢・国籍の制限はありません。理系・文系を問わず受験できます。

## 試験の流れ

### 1. 短答式筆記試験

知的財産法を中心とする基礎知識を多肢選択式で確認します。短答式に合格しないと、原則として論文式試験へ進めません。

### 2. 論文式筆記試験

必須科目と選択科目があります。

法律知識を覚えているだけでなく、事例に対して条文・制度趣旨を使って論理的に答案を組み立てる力が必要です。

### 3. 口述試験

論文式試験の合格者を対象に、知的財産法に関する理解を口頭で確認します。

## 免除制度

弁理士試験には複数の免除制度があります。

- 短答式筆記試験の一部科目免除
- 修士・博士等の学位に基づく論文式選択科目免除
- 他の公的資格に基づく論文式選択科目免除
- 過去の試験合格実績に基づく所定科目の免除

免除条件は細かく定められているため、自分の学位・資格・過去合格歴が対象かは特許庁の最新案内で確認してください。

## 2026年度

2026年度弁理士試験の受験願書提出期間は、2026年3月5日〜4月2日でした。

試験は例年、短答式を5月頃、論文式を6月末〜7月頃、口述試験を10月頃に実施する流れです。正確な日程は毎年1月頃に公告されます。

2026年度分はすでに試験が進行しているため、2027年度以降に受験する場合は次年度の受験案内を確認してください。

## 合格後

試験に最終合格しただけで、自動的に弁理士として登録されるわけではありません。

弁理士法第16条の2に基づく**実務修習**を修了した上で、日本弁理士会への登録手続を行います。

## 難易度・勉強時間目安

特許庁は標準勉強時間を公表していません。

短答式・論文式・口述という異なる形式を突破する必要があり、特許法・実用新案法・意匠法・商標法など複数法分野の理解が必要です。

勉強時間を固定値で捉えるより、短答知識、論文答案作成、口述応答を別々に確認し、試験段階ごとに完成度を上げる方が適切です。
