# IFRS検定 (国際会計基準検定)

## 概要
IFRS検定（国際会計基準検定）は、ICAEW（イングランド・ウェールズ勅許会計士協会）が運営する国際資格です。
IFRS（International Financial Reporting Standards：国際財務報告基準）に関する知識と理解度を評価し、国際会計基準に対応できることを証明します。
企業の経理・財務担当者、会計士、監査法人などで働く方のスキルアップに有効な資格です。

## 試験詳細
IFRSは日本の会計基準とは大きく異なるため、一から学習を始める必要があります。

| 項目 | 内容 |
| --- | --- |
| **試験日程** | 年4回（2月・6月・10月・翌年2月） |
| **試験方式** | オンライン試験（自宅またはテストセンター） |
| **試験時間** | 120分 |
| **問題数** | 100問（選択式・記述式） |
| **合格基準** | 60点以上 / 100点満点 |
| **受験資格** | なし（誰でも受験可能） |
| **受験料** | 11,000円（税込） |

## 出題範囲
IFRSの包括的な知識が問われます。実務的・実用的な内容が中心です。

- 財務諸表の表示（IAS 1）
- 連結財務諸表（IFRS 10）
- 収益認識（IFRS 15）
- リース（IFRS 16）
- 金融商品（IFRS 9、IAS 32、IAS 39）
- 有形固定資産（IAS 16）
- 無形資産（IAS 38）
- 法人所得税（IAS 12）
- 従業員給付（IAS 19）
- 保険契約（IFRS 17） ※2024年1月から追加
- その他の主要なIFRS基準

## 難易度・勉強時間目安
- **難易度**: 普通 (合格率 70～80%程度)
    - 2024年度の合格率：
        - 2024年2月（第51回）：68.4%
        - 2024年6月（第52回）：80.0%
        - 2024年10月（第53回）：70.7%
    - IFRSの基本的な内容をしっかり理解していれば合格できるレベル
    - 日本の会計基準との違いを理解することが重要
- **勉強時間**: 150～200時間
    - 日商簿記2級程度の会計基礎知識があることが望ましい
    - BATIC（国際会計検定）より多くの学習時間が必要とされる

## 対象者
- 経理・財務部門の担当者
- 上場企業・グローバル企業の経理担当者
- 公認会計士・税理士
- 監査法人勤務者
- IFRSに興味のある学生
