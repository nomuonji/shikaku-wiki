# 公認会計士

## 概要
公認会計士は、企業等の財務情報の信頼性を保証する「監査」を独占業務とする国家資格です。
医師、弁護士と並ぶ「三大国家資格」の一つとされ、会計・財務・税務・経営のプロフェッショナルとして、監査法人、コンサルティング会社、一般企業のCFO、独立開業など、活躍の場は極めて広いです。
試験合格後は、業務補助等の実務経験（2年）と実務補習所の修了を経て、公認会計士として登録できます。

## 試験詳細
試験は「短答式試験」と「論文式試験」の2段階で行われます。

| 項目 | 内容 |
| --- | --- |
| 試験日程 | 短答: 年2回（12月、5月）、論文: 年1回（8月） |
| 合格ライン | 短答: 総点70%目安、論文: 偏差値52目安 |
| 受験料 | 19,500円 |
| 受験資格 | なし（誰でも受験可能） |
| 試験方式 | 短答: マークシート、論文: 記述式 |
| 有効期限 | 短答合格は2年間免除 |

## 学習範囲・シラバス
**短答式試験 (4科目)**
- 財務会計論（簿記、財務諸表論）
- 管理会計論（原価計算、管理会計）
- 監査論
- 企業法

**論文式試験 (必須5科目＋選択1科目)**
- 必須: 会計学（財務会計・管理会計）、監査論、企業法、租税法
- 選択: 経営学、経済学、民法、統計学から1科目選択

## 難易度・勉強時間目安
- **難易度**: 超難関（最終合格率 7% ～ 10%）
    - 質・量ともにトップクラスの難易度を誇ります。
- **勉強時間**:
    - およそ 3000 ～ 5000 時間
    - 学生や専念受験生が多く、1.5年～2年以上の学習期間が一般的です。

## 試験合格から登録までの道のり
公認会計士試験に合格した時点で、直ちに公認会計士として登録できるわけではありません。公認会計士になるには、試験合格後に業務補助等の実務経験、実務補習、修了考査など法令に定める条件を満たし、日本公認会計士協会への登録手続を行います。監査法人への就職は代表的な進路ですが、企業の経理・財務、コンサルティングなど資格取得後の働き方は一つに限られません。進路を比べる際は、合格者数や合格率だけでなく、合格後に必要な期間・費用と、希望する実務経験を積める環境も考慮してください。

## 短答式・論文式の対策を分ける
試験は短答式と論文式の段階で構成され、財務会計、管理会計、監査、企業法などの知識を問います。短答式は広い範囲の基礎理解と正確な処理、論文式は知識を事例に適用し筋道立てて説明する力が中心です。学習時間や最終合格率は受験者の前提や年度で大きく変わり、万人に当てはまる数字ではありません。予備校等のモデル時間は計画の参考にとどめ、模試の弱点と使える週あたりの学習時間から自分の見通しを作ってください。

試験日程、願書、試験科目、合格者発表は公認会計士・監査審査会が公表します。[公認会計士試験の公式案内](https://www.fsa.go.jp/cpaaob/kouninkaikeishi-shiken/index.html)を確認してください。確認日: 2026-09-24。
