# 仕事から、必要な資格を逆算する

「この職業におすすめの資格10選」の一覧より先に、**その仕事で何を担当するのか**を確かめます。同じ職業名でも、会社の業務範囲や担当設備により求められる免状が異なります。

## 担当する業務で探す

| 仕事でやりたいこと | 最初に確認する制度・資格 | 判断ポイント |
| --- | --- | --- |
| 住宅や小規模な店舗などの電気工事 | [第二種電気工事士](/docs/etc/General/daini-shu-denki-koujishi/) | 工事対象が一般用電気工作物等に該当するか、免状が必要な工事か |
| 自動火災報知設備等の工事、点検 | [消防設備士甲種4類](/docs/safety-environment/Safety/bousai/shoubou-setsubishi-koushu-4rui/) | 第4類の設備か、工事があるか、それとも整備・点検だけか |
| ガソリン、灯油などの危険物に関わる | [危険物取扱者乙種4類](/docs/safety-environment/Environment/kagaku/kikenbutsu-toriatsukaisha-otsushu-4rui/) | 第4類危険物に該当するか、甲種や他の類が必要な業務か |
| ビルの電気・防災設備を管理 | [設備管理と関連資格の整理](/birumen-shikaku/) | 保安・工事・危険物取扱い・消防設備の業務を分ける |
| AWSを使った提案・管理やクラウドの基礎 | [AWS Cloud Practitioner](/docs/technology/General/aws-cloud-practitioner/) | AWSの用語理解が目的か、実装・運用職を目指すか |
| Google Cloudを使った事業企画 | [Cloud Digital Leader](/docs/technology/General/google-cloud-digital-leader/) | 会社で使うクラウドの違い、事業面の学習か実装面の学習か |
| 小売店舗の販売・運営 | [販売士（リテールマーケティング）](/docs/business/Marketing/hanbaishi-retail-marketing-kentei/) | 接客、売場管理、経営のどの段階にいるか |

## 「必要」の意味を3つに分ける

1. **法令や業務範囲に必要な免状・選任**：その仕事の特定業務を担当するための法的要件。資格を持っていればあらゆる業務ができるわけではありません。
2. **企業の応募条件**：求人票で企業が定める採用条件。法令による一律の資格要件とは別です。
3. **知識の学習・民間認定**：業務への理解を深める目安。取得すれば採用や昇進が保証されるものではありません。

### ビルメンテナンスを例に

ビルの設備管理でも、電気工事を自らする業務、受変電設備の保安、消防用設備の点検、危険物を扱う業務ではそれぞれ制度が異なります。資格名だけのランキングでは、これらの違いが見えなくなります。[実際の業務から資格を選ぶビルメンガイド](/birumen-shikaku/)で整理できます。

## 仕事の種類自体を探す

資格より職業そのものを広く探すなら、別サイトの[しごと図鑑](https://job.antonbase.com/)で業務・就業経路を調べられます。候補の職種と実際の求人条件を把握したら、ここに戻って資格の対象範囲や受験経路を照合してください。

## 出願前の確認

免状交付、試験合格、行政登録、実務経験は別の条件です。[受験資格の逆引き](/juken-shikaku/)から、現在の免状・学歴・経験で進める制度を確認できます。原則として、実施団体と主管官庁の最新資料、勤務先の具体的な業務・応募条件を優先します。
