# 危険物乙4と甲種の違い。「上を取るべき？」を業務から考える

乙4は第4類の引火性液体を扱う資格区分です。甲種は第1〜6類のすべての種類の危険物を対象とします。ただし、**乙4の免状を取れば自動的に甲種を受けられるわけではありません**。

## 乙4と甲種、できることと試験の違い

| 比較 | 乙種第4類（乙4） | 甲種 |
| --- | --- | --- |
| 対象危険物 | 第4類・引火性液体（例：ガソリン、灯油、軽油など） | すべての類の危険物 |
| 受験資格 | 制限なし | 化学系学歴・15単位・乙種免状＋所定実務2年・所定4種類の乙種免状など |
| 筆記問題数 | 35問（法令15・物化10・性消10） | 45問（法令15・物化10・性消20） |
| 試験時間（免除なし） | 2時間 | 2時間30分 |
| 試験手数料（公式掲載） | 5,300円（非課税） | 7,200円（非課税） |

数値は[消防試験研究センターの試験方法](https://www.shoubo-shiken.or.jp/kikenbutsu/annai/way.html)・[試験科目](https://www.shoubo-shiken.or.jp/kikenbutsu/annai/subject.html)・[受験資格](https://www.shoubo-shiken.or.jp/kikenbutsu/qualified01.html)によります。日程と手数料は受験時点で再確認してください。

## 乙4だけでよい場合

予定している危険物取扱いが第4類に限られ、甲種や他類を必要とする業務を担当しないなら、甲種の取得が常に必須というわけではありません。職場で取り扱う物質の種類、作業の立場や制度上の要件を確認します。

## 甲種を検討する場合

将来、第4類以外の危険物も対象とする業務に関わるなら甲種が候補です。ただし受験できるかは別の問題です。

- **乙種免状交付後の実務経験が2年以上**：危険物製造所等で所定の取扱経験がある場合、事業主等の証明により受験資格となる経路があります。
- **乙種4種類ルート**：第1類または第6類／第2類または第4類／第3類／第5類の各グループを満たす免状が必要です。
- **化学の学校・単位・学位**：所定の学科卒業、化学関連授業科目15単位以上、化学専攻の修士・博士等の経路があります。

[保有している乙種免状から不足グループを計算するチェッカー](/kikenbutsu-kou-juken-shikaku/)を使うと、4種類ルートの組み合わせを確認できます。乙4だけでなく他の経路がないかもあわせて確認してください。

## 勉強時間や「難易度ランキング」で決めない

公式が一律の標準学習時間を定めていない場合、「乙4は必ず40時間」などの数値は出しません。乙4は第4類の性質・消火を中心に学ぶのに対して、甲種は対象となる危険物の範囲が広くなります。公式試験科目と過去の公表問題を確認し、前提の化学知識や仕事の必要性で判断するのが合理的です。
