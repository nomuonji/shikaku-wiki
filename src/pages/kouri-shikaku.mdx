# 小売業で役立つ資格は？　担当する仕事から選ぶ

販売職で働くために全員が同じ資格を取る必要があるわけではありません。**売場で何を担当するか**によって、学ぶべき内容は違います。資格が採用必須かどうかは実際の求人票で確認します。

## 役割から見る販売士の級

日本商工会議所のリテールマーケティング（販売士）検定は、小売の接客、売場運営から経営までを段階的に学ぶ検定です。

| 自分が関わる仕事 | 検討する級 | どう学習を結びつけるか |
| --- | --- | --- |
| 接客・商品説明・売場の基本 | 3級 | 商品、売場、接客と流通の仕組みを理解する |
| 売場管理・販促・店舗運営 | 2級 | 在庫・販促・人員などの店舗運営の判断を学ぶ |
| 商品計画・複数店舗や経営の判断 | 1級 | 店舗だけでなく事業全体の計画を扱う |

資格名だけで難易度を比べず、日常の業務と試験範囲がつながっているか確かめてください。[販売士検定の級別ガイド](/docs/business/Marketing/hanbaishi-retail-marketing-kentei/)で試験方式、更新情報、科目体系を整理しています。

## これから販売士を受けるなら、制度移行に注意

日本商工会議所は、2026年2月3日に販売士試験の科目体系を現行5科目から新4科目に再編し、級ごとに段階的に移行すると案内しています。

| 級 | 新しい試験体系の開始予定年度 |
| --- | --- |
| 3級 | 2027年度 |
| 2級 | 2028年度 |
| 1級 | 2029年度 |

これは級ごとに異なるため、旧版教材を買う前に受験する年度と級の組み合わせを確かめます。詳細は[日本商工会議所の公式発表](https://www.kentei.ne.jp/50119)に掲載されています。

## 接客以外の担当になった場合

### ECや集客の運用を担当する

販売士の店舗運営に加え、Webのアクセス解析やインバウンドマーケティングの基礎が必要なことがあります。[Google Analytics認定](/docs/business/Finance/bunseki/google-analytics-individual-qualification-gaiq/)や[HubSpot Inbound認定](/docs/business/Marketing/hubspot-inbound-marketing/)は対象が異なるため、勤務先の仕事と使うシステムに合う学習を選びます。

### 会計や経営に関わる

売上・原価・利益の管理は小売の実務に直結します。ただし「販売士の上級を取れば管理職になれる」と保証するものではありません。資格試験で学ぶことと、職場での業務実績・役割を分けます。

## 申込前に見ること

1. 担当したい業務を接客・売場・店舗運営・経営に分ける。
2. 自分に合う級の試験範囲を公式シラバスとサンプル問題で見る。
3. 受験する年度の新旧科目体系と対応教材を照合する。
4. CBTの申込条件・空席と受験料を公式受付で確認する。
