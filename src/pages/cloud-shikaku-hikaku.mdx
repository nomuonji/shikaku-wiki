# AWS Cloud PractitionerとGoogle Cloud Digital Leader、最初の一つはどちら？

どちらもクラウドの基礎に関わる認定ですが、**資格名が似ていても、対象にするサービスとその学び方は異なります**。現場で使うクラウドを把握することが第一の判断材料です。

## 2つの基礎認定を比較

| 判断 | AWS Certified Cloud Practitioner（CLF-C02） | Google Cloud Digital Leader |
| --- | --- | --- |
| 提供元 | AWS | Google Cloud |
| 主な範囲 | クラウド概念、責任共有モデル、セキュリティ、AWSサービス、請求・価格 | デジタルトランスフォーメーション、データ、AI、インフラ、信頼・セキュリティ、運用 |
| 想定する学習用途 | AWSを使う組織で基礎用語を理解する | Google Cloudが事業課題にどう使えるか理解する |
| 実装力の証明 | これ単独で専門的な構築・運用スキルを保証しない | これ単独で専門的な構築・運用スキルを保証しない |
| 次の検討 | Solutions Architect / Developer / CloudOpsなど職務別の学習 | 利用サービスや担当業務に対応したGoogle Cloudのロール別認定等 |

AWS CLFについては[AWS認定 Cloud Practitionerの個別ガイド](/docs/technology/General/aws-cloud-practitioner/)、Google側は[Cloud Digital Leaderの個別ガイド](/docs/technology/General/google-cloud-digital-leader/)に公式試験内容と再認定情報をまとめています。

## 状況別に選ぶ

### 勤務先や学習環境ですでにAWSを使っている

基本サービスや責任共有モデル、請求・料金体系を理解したいなら、AWS CLFを先に確認する理由があります。より実務に近い構築や運用が目的なら、基礎認定を必ず経由する前提ではなく、[AWS認定の職務別選択ガイド](/docs/technology/General/aws-certification-path/)も見てください。

### Google Cloudを使った事業企画やAI・データ活用に関わる

Google Cloudの仕組みとビジネス上の用途を幅広く理解する目的ならCloud Digital Leaderが候補です。Google Cloudを実際に操作し、構築する業務が目標なら、基礎認定だけでは仕事の準備が完了しません。

### まだ使うクラウドが決まっていない

どちらが普遍的に「優れている」とは言えません。先に目的を決め、公式の学習パス・シラバスを見比べ、実際に触れるクラウド環境を一つ選びます。二つの基礎認定を無条件に両方取得する計画にしなくても構いません。

## 費用・出題範囲・更新を確認する順番

1. 利用するクラウドと目指す担当業務を決める。
2. 各社の公式ページから現行の試験ガイドを確認する。
3. 予約時点の料金・日本語対応・オンライン受験条件を比べる。
4. 有効期間と再認定の手続きまで確認する。
